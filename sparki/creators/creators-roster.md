## 一、为什么要做 Creators 页面

### 项目目标

- 构建一系列**红人视频页面**获取 **SEO 流量**,围绕红人名字、剪辑风格、视频内容承接搜索。
- 每个红人页面展示**原视频**,支持用户**一键拷贝**该视频,进入 Sparki 进行 AI 编辑 / **Copy Style**。
- 与 [sparki-use-cases.md](../sparki-use-cases.md) 中 U1-B5 Copy Style 场景打通:「Edit Like {红人}」即核心 SEO 落地页形态。

### 转化路径

```
搜索红人 / 剪辑风格 → 进入详情页 → 一键拷贝原视频 → Sparki 二次创作
```

### 选红人标准（首批）

- **粉丝量大**:YouTube Shorts 有稳定流量,能承接品牌与名字搜索。
- **剪辑风格有辨识度**:节奏、转场、镜头语言可被拆解为「配方」,适合 Copy Style 演示。
- **品类覆盖**:时尚、美食、生活方式、健身、喜剧等,对齐 Sparki 现有编辑能力。
