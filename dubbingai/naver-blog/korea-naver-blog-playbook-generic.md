# 韩国 Naver Blog 增长要点（泛用 · 脱敏版）

> **用途**：仓库内任意 **B2C SaaS / 工具类产品** 在韩国通过 Naver Blog 做内容增长时的 **一页摘要**；**不**绑定特定客户名、行业案例或竞品代号。详细条款与界面路径以 [Naver-Blog.md](../../../Naver/Naver-Blog.md)、[Naver-Blog-发布与编辑指南.md](../../../Naver/Naver-Blog-发布与编辑指南.md) 为准。  
> **整理日期**：2026-04-28

---

## 1. 为何单独配 Naver

- 韩国用户大量在 **Naver 生态**内搜索与阅读长文；仅押 **Google + 英文官网** 往往覆盖不足。
- **官网** = 价格、条款、产品真相 **SSoT**；**Naver** = 韩文教程、对比、信任与社交证明；数据 **分渠道** 复盘（勿用 GSC 替代 Naver 后台）。

## 2. 开号前四件事

| 事项 | 建议 |
|------|------|
| 单篇主意图 | 每篇一个问题：教程 / 对比 / 测评 / 公告 |
| 读者与语言 | 目标读者用 **自然韩语**；产品名、英文 UI 名配 glossary |
| 博客垂类 | **2～3 个主类目**，忌类目混杂 |
| 合规 | 广告、협찬、赞助关系按平台与韩国标识义务标注 |

## 3. 账号与编辑环境

- **运营专用 Naver 账号**（2FA、交接写清）；优先 PC 端或官方 App 的 **스마트에디터 ONE** 写长文。
- **기본 에디터** 设为 ONE；**字体/行距** 一次性设好。
- **카테고리** 先规划主类，系列文归入同一主类。

## 4. Profile 与博客层展示

- 博客名、简介、封面与 **对外品牌写法** 一致；外链指向 **官方域名**（带统一 UTM），忌可疑短链。
- 多账号矩阵避免异常互赞、机刷（见通用指南「多账号底线」）。

## 5. 首篇务实选题

- 选 **高意图、单场景、少争议**：例如「 한 플랫폼에서 ○○ 설정하는 방법」或「카테고리 내 **한 차원** 비교」。
- 避免首篇即大全促销；结构用 **제목 · 리드 · H2/H3 · 표 · CTA**；粘贴用纯文本避免脏格式。
- **발행屏**：카테고리、태그（少而精）、전체공개、검색 허용、댓글/공감、대표 이미지 — 一次勾选完整。

## 6. 可发现性与迭代

- 标题与首段强相关；原创图与 ALT；**稳定发刊节奏**；同系列 **内链** 2～3 篇。
- 发后 **频繁小幅改写** 可能对展示不利（社区经验，非官方承诺）；大改版可考虑新文承接。
- 月度表记录：文章 URL、上线日、主词、UTM 落地表现。

## 7. UTM（与官网互链时）

定稿前统一命名规则，示例格式：

`https://example.com/path?utm_source=naver_blog&utm_medium=social&utm_campaign=kr_growth_YYYY&utm_content={topic_slug}`

## 8. 合规与品牌安全

- 광고·협찬·제공품 표시义务；转载注明来源；音视频与商标素材注意版权。
- YMYL 领域避免无证收益承诺。
