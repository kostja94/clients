## §PR — Track C CMS 表现形式

> Phase 4 / Phase 5 加载 · 对标 cms-export 典型稿

### 1. 结构模板

```
# H1
{1–2 段 hook — meme/角色/趋势语境}

## Key Takeaways
* bullet 1
* bullet 2
* bullet 3–5

> **Pro Tip:** {optional one-liner}

## {H2 sections — 2–5 节}
...
## Conclusion
{1–2 段 + 可选 CTA}
```

### 2. Key Takeaways 规则

- 3–5 bullets
- 第一项可含 [Dubbing AI](https://dubbingai.io/) 产品钩（自然，非硬广）
- 不重复 H1 全文

### 3. 词数与密度

| 类型 | 词数 | 列表占比上限 |
|------|------|:---:|
| SoundboardPick | 1200–2000 | 45% |
| SoundEffectPick | 1200–2000 | 45% |
| VoiceActorProfile | 1500–2500 | 40% |
| PopCultureExplain | 1000–1800 | 40% |
| CharacterBridge | 1200–1800 | 40% |

### 4. 产品提及

- SoundboardPick：Dubbing AI 可排第一，但须列 2+ 第三方来源
- VoiceActorProfile：≤20% 产品；结尾轻链 `/voice-changer/{slug}`
- 全文 CTA ≤2

### 5. 图片

Track C 可保留 `![alt](url)`；Image Source 行可选；新稿优先 `/blog/images/{slug}.jpg` 占位。

### 6. Voice

- 年轻、meme 友好、第二人称 you
- 仍禁：revolutionary · 无据「Voicemod 更差」· 1000 tones

### 7. 内链

- 1–3 条 `/community-sounds` 或 `/soundboard`（SoundboardPick）
- P4：生成意图链 `/sound-effect-generator`
- 2–4 条 cms-export 互链可接受（相关 meme/游戏文）

### 8. SelfCheck 快速项

- Key Takeaways 存在且 3–5 条
- category frontmatter 匹配类型
- 产品占比 ≤ 类型上限
- G1/P1/P6 Pass
