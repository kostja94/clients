## Proof Gate（P1–P6，一票否决）

Dubbing AI 博客涉及实时音频、硬件、竞品对比与合规边界。**P1–P6 任一项 Fail = 不得发布。**

| # | 阻断条件 | 严格标准 |
|---|---------|---------|
| **P1** | 产品规模数字无 as-of | 500+ voices、100,000+ sounds、<30ms、<3% CPU 须 **as of {month} {year}** 或链 dubbingai.io/features 或首页；禁 CMS 遗留「1000 tones」 |
| **P2** | Live vs File 品类混淆 | Murf、录音型 TTS、upload-first SaaS **不得**标为 live Discord/gaming mic 首选 |
| **P3** | Assistant vs live mic 混用 | 涉及 Google Assistant/Siri/系统 TTS 的稿须链 `/blog/how-to-change-google-assistant-voice` 或明确分流；live mic 稿链 `/blog/how-to-change-your-voice` |
| **P4** | Soundboard / Community / Generator 混用 | 现成梗音库 → `/community-sounds`；AI 生成 → `/sound-effect-generator`；禁把库当「生成器」 |
| **P5** | Dubbing Box 夸大 | 须区分 Desktop 虚拟麦 vs 硬件桥接；禁「所有移动端开箱即用零延迟」 |
| **P6** | 竞品不公平 | Voicemod/Voice.ai 须 ≥1 条真实优势；Voice.ai 社区 15k–20k 声音等数字须有来源 |

## Live vs File 边界表（P2）

| 工具类型 | 典型产品 | 适合 | 不适合 |
|---------|---------|------|--------|
| Real-time desktop | Dubbing AI, Voicemod, Voice.ai | Discord, OBS, in-game VOIP | 批量 WAV 导出流水线 |
| Record-first / TTS | Murf | 旁白、培训、多语言成片 | 排位赛 live mic |
| Browser upload | 部分 online tools | 快速试听、单文件 | 全局虚拟麦（多数不支持） |

| 禁写 | 正确写法 |

| Murf for Discord gaming | Murf for recorded narration |
| Dubbing AI updates every week（无据） | check official changelog; avoid unverified cadence claims |
