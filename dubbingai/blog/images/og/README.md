# Blog OG cover images

1200×630 WebP OG covers for dubbingai.io/blog articles.

**Path pattern:** `{slug}/{slug}-og-en.webp`

**Generate:** see [skills/ops/og-covers.md](../../skills/ops/og-covers.md)

```powershell
python ../../scripts/ops/generate-og-cover.py --slug best-ai-voice-changer
```

Do not commit API keys. `.meta.json` sidecars are optional debug output from the generator.
