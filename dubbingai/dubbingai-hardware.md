## 硬件策略总览

Dubbing AI 是实时 AI 变声赛道中**唯一拥有自研硬件产品的厂商**。主要竞品（Voicemod、Voice.ai）均为纯 Desktop 软件。硬件产品线让 Dubbing AI 在以下场景建立壁垒：

- **移动端实时变声**：手机无法像 PC 一样运行桌面级实时变声应用
- **主机端（PS5/Switch/Xbox）变声**：主机生态无原生变声软件支持
- **低延迟硬件处理**：专用 NPU 芯片处理 AI 推理，不抢占手机/主机算力

### 1.8 典型使用场景

```
手机 → USB-C → Dubbing Box → 蓝牙 → 无线耳机
                                      ↓
                              语音 App / 手游 / 直播
```

- **手游变声**：Android 手机直插 Dubbing Box，连接蓝牙耳机，在 PUBG Mobile / Fortnite 中使用角色声音
- **主机游戏变声**：Switch/PS5 连接 Dubbing Box，派对聊天实时变声
- **移动社交**：Discord/WhatsApp/Telegram 通话实时变声
- **直播/内容创作**：手机直播时通过 Dubbing Box 实现变声 + 音效板

### 1.9 限制与注意事项

- **有线耳机不支持**：通过蓝牙连接无线耳机（Dubbing Box 蓝牙芯片仅作音频输出）
- **iOS 暂不支持**：需加入 Waitlist 等待 iOS 版本
- **需配合手机 App**：不含独立操作界面，声音选择/管理通过 App 完成
- **配送周期**：美国 14-20 工作日，加拿大 14-20 工作日

## 五、FAQ（常见问题）

**Q: Dubbing Box 支持有线耳机吗？**  
A: 不支持。Dubbing Box 通过蓝牙芯片连接无线耳机。如需有线监听，建议保留手机直插有线耳机（此时 Dubbing Box 仅作无线发射）。

**Q: 可以用在 PC 上吗？**  
A: 可以。通过 USB-C 连接 PC，配合 Dubbing AI 桌面版 App（Windows/Mac）使用。

**Q: iOS 什么时候支持？**  
A: 官方已开放 Waitlist，具体时间待公布。

**Q: Dubbing AI Earbuds 和 Dubbing Box 是什么关系？**  
A: **独立产品线**。Earbuds 是 USB-C **有线变声耳机**（`/earbuds`）；Box 是连接手机/主机的 **AI 硬件盒**，通过蓝牙连无线耳机。二者场景不同，非「Box 专用配件」。

**Q: Earbuds 什么时候发货？**  
A: 以 [dubbingai.io/earbuds](https://dubbingai.io/earbuds) 与官方商店 PREORDER 说明为准。
