| **Reporting / Dashboard（暂缓）** | social media report（2,900）、instagram reporter app（1,300）、social media analytics dashboard（720） | 仅作 `/research` Sample Output 模块，不建独立页，避免偏传统 SaaS dashboard |
| **Sentiment / Listening（暂缓）** | social media sentiment（1,600）、social media monitoring platforms（1,000） | 仅作 comment signals 模块 / 远期观察 |
| **AI 生成类工具（Watch）** | ai social media post generator（2,900）、ai social media manager（1,600） | 后续可作 idea/caption generator 类工具验证 |
| **Viral Video Analyzer / Hook Analyzer（观察）** | hook analyzer（140） | 无直接关键词数据，不作为 Phase 1 页面 |
| **竞品品牌词（排除）** | ocoya ai（2,400）、trendtok analytics（1,300）、hootsuite insights（1,000）、sprout social analytics | 只记录竞品词，不主攻 |
| **广告/投放分析（排除）** | ads insights facebook（210）、tiktok ad analytics（110）、paid social analytics | 2mv 只做 Organic |
| **偏学术/网络分析（排除）** | web traffic measurement（1,600）、social network analysis and mining（1,300）、social network analysis python（70） | 与短视频增长方向弱相关 |
