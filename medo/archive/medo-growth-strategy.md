## 1. 增长目标与约束

| 维度 | 策略 |
|------|------|
| **主转化** | 注册 → 首次生成 → Publish → 消耗 credits 续用 |
| **主战场** | 全球 vibe coding / no-code；垂类：教育、游戏、落地页、小电商 |
| **内容支柱** | 全栈非 Demo、多 Agent、低价 credits、广场案例 |
| **约束** | 生成内容版权与 UGC 审核；联盟佣金需合规披露；Baidu 关联表述需法务统一 |

### 方向 B：Hackathon 与创作者生态

| 要素 | 内容 |
|------|------|

### 方向 C：Affiliate / KOL

| 要素 | 内容 |
|------|------|
| **目标** | 付费转化、recurring 收入分成 |
| **战术** | 官方 **30% recurring commission**（Affiliate Banner） |
| **受众** | 教程博主、Indie Twitter、中文开发者社区 |
| **交付** | 联盟落地页 + 素材包 + 专属 credits 码（**待验证**） |
| **联动** | [medo-use-cases.md P5](../medo-use-cases.md) |

### 方向 D：SEO + 对比 + 模板

| 要素 | 内容 |
|------|------|
| **目标** | 拦截 AI app builder、lovable alternative、分类长尾 |
| **交付** | `/pricing`、`/vs/lovable`、`/templates/{category}` |
| **程序化** | 广场优质 App → 结构化 showcase 页（标题即长尾） |
| **联动** | [medo-keywords.md](../medo-keywords.md) P0 |

### 方向 E：开发者关系与文档

| 要素 | 内容 |
|------|------|
| **目标** | 降低首次 Publish 失败率 |
| **战术** | MIAODA Quickstart、插件文档、DEV 深度案例复投 |
| **GEO** | FAQ：全栈栈、Supabase、Stripe、导出策略 |
| **联动** | Baidu 文档树 + 建议 `/developers` |

### 方向 F：UGC 广场飞轮

| 要素 | 内容 |
|------|------|
| **目标** | 新访客停留、模仿创建 |
| **战术** | Recommended 编辑精选；分类 Tab SEO 化；分页深度收录 |
| **风险** | 低质/违规 App 伤害品牌 → 审核与举报（**待验证** 机制） |
