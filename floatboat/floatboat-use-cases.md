## 1. 叙事主轴（与官网对齐）

- **官方定位**：*The Proactive Agent OS that Runs Work from the Calendar* —— 日历驱动的 Agent OS，以日历为运行时，Agent 会前准备、到期执行、会后跟进，自动完成。  
- **英文传播**：用 *Calendar-Driven AI for Solopreneurs* 或 *Proactive AI Agent for Solo Founders*。  
- **核心叙事**：Calendar-Driven（主动）vs Chat-Based（被动）——"Work isn't a chat thread — it's a schedule."  
- **写作提示**：Blog / 落地页先写 solopreneur 的日历压力（会议、截止日、跟进漫天），再展开 Floatboat 如何把日历从「时间列表」变成「执行引擎」。

## 2. 外部语境（检索摘要 · 供内容与脚注）

以下为有公开出处的行业叙述摘要，**引用时请回原报告口径**，避免二次传播时夸大单一数字。

### 2.1 Solo Founder 结构性上升（创投与公司设立数据）

- **Carta × Solo Founders（2025）**：美国新公司中，**单人创始人占比从约 23.7%（2019）升至约 36.3%（2025 年上半年）**；报告将 **AI 与自动化**、成功案例示范、以及部分人偏好早期掌控权列为驱动因素。  
  - 参考：[Solo Founders Report 2025（Carta）](https://carta.com/data/solo-founders-report/)  
- **对 Floatboat 的含义**：「单人开局」已是常态而非边缘；文案可强调 **桌面上下文 + 浏览器/OS 能力 + 可封装技能**，对齐「没有联合创始人分工」的现实。

### 2.2 非雇主经营主体规模（宏观经济叙事）

- 美国 Census 口径下的「非雇主企业」规模约为数千万量级，solo 业务收入分层从副业到高收入并存。  
- **Stripe / Emily Sands「nanocorp」叙事**：强调 **无雇员经营主体在新设企业中的增长贡献**、以及 **AI 作为单人杠杆** 的组合 —— 适合用作「为何现在是单人工具窗口期」的背景段，**不宜在没有一手图表时写死具体百分比**。  
  - 可作延伸阅读：[Solopreneur statistics 类综述（示例）](https://crevio.co/blog/solopreneur-statistics)

### 2.3 常见痛点（与产品映射）

| 痛点类型 | 公开叙述中常见表述（归纳） | Floatboat 映射（内部） |
|----------|----------------------------|-------------------------|
| **职能全集** | 销售、交付、财务、客服、运营同属一人 | Combo Skills；减少「每次从零 prompt」 |
| **时间与注意力** | 瓶颈常被归为「优先级/打断」而非不会做 | 分屏、预览、上下文拖拽；Reminders / 邮件跟进 |
| **产出压力** | 对客户/投资人的材料要又快又像「团队水准」 | Voice notes → Tailor-Made Deck；碎片 → 成稿 |
| **商务与风险** | 合同、条款、谈判准备耗时且不敢出错 | 「Help Me Win」类审查视角（**必须**配非法律建议免责声明） |
| **倦怠与波动** | 调研类报告常提收入不稳定、身心负荷 | 适合 **共情型内容** 与「减少上下文切换」卖点，避免宣称治愈心理健康 |

### 2.4 AI 采用（佐证「单人 + AI 杠杆」）

- **Simply Business 2025 Solopreneur Report**（2025-08 发布，1,023 名美国 solopreneur 调研）：  
  - **61%** 低估了独自处理所有业务职能的难度 → 直接验证 Combo Skills 需求  
  - **仅 23%** 使用 AI/自动化工具 → 市场渗透率极低，Floatboat 有巨大教育+获客空间  
  - **48%** 经历过至少一个月无收入；**68%** 储蓄不足 6 个月 → 定价需匹配 solopreneur 现金流现实  
  - **76%** 对未来 12 个月增长有信心 → 乐观但不富余，产品价值需快速显现  
  - 参考：[Simply Business 2025 Solopreneur Report](https://www.simplybusiness.com/resource/2025-solopreneur-report/)  
- 其他面向 solo / 小微的报告提到较高比例受访者已将生成式 AI 用于 **营销、客服、销售辅助** 等职能 —— 可作为「Solopreneur 已不是要不要用 AI，而是用哪种工作台面」的过渡句。

## 4. 官网 Combo 场景（Solopreneur / Solo Founder 语境）

### 4.1 Voice notes → Tailor-Made Deck

- **Solopreneur**：一人见客户/渠道伙伴前要「像样的 deck」，但没助理排版。  
- **Solo Founder**：路演、天使沟通、产品叙事迭代 —— 从备忘录与通话录音快速成稿。  
- **输入**：文档、语音笔记、通话录音、原始想法  
- **输出**：清晰叙事、结构化幻灯片、客户就绪、个人语气  
- **关键词**：voice to deck AI；founder pitch；sales deck AI；solopreneur presentation

### 4.2 Scattered notes → Publish-ready content

- **Solopreneur**：营销、获客、社群更新不能停，但没时间重写同一事实五遍。  
- **Solo Founder**：发布节奏 = 存在感；需把思考碎片变成可发布的连贯叙事。  
- **输入**：粗稿、研究链接、风格参考、语音片段  
- **输出**：平台就绪帖子、润色长文、个人声音一致  
- **关键词**：content repurposing；AI writing workspace；solo founder content workflow

### 4.3 「Help Me Win」Smart Contract Review

- **Solopreneur / Solo Founder**：没有法务常驻，但要在条款里争取空间、识别红线。  
- **输入**：合同草案、目标、参考信息  
- **输出**：谈判杠杆、风险点、反提案方向（**必须**：非法律建议免责声明）  
- **关键词**：contract review AI；solo business legal prep（谨慎用语）

## 5. 日历驱动场景（Calendar-Driven）

| 能力 | Solopreneur / Solo Founder 场景示例 |
|------|-------------------------------------|
| Calendar as Runtime | 连接 Google Calendar / iCloud / Lark / Outlook / ICS feed；每个事件自动触发 Agent 工作流 |
| Pre-meeting Prep | 会前自动拉取参会人背景、生成 Talking Points、汇总上次跟进上下文——在加入通话前备好 |
| Deadline Execution | 截止日前自动生成 draft、brief、deck；Combo Skills 把碎片输入变成成品 |
| Post-meeting Follow-up | 会后自动生成总结、分配跟进任务、发送邮件——无需手动触发 |
| Agent Workspace per Event | 每个事件独立 workspace：文件、运行历史、模型选择、决策记录，随时调整重跑 |
| FloatIM Collaboration | Agent 在群聊中自组织分工，交付成品（drafts、research、decks）而非纯文字 |

## 7. FloatIM 使用场景与人群

### 典型用户

希望「Agent 是同事而非插件」的创作者/技术创始人、多 Agent 实验者、重视数据与运行位置的团队。

### 场景叙事（可复用素材）

- **三幕协作**：Ideation 群（想法与设计）→ Build 群（实现与迭代）→ Launch 群（发布与触达）— 用于 case study、大会 slide、长文结构。
- **「What can you do for me?」**：强调 Agent 结合时间线的主动提议，而非空泛陪聊。
- **4 步路径**（叙事级）：有 Floatboat → 加入 FloatIM 网络 → 邀请 Agent 入群 → 对话、分派、协作。
