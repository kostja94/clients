## 1. Floatboat 产品事实

**One-line（Meta/PR）**：
> Floatboat is the proactive agent OS where your calendar becomes the runtime — agents prep before meetings, execute on deadlines, and follow up after, automatically. Works with Google Calendar, Notion Calendar, Lark, Outlook, iCloud, or any ICS feed.

### Calendar-Driven 四步机制

| 步骤 | 一句话 | 创作要点 |
|------|--------|---------|
| Calendar as Runtime | 日历是 Agent 时钟，事件即触发器 | vs「导入联系人列表」式日历 |
| Reads the Rhythm | 会议/截止日/例行任务分类匹配准备类型 | 无需手动配 workflow |
| Agents Prep & Execute | 会前 brief、截止日前 draft、会后 follow-up | Combo Skills；~10 min/run |
| Agent Workspace per Event | 每事件独立持久 workspace | 多模型切换、重跑不丢上下文 |

### 产品支柱

- **All Frontier Models, Zero Setup**：DeepSeek, MiniMax, GLM, Kimi, GPT-5, Claude, Gemini 内置，免 API Key
- **Combo Skills**：预置配方；日历事件/拖放/定时触发
- **FloatIM**：Agent-native 群聊；im.floatboat.ai；与 Floatboat「两 App 同一网络」

**集成**：3500+ 工具；MCP + IACT 原生协议；Mac + Windows。

**Demo**：[Floatboat Demo](https://www.youtube.com/watch?v=SWMIbUBfhJY)

## 2. Calendar-Driven vs Chat-Based（对比叙事轴）

| 维度 | Calendar-Driven | Chat-Based |
|------|----------------|------------|
| 触发 | 日历事件 | 用户 prompt |
| 主动性 | 系统 push | 用户 pull |
| 上下文 | 事件 workspace 持久 | 多 session 重置 |
| 典型工具 | Floatboat | ChatGPT, Claude, Gemini |

**写作句**：*Work isn't a chat thread — it's a schedule.*

## 3. 竞品速览

| 产品 | 定位 | 写作时必须承认的优势 |
|------|------|---------------------|
| **Calendly / Doodle** | Gen 1 智能 schedulers | 极简预约链接；低学习成本 |
| **Motion / Reclaim / Clockwise** | Gen 2 AI optimizers | 团队时间优化；任务重排 |
| **Fireflies / Otter / Fathom** | AI note-takers | 会议中转录；成熟生态 |
| **ChatGPT / Claude / Gemini** | Chat-Based | 灵活探索；对话深度 |
| **Claude Cowork** | 桌面 Agent | Anthropic 生态；文件自动化叙事 |
| **Manus / Accomplish / Eigent** | 通用/desktop Agent | 各官网为准，需引来源 |
| **Slock** | 频道型多 Agent + 本机 | 团队 IM 内协作；跨 session 记忆 |
| **Kollab** | 团队 AI 工作区 | 组织知识+IM；Skills 存 GitHub |

**对比维度表**（Comparison/Alternative 文可用）：触发模型 · 日历接入 · 形态 · 协作模型 · 模型内置 · 本地文件 · 技能复用 · 集成 · 平台 · 定价 · 隐私
