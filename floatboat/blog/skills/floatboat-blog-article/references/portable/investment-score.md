# Investment Score（Phase 0）

> 与 `01-intake` §三、`00-content-strategy` 一致。随 skill 分发。

---

## 五因子（各 1–5，算术平均）

| 因子 | 1 分 | 5 分 |
|------|------|------|
| 搜索需求 | 几乎无搜索量 | 稳定/上升需求 |
| 商业相关性 | 与 ICP 无关 | 靠近购买/使用路径 |
| 差异化能力 | 只能复述 SERP | 有 Moat / Proof |
| 证据可得性 | 无法验证 claim | Proof Library / R3 可支撑 |
| 内容生命周期 | <3 月过时 | 2+ 年常青 |

## 动作

| 均分 | 动作 |
|------|------|
| ≥4.0 | KEEP，按 Mode 执行 |
| 3.0–3.9 | 降级 Mode 或改角度 |
| <3.0 | MERGE / STOP / 降级 FAQ·docs |
