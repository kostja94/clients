# FloatBoat SEO 周报

本目录存放 SEO 周报 **生成 Skill**（v3.1.0 自包含）与 **历史报告**。

| 文件 | 用途 |
|------|------|
| [floatboat-seo-weekly-report-skill.md](./floatboat-seo-weekly-report-skill.md) | **唯一 Skill 文件**（v3.1.0）— 自包含所有分析规则、输出模板、数据提交规范 |
| `floatboat-seo-weekly-report-YYYY-MM-DD.md` | 各周历史报告（日期 = 报告周结束日） |

## 每周最小数据包

按 Skill §0 准备：

1. GSC Compare xlsx（P0 必填，Queries/Pages/Countries/Devices，7 天 vs 7 天）
2. 项目执行 `===CONTENT===` 等（P0 必填）
3. GA4 BigQuery 导出或 UI 导出（P1 推荐）
4. 上周报告 md（P1 推荐）
5. Bing CSV（P2 可选）

## 使用方式

将 Skill 全文 + 数据包 + 上周报告提交给 AI，指令：**"按本 Skill 生成本周 FloatBoat SEO 周报"**。
