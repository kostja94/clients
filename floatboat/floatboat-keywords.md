## 1. 关键词梯队

### 1.1 第一梯队 — 必须主打（高搜索量 + 高匹配）

| 关键词 / 短语 | 含义与背景 | 与 Floatboat 的匹配 |
|----------------|------------|---------------------|
| **Proactive AI Agent** / **Proactive Agent OS** | 2026 年新兴品类热词；主动式 Agent vs 被动式 Chat | 官方定位 *The Proactive Agent OS that Runs Work from the Calendar* |
| **Calendar-Driven AI** / **Calendar AI Agent** | Calendar 是核心差异化——不是日程工具，是 Agent 运行时 | 官网核心叙事：日历触发 vs 聊天触发 |
| **Agentic Calendar** | 品类定义词，竞争相对空白 | 日历即 Agent OS，非传统日程管理 |
| **Claude Cowork alternative** | 高商业意图长尾；桌面 Agent 赛道核心截流词 | 对比页（Calendar-Driven vs Chat-Based） |
| **AI agent for solopreneurs** | 中高意图、竞争相对可控 | 与官方定位一致（solopreneur 而非 OPC） |
| **chat AI alternative** / **ChatGPT alternative for work** | 对比类高意图长尾 | Calendar-Driven 叙事直接对标 chat AI 的被动性 |

## 6. 姊妹产品 FloatIM（独立词表）

**FloatIM** 不以 solopreneur 桌面工作区为主词，而以 **agent-native IM / multi-agent group chat / chat with AI agents** 等为第一梯队。

| 梯队 | 意图母题 | 用途 |
|------|----------|------|
| **P0** | AI agent chat，chat with AI agents，multi-agent collaboration，agent-native messaging，agent-first messenger | 主品类、教育市场 |
| **P1** | AI group chat，human–agent collaboration，Slack/Discord for AI agents（类比，防商标） | 高意图与类比检索 |
| **P2** | A2A，agent-to-agent，multi-agent orchestration，本机/自托管 Agent 网络，open agent protocol | 技术受众与协议向内容 |

**长尾语料**（可化入帮助中心、长文、社媒）：*agent-native instant messaging*；*chat with multiple AI agents*；*run AI agents on your own computer*；*IM for agents and humans*；*agent IM* / *AI IM* 等。

避免在 Floatboat 首页 Title 中堆砌 FloatIM 词，以免稀释主站品类。FloatIM 相关词在 FloatIM 专属载体上展开。
