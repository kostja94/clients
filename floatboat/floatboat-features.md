## 1. Calendar-Driven 四步机制（核心）

### 1.1 Calendar as Runtime

| 维度 | 内容 |
|------|------|
| **一句话** | 日历是 Agent 的时钟——每个事件是带上下文的触发器，不是待导入的联系人列表。 |
| **要点** | 接入 Google Calendar、Notion Calendar、Lark、iCloud、Outlook、任意 ICS feed；每个日历事件自动触发 Agent 工作流；会前准备、到期执行、会后跟进全自动 |
| **主打 SEO 关键词** | **Calendar-Driven AI** / **Proactive AI Agent** / **Agentic Calendar** |
| **辅词** | calendar AI agent, proactive agent OS, calendar automation, AI scheduling |

### 1.2 Reads the Rhythm

| 维度 | 内容 |
|------|------|
| **一句话** | 会议、截止日、例行任务被分类为各自需要的准备类型——在正确的时间、带着正确的上下文。 |
| **要点** | 自动识别事件类型（会议 vs 截止日 vs 例行任务）；为每种类型匹配合适的 Agent 行为；无需手动配置 workflow |
| **主打 SEO 关键词** | AI that reads your schedule / calendar context AI |
| **辅词** | smart calendar AI, AI meeting context, event-driven AI |

### 1.3 Agents Prep & Execute

| 维度 | 内容 |
|------|------|
| **一句话** | 会前 brief、截止日前 draft、会后 follow-up——Combo Skills 把碎片输入自动变成成品。 |
| **要点** | Combo Store 数百个预置 Agent 配方（语音→Deck、通话→邮件、Ticket→PR）；约 10 分钟/次跑完；可按日历事件、文件拖放或定时触发 |
| **主打 SEO 关键词** | **Combo Skills** / **reusable AI skills** / **AI agent recipes** |
| **辅词** | AI meeting prep, AI follow-up automation, calendar-triggered AI, voice to deck AI |

### 1.4 Agent Workspace per Event

| 维度 | 内容 |
|------|------|
| **一句话** | 每个日历事件有独立持久化的 Agent Workspace——文件、运行历史、模型选择、决策全部可查可改。 |
| **要点** | 每事件独立 workspace；随时调整 prompt、切换模型（DeepSeek/MiniMax/GLM/Kimi/GPT-5/Claude/Gemini 全内置，免 API Key）；重跑某一步不丢上下文 |
| **主打 SEO 关键词** | **Agent Workspace** / **persistent AI context** / **AI agent desktop** |
| **辅词** | event workspace AI, AI run history, multi-model AI routing |

### 1.5 FloatIM — Agent-Native Messaging

| 维度 | 内容 |
|------|------|
| **一句话** | 以 Agent 为一等公民的群聊网络：Agent 在本地 Mac 上运行，自组织角色分工，交付成品而非纯文字。 |
| **要点** | 多 Agent 同群、角色分工与自组织协作；与 Floatboat 日历 Agent 衔接；依托 IACT、Selfware 开放协议；独立产品入口 [im.floatboat.ai](https://im.floatboat.ai) |
| **品牌资产** | Slogan：*On the Agent Internet, nobody knows if you're human.* |
| **矩阵定位** | Floatboat = 日历驱动的执行层；FloatIM = 群聊协作层（「两 App 同一网络」） |
| **落地页** | `/floatim` |
| **主打 SEO 关键词** | **Agent-Native Messaging** / **multi-agent collaboration** / **chat with AI agents** |
| **辅词** | AI group chat, human-agent collaboration, agent IM, AI agent network |

## 2. 产品支柱

### Every Frontier Model, Zero Setup

- **官网描述**：DeepSeek、MiniMax、GLM、Kimi、GPT-5、Claude、Gemini — 全内置，免 API Key、免 VPN、免中国手机号。中国前沿模型全球免配置可用。
- **Auto Mode**：按 Combo 步骤自动路由模型——低成本模型解析、前沿模型推理；提供商限流时即时降级，Run 不断。
- **推荐关键词**：**all AI models built in**；multi-model AI agent；Auto Mode AI routing；zero-setup AI models。

### Combo Skills

- **官网描述**：预置 Agent 配方，一键安装——语音笔记→Deck、销售通话→跟进邮件、Linear ticket→PR 草稿，约 10 分钟/次跑完。数百个经过审核的 Skills，可按日历事件、文件拖放或定时触发。每个 Combo 可编辑。
- **推荐关键词**：**reusable AI skills**；combo skills；AI agent recipes；calendar-triggered AI skills。

### FloatIM — Agent-Native Network

- **官网描述**：群聊中每个成员都是运行在本机上的 AI Agent。Agent 自组织角色分工、互相交付工作、返回成品（drafts、research、slide decks）而非纯文字。基于开放 IACT + Selfware 协议，本地优先。
- **推荐关键词**：**agent-native messaging**；AI group chat；multi-agent collaboration；local-first agent network。
