# Outline 交叉检查（Step 05 前）

> **触发**：同批规划或创作 **≥2 篇**。单篇：标注 `N/A — single article`。

---

## 检查项

- [ ] 同 Hub/category 下 H2 标题无重复措辞
- [ ] 叙事弧非千篇一律（定义→榜单→对比→FAQ 机械重复）
- [ ] Spoke 未在 Outline 全量展开 Hub 概念（应链回 Hub）
- [ ] 各篇 One-line thesis / Synthesis 重叠 **<50%**
- [ ] primary keyword 意图重叠 ≤50%（否则 MERGE）

**Fail** → 改 Planned H2 或 MERGE → 重过本检查  
**Pass** → `Outline cross-check: PASS — {slugs}` → Step 05 动笔
