## 平面设计手法（空间 · 层次）

SSOT 见 KB **§平面设计手法**：

| 手法 | 效果 |
|------|------|
| **置换扭曲** | 突破平面界限 |
| **汉字拆解重构** | 笔画层叠 → 立体感（字稿宜后制） |
| **环面 + 高斯模糊** | 杂乱环景深 → 空间纵深 |
| **图文穿插叠压** | 打破分区 → 层次感 |
| **标题角度透视** | 普通标题加透视 → 冲击力 |

```
… scattered torus rings, gaussian blur background, sharp foreground ring, perspective headline 20deg …
```

```
… displacement warp breaking paper plane, interleaved text over image crop, single accent …
```

## 配色（色轮 · 命名色）

SSOT 见 KB **§配色 · 色轮与命名色**：

| 色名 | 用途提示 |
|------|----------|
| **提香红** Titian red | 暖红 accent；人文/档案 stamp |
| **马尔斯绿** Mars green | 低饱和矿物绿；标本/编号 |
| **克莱因蓝** IKB | 高饱和纯蓝块；画廊/极简 |

**规则**：同一 zine hero **只选一个** high-chroma accent。Prompt 示例：

```
… warm cream paper, single International Klein Blue matte rectangle, 85% negative space, no gradient …
```

```
… aged paper, small Mars green archival label, typewriter caption, no neon …
```
