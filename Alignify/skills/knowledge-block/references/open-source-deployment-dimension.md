> **CMS 专册**：[`open-source-cms.md`](../../../knowledge/tools/cms/open-source-cms.md) — OSS CMS **有独立检索资源**，单独知识块；本文 **不替代** 该专册

## 两层结构

| 层 | 是什么 | 例子 |
|----|--------|------|
| **跨品类维度** | Open Source 对 API、IDE、Agent、CMS… **通用** | 每个 KB 产品表加 License 列 |
| **CMS 专册 KB** | `open source CMS` 有 **SERP + GitHub + 官方文档簇** | [`open-source-cms`](../../../knowledge/tools/cms/open-source-cms.md) |

其他品类（如 `open source AI IDE`）**不必**各建 slug，除非未来出现 **同等资源密度** 的检索簇。

## 商业化产品 ↔ 开源 · 六种关系（2026-08-28）

| 模式 | CMS 例证 | 写在哪 |
|------|----------|--------|
| **OSS + 托管云** | Strapi CE + Cloud | `open-source-cms` 产品表 |
| **Open core** | Strapi 企业功能 | `open-source-cms` + FAQ |
| **分层栈** | Sanity Studio / Content Lake | `open-source-cms` §半开源 |
| **纯 SaaS + 别厂 OSS 替代** | Contentful ↔ Strapi | `open-source-cms` FAQ |
| **基金会 + 商业品牌** | WP.org / WP.com | 跨链，无品牌 slug |
| **Source-available** | Directus 2026 | License 行精确写法 |
