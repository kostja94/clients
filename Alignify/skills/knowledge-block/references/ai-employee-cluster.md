## 三分法（对外口径）

| slug | 优化什么 | 一句话 |
|------|----------|--------|
| **`work-agent`** | **这一次活干完没有** | 委派 → **交付物**（deck、报告、文件夹） |
| **`workspace-agent`** | **这一类流程能不能规模化** | 建 playbook → RBAC / API / 审计 |
| **`ai-employee`** | **Agent 在 IM 里像不像真同事** | Slack/Teams/企微 → @ 委派 → thread 交活 |
