# R1–R7 违规 → 修复动作

| 规则 | 违规 | 修复 |
|------|------|------|
| R1 | distinct < 5 | 从附录 B 补邻居至 ≥5；优先 TLDR/什么是/场景 |
| R2 | 密度窗口 >3 链 | 分散到远端区块或删弱相关链 |
| R3 | tools 链占比过高 | 加 1 条跨板块（marketing/productivity 等） |
| R4 | 重复 slug | 删重复；FAQ 与正文 slug 不可重复 |
| R5 | 锚文本不描述 | 改用 keywords 表 keywordEn/Zh |
| R6 | 锚过短 / 禁词 | 扩写锚文本；换描述式短语 |
| R7 | FAQ >3 slug | 删最弱 FAQ 链或移到正文 |
| R7 | 单答 >2 链 | 拆答或减链 |
| R7 | FAQ 与正文 slug 重叠 | 从 FAQ 移除，换未用邻居 |
