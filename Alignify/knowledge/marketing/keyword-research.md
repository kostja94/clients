**词汇锚点**

- **Keyword Research（关键词研究）**：系统性发现用户搜索词、问题与话题，并评估其商业与内容价值；是 SEO、SEM 与内容选题的共同起点。
- **Search intent（搜索意图）**：Informational / Navigational / Commercial / Transactional 等分类；决定页面类型与 CTA，而非仅决定关键词列表。
- **Seed keyword（种子词）**：从业务、用户访谈或品类常识出发的初始词集；需经工具扩展与 SERP 验证。
- **Long-tail keyword（长尾词）**：低竞争、高具体度的词组；常成 AI/SaaS 早期内容的突破口。
- **Topical Map（主题地图）**：以 Hub 支柱页 + Spoke 集群页组织同一主题域的内容网络；强调覆盖度与内链，而非单页堆砌。
- **People Also Ask（PAA）**：SERP 中的相关问题模块；揭示用户追问链与 FAQ 选题。
- **Keyword difficulty（KD）**：工具估计的排名难度；需结合域名权威与 SERP 玩家类型解读。
- **SERP features**：精选摘要、AI Overview、视频轮播、本地包等；影响点击与内容格式选择。

**问题域（为何会出现这类产品/方法论）**

- **需求不透明**：创始人假设的用户语汇与 GSC/工具中的真实 query 常错位；需数据化校准。
- **竞争与机会并存**：头部词被评测站、目录与 incumbents 占据；长尾与问题型词是 indie/SaaS 现实入口。
- **内容 ROI 压力**：无选词纪律会导致「写很多、排很少」；Topical Map 把投入绑到可验证的搜索需求。
- **意图误判**：把 commercial 词做成纯教程、或把 informational 词硬塞 pricing CTA，均损害转化与排名。
- **AI 搜索扰动**：同一主题需在经典 SERP 与生成式答案中双重可见；选词需纳入「可被引用的问题句式」。

---

**能力栈（概念拆分，非厂商功能表）**

- **受众与主题框定**：ICP、Jobs-to-be-done、产品边界 → 种子词与禁止词清单。
- **多源扩展**：SEO 工具、GSC、PAA、Reddit/X/社区、Sales 录音、竞品博客逆向。
- **意图标注与聚类**：modifier（best / vs / alternative / how to）+ SERP 类型交叉验证。
- **优先级评分**：搜索量、难度、商业接近度、现有排名基础、内容生产成本。
- **Topical Map 设计**：Hub 定义、Spoke 清单、内链规则、更新节奏。
- **竞品逆向衔接**：2–3 个 SERP 竞品的 Top pages 与 gap 词进入路线图（见 competitive-analysis）。
- **测量闭环**：发布后 GSC 查询、排名、转化；季度 prune 低表现集群。

---

**形态谱系（与具体品牌解耦）**

- **工具驱动型**：Ahrefs / Semrush / Moz 关键词魔术棒 + gap 报告——偏可执行词表。
- **SERP 手工型**：逐 query 看前 10 结果页面模板——偏意图与格式判断。
- **用户洞察型**：访谈 + 支持工单 + 社区监听——偏未索引需求与用语。
- **集群架构型**：Hub-Spoke / Topic cluster——偏站点 IA 与内链。
- **持续运营型**：GSC + 排名追踪 + 内容刷新队列——偏迭代而非一次性项目。

---

**风险 · 合规 · 边界**

- **工具数据误差**：搜索量为估计；不同工具差异大；重大决策需 GSC 实数交叉。
- **关键词堆砌**：为密度牺牲可读性；现代算法与 AI 摘要均惩罚低质堆砌。
- **忽视 SERP 现实**：高难度词若 SERP 全是 UGC/媒体/目录，新域短期难进——需调整预期或换长尾。
- **翻译式国际化**：把英文词直译当地语常错失真实 query；各语言市场应独立选词（见 localization-strategy）。
- **版权与 scraping**：批量抓取 SERP/竞品正文可能违反 ToS；优先合规 API 与手工采样。

---

**落地碎片（无先后）**

- 先 **用户视角** 列 20–30 个「他们会搜什么」，再开工具扩展。
- 每个核心主题画 **Topical Map**：1 Hub + 5–15 Spoke 再动笔。
- **PAA 与 Related searches** 是 FAQ 与 H2 的低成本来源。
- 选词时打开 SERP：若前 10 全是 listicle，你的页面也需提供对比/列表结构。
- **2–3 个竞品** 博客 + 帮助中心逆向，差距词进 backlog（链 competitive-analysis 深度流程）。
- 新站优先 **长尾 + 问题型**；品牌词与品类大词作长期 Hub 目标。
- 每季度用 GSC **查询报告** 刷新词表：已排名 4–15 位的词优先优化。

### 对比与测评（第三方；观点非官方）

社区对 **「高搜索量优先」vs「低竞争长尾优先」** 的分歧在于：前者流量天花板高但新域难兑现，后者更快获得 GSC 信号但单页上限低。对 **工具搜索量**，一方认为足够排期，另一方强调用 GSC 与手工 SERP 校准。综合意图标注、SERP 模板与 2–3 个工具交叉比读较稳。

*本小节为网摘与社区观点综合，非 Alignify 实测。*
