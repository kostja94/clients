## 词汇锚点

- **AI Presentation Maker**：主题/大纲/文档→每页内容+版式+配图→可编辑导出——区别于 PowerPoint 空白页起步。
- **Smart Slides**：内容量变化时版式自适应——Beautiful.ai 最早产品化。
- **AI Agent 模式编辑**：自然语言全局修改整份 deck——Gamma Agent（2025-09）代表；可 web 搜索补数据。
- **Multi-Agent AI Engine**：内容架构/视觉/数据 viz 分工——Pi 代表（10-15 秒生成）。
- **Brand Kit**：Logo/色彩/字体约束全公司演示一致——Beautiful.ai Team。
- **PPTX 导出保真度**：Web 原生工具常 10-20% 损失；Beautiful.ai PPTX 为图像化——视觉准但不可在 PPT 内编辑。
- **AI Data Visualization**：CSV→图表嵌入——Visme、Beautiful.ai 瀑布图等。
- **Interactive Sales Deck**：滚屏+CRM 个性化+观看分析——Storydoc。

## 专题对照 / 扩展定义

**三类路线**（术语见 §词汇锚点；下表只列交付与导出差）

| 维度 | **Web 原生（Gamma/Pi）** | **PPTX 原生（Plus AI/Copilot）** | **设计驱动（Beautiful.ai/Canva）** |
|------|-------------------------|----------------------------------|-------------------------------------|
| **载体** | web 链接分享 | 标准 PPTX | Smart Slides+Brand Kit |
| **PPTX 导出** | 中（~80-90%） | 高（原生） | 中–高（Beautiful 图像化） |
| **AI 写作深度** | 深 | 中 | 浅–中 |
| **离线** | 否 | 可 | Canva 部分可 |

## 问题域

- **做 PPT 是普遍厌恶任务**——3-8 小时多在排版非内容；AI 压缩「设计时间」。
- **空白幻灯片心理阻力最大**——AI 提供可编辑初稿。
- **非设计师演示质量鸿沟**——AI 排版保底专业门槛。
- **企业品牌一致性规模化**——Brand Kit 技术锁定规范。
- **市场**：2025 ~$1.94B，2029 ~$4.79B；Gamma ~$102M ARR、$2.1B 估值（a16z B 轮）。

---

## 能力栈

- **内容生成层**：LLM 结构化长文+信息层级（Pi 多 Agent 最先进）
- **版式排版层**：Smart Slides 等自适应
- **视觉风格层**：配色、字体、背景统一
- **图表与数据层**：Visme、Beautiful.ai
- **导出兼容层**：PPTX/PDF/Google Slides 保真度因工具而异
- **交互与分析层（2026）**：分享链接+观看分析——Gamma、Storydoc

## 风险 · 合规 · 内容与品牌治理

- **AI 内容准确性**——面向客户/高层须人工核查事实；Copilot 有幻觉风险报道。
- **PPTX 导出隐性成本**——最终交付必须是 PPTX 时选型首要测导出。
- **云端敏感信息泄露**——Beautiful.ai SOC 2 Type II 为企业采购最低门槛。
- **Tome 警示**：2025-03 停止演示产品——勿纳入 2026 新采购评估。
- **品牌 drift**——须 Brand Kit + 人工审查。

## 落地碎片（无先后）

- 选型前做「导出测试」——最复杂一页生成→导出 PPTX→查保真度。
- Web 分享为主 → Gamma 或 Pi；必须可编辑 PPTX → Plus AI 或 Copilot。
- Tome 已退出——迁移 Gamma/Pi。
- 团队协作 → Beautiful.ai Team 或 Pitch Plus。
- 已订 Microsoft 365 → Copilot 集成最高但设计最弱。
- 融资/销售 → Storydoc 交互式+CRM。
- 预算有限 → Slidesgo AI $4.99 或 Pi Free；PowerPresent 买断 $39.99。
- 中文：Pi/Gamma 持续改善但排版仍逊英文——AI 初稿+人工精调。
