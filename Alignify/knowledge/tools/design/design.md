## 词汇锚点

- **AI Design Tool（上位概念）**：LLM/生成式 AI 辅助产品设计全流程总称——五子品类各有独立产品集与搜索意图（展开见各 spoke §词汇锚点）。
- **Vibe Design**：与 Vibe Coding 平行——自然语言描述设计效果，AI 生成 UI（详见 [ui-design.md](ui-design.md)）。
- **Connected Canvas**：画布经 MCP 等与开发环境实时连接（详见 [ui-design.md](ui-design.md)）。
- **Design Fidelity Spectrum**：Wireframe→Mockup→Prototype 三阶递进；UX Design 横跨光谱（IA/流程→系统治理→无障碍）。跳过线框直接高保真是常见错误，AI 秒出高保真正在挑战该原则。
- **与相邻品类**：输出设计稿/组件，非后端/部署 → [`app-builder`](../coding/app-builder.md)；用户访谈/合成用户 → [`user-research`](user-research.md)；与 [`vibe-coding`](../coding/vibe-coding.md) 有重叠区但买家角色不同。

## 问题域（Hub 级；细节见各 spoke）

- **设计效率物理上限**：想法→可见设计时延从数天压缩至数分钟。
- **设计系统维护成本**：tokens/组件跨平台同步——AI 治理从加分变必需。
- **设计-开发交接摩擦**：Connected Canvas/MCP 将单向交接变双向同步。
- **非设计师需求爆发**：Vibe Design 降低出图门槛，「出好图」仍要设计素养。
- **无障碍合规硬性要求**：EAA 2025（2025-06 生效）——检查从差异化变准入门槛（工具见 [ux-design.md](ux-design.md)）。

## 风险 · 合规 · 治理（Hub 级摘要）

- **EAA 2025 / WCAG**：AI 生成稿不自动合规——详见 [ux-design.md](ux-design.md) §风险。
- **设计系统锁定**：导出 fidelity loss——选型前验证。
- **版权与训练数据**：生成结果衍生作品法域不一。
- **品牌一致性**：须叠加设计系统校验层。

## 落地碎片（无先后）

- 先定保真度：结构 → wireframing；视觉 → UI design；交互 → prototyping；治理 → UX design；用户声音 → user-research。
- 企业选型优先**设计系统感知**——决定 demo→生产距离。
- POC 用最复杂 3 页（表单、表格、响应式）——非 demo 首页。
- 欧洲市场：**无障碍**为硬性门槛。
