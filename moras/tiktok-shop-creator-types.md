## 0. 先分清：平台身份 ≠ 业务叫法

讨论「TT Shop 红人」时，行业常把几套分类混在一起：

| 分层 | 问的是什么 | 例子 |
|------|------------|------|
| **A. 平台账号身份** | 账号在 Shop 后台是什么类型 | Official / Marketing / Affiliate |
| **B. 合作关系** | 品牌怎么付钱、管多久 | 纯佣联盟 / 大使 / 单次付费 / UGC 交片 |
| **C. 内容形态** | 主要靠短视频还是直播 | Short-form / Live Host / 双栖 |
| **D. 体量与组织** | 粉丝层级、是否签约 MCN | Nano–Mega；独立 vs Agency |

**平台官方只定义 A 层的 3 种身份**（见下节）。B/C/D 是运营与选人维度，不是新的「账号类型」。

业界榜单里常说的两句：

- **Top Brand-Creator Accounts（品牌自营达人）** ≈ Official + Marketing（卖自家货）
- **Top Affiliate Creators（第三方带货达人）** ≈ Affiliate（帮多品牌卖、拿佣金）

## 1. 平台账号身份（只有这 3 种）

信源：[Creator Eligibility Policy](https://seller-us.tiktok.com/university/essay?knowledge_id=6939143037667118&lang=en) · [What You Need to Know Before Becoming a TikTok Shop Creator](https://seller-us.tiktok.com/university/essay?knowledge_id=7608640301074219&lang=en) · [Official Account Rights](https://seller-us.tiktok.com/university/essay?knowledge_id=6837877346993921)

### 1.1 Official Shop Creator（官方店账号）

| 项 | 说明 |
|----|------|
| 绑定 | 与卖家店铺做 **official creator bind** |
| 命名 | 账号名须与店铺名一致；一店仅 1 个官方号 |
| 能卖什么 | **仅绑定店铺的商品**；**不能**进 Affiliate Product Marketplace |
| 粉丝门槛 | 绑定无最低粉丝要求（仍须过合规） |
| 资料页 | **Store Page**，商品可与 Seller Center 自动同步 |
| 赚钱方式 | 品牌/店铺利润（DTC），不是联盟佣金 |

### 1.2 Marketing Creator（营销 / 渠道号）

| 项 | 说明 |
|----|------|
| 绑定 | 与卖家店铺做 **marketing creator bind** |
| 命名 | 不必与店铺同名；一店最多约 **4** 个营销号 |
| 能卖什么 | 主卖绑定店商品；粉丝够（美区常见门槛约 **5,000**）可申请开联盟选品权限 |
| 粉丝门槛 | 自卖绑定无最低粉丝；进 Marketplace 另有门槛 |
| 资料页 | **Showcase**，商品需手动加入 |
| 典型用途 | 创始人号、垂类人设号、矩阵测号，仍归属品牌自营矩阵 |

### 1.3 Affiliate Creator（联盟达人）

| 项 | 说明 |
|----|------|
| 绑定 | **不绑店**；自申请进 Creator / Affiliate 体系 |
| 能卖什么 | TikTok Shop **Product Marketplace** 多品牌选品 |
| 粉丝门槛 | 美区常见约 **1,000+**（Pilot / 毕业规则会变，以当期为准） |
| 库存履约 | 不管货、不管售后 |
| 赚钱方式 | 按成交抽佣（类目常见约 **10%–25%**，定向可更高） |

### 1.4 对照表（身份层）

| | Official | Marketing | Affiliate |
|--|----------|-----------|-----------|
| 归属 | 品牌自营 | 品牌自营（可兼联盟） | 第三方 |
| 卖谁的货 | 只自家店 | 主自家，可开 Marketplace | 多品牌 |
| 收入 | 商品利润 | 利润为主，可加佣金 | 佣金 |
| 适合叙事 | 「品牌+达人合一 DTC」 | 矩阵 / 创始人号 | 「多品牌带货」 |

## 2. 合作关系类型（品牌侧怎么用达人）

同一 Affiliate 账号，可落入不同合作模型（[MomentIQ 等行业框架](https://bemomentiq.com/blog/tiktok-shop-ambassador-vs-affiliate-vs-one-time-influencer-which)）：

| 类型 | 关系长度 | 常见结算 | 品牌要什么 |
|------|----------|----------|------------|
| **Open Affiliate（公开联盟）** | 松散、可随时停 | 纯佣 | 内容量与发现 |
| **Target Collaboration（定向合作）** | 邀请制 | 佣金常更高 + 寄样 | 指定达人推指定 SKU |
| **Brand Ambassador（品牌大使）** | 约 3–12 个月 | 月费 + 佣金 + 寄样 | 信任、复购叙事、稳定出片 |
| **One-time Influencer（单次达人）** | 1–3 条 | 一口价（±佣金） | 上新 / 季节节点曝光 |
| **UGC Creator（素材创作者）** | 按条交付 | 按条付费 | 素材给官方号发 / Spark Ads；达人未必自有大粉 |

联盟协作入口（卖家侧）：

- **Open Collaboration**：商品对符合条件的达人开放，达人可主动挂链  
- **Target Collaboration**：品牌邀请指定达人（见 Seller Center Affiliate 文档）

## 4. 体量与组织形态（筛人维度）

### 4.1 粉丝层级（行业通称，区间略有出入）

| 层级 | 粉丝量级（常见说法） | TTS 侧常见用法 |
|------|----------------------|----------------|
| Nano | ~1K–10K | 高转化、低成本海量测 |
| Micro | ~10K–100K | 垂类信任 + 可规模化 |
| Mid | ~100K–500K | 品类头部 KOC |
| Macro | ~250K–1M | 品牌大使候选人 |
| Mega / Celebrity | 1M+ | 上新节点、品牌叙事 |

TikTok Shop 另有按 **GMV** 的 Creator Badge / Tier（Bronze→Diamond 等），与粉丝层级不是同一套，以 Creator Center 为准。

### 4.2 组织形态：独立达人 vs MCN / Agency

| 形态 | 说明 |
|------|------|
| **独立达人（Independent）** | 自己谈佣、选品、发片；佣金归个人 |
| **MCN / Creator Agency Partner（机构旗下达人）** | 签约机构：培训、选品、品牌对接、违规申诉、有时抽佣分成；**平台账号身份通常仍是 Affiliate** |

TikTok Shop Partner 侧常见名称：

- **MCN（Multi-Channel Network）**：孵化/管理达人，支持可购短视频、直播运营、达人–商品撮合等（[Partner Center — MCN](https://partner.tiktokshop.com/docv2/page/multi-channel-network-mcn)）
- **CAP（Creator Agency Partner）**：同类「达人机构伙伴」，帮创作者加速、对接卖家（[Become a CAP](https://business.tiktokshop.com/us/partner/creator-agency)）

行业口语里常把上述统称 **「TTS MCN / Agency」**——**不是第四种平台 Creator 身份**，而是「达人背后的组织」。

#### 真实机构例：The Fast Track Girl

[thefasttrackgirl.com](https://thefasttrackgirl.com/) · TikTok [@thefasttrackgirl](https://www.tiktok.com/@thefasttrackgirl)（创始人 Kierra）

| 点 | 说明 |
|----|------|
| 是什么 | TTS **联盟教育 + 社区（Clubhouse）+ Agency** 生态，非品牌方、非 Official 店铺 |
| 创始人 | Kierra：头部 Affiliate（自称 $5M+ 联盟 GMV），兼社区/机构主理人 |
| 提供什么 | 训练课、社群辅导、AI 工具 TESS、违规申诉等 Agency 服务；品牌可对接其 1,000+ affiliates |
| 与正式 Agency | 公开内容中曾提及合作/旗下 Agency 名如 **High Roller Media**（以当期披露为准） |
| 成员例 | **[@hannahbentley](https://www.tiktok.com/@hannahbentley)** 公开内容中与 Fast Track 强关联（「Fast Track Era」、社区/机构语境）——**她仍是 Affiliate 身份，只是挂在机构/社群体系下** |

**读法**：`@hannahbentley` ∈ Affiliate（平台身份）+ Fast Track 体系（组织形态）。  
≠ 变成 Brand-Creator；≠ 卖自己的品牌货。

#### 这类机构多吗？（2026 公开信息）

**多，但「Agency」一词混了三种生意**——检索榜单时务必先分清服务对象：

| 类型 | 服务谁 | 做什么 | 例子 |
|------|--------|--------|------|
| **A. 达人侧 MCN / CAP** | Affiliate 达人 | 签约/社群、培训、选品对接、违规申诉；常抽佣或收会费 | Fast Track / High Roller Media、部分 TAP |
| **B. 品牌侧 Affiliate Agency** | 卖家/品牌 | 代招达人、寄样、佣金策略、Open/Target、Shop Ads | Hamster Garage、MediaLabs、Trendio（SaaS+托管）、MuteSix、Ubiquitous 等 |
| **C. 教育/社群（Clubhouse）** | 想入门的达人 | 付费课 + Discord/社群；未必是官方 CAP | Fast Track Clubhouse、Creator Connections 等（Reddit 达人常提） |

公开信号（无官方「全美共有 N 家 MCN」精确总数）：

- TikTok 开放申请 **[Creator Agency Partner](https://business.tiktokshop.com/us/partner/creator-agency)**：有创作者网络的机构均可申请（美国公司注册、服务达人/商家经验、短视频或直播能力等）。说明平台侧在**主动扩机构供给**。
- 联盟体量：上线初期官方曾称约 **10 万+** creators 参与联盟；第三方（如 Hamster Garage 2026 文）称美区活跃联盟达人可达 **数十万级**，且联盟渠道可贡献平台很大一块 GMV——机构需求随之变大。
- 榜单生态：2026 年「Best TikTok Shop Agency」类文章普遍列出 **7–12 家**品牌侧机构（MediaLabs、Pattern、Social Shepherd、GrowMojo、AdQuadrant…），另有 **9+** 家「Affiliate Agency」专文（Hamster Garage、Trendio、Tinuiti…）——这是**可见头部**，长尾还有大量小 MCN/社群。
- 社区实况：[Reddit r/TikTokshop](https://www.reddit.com/r/TikTokshop/comments/1o67s9k/are_you_a_tiktok_shop_affiliate_and_who_is_your) 达人讨论里，常见建议是「先找 **community/course**」，并提醒：**收费加入的机构良莠不齐**；卖家侧则指向 Partner Center，但目录里大量是传统 influencer / 投流代理，**不等于**达人侧 MCN。

**对 Moras 的含义**：

- ICP「MCN / Agency」真实存在且供给不少，但采购方可能是 **管达人的机构**，也可能是 **帮品牌管联盟的代理**——话术要分开。
- Fast Track 这类 = **达人教育 + 社群 + Agency** 混合体，是 A+C，不是 `@based` 那种品牌自营。

数据与榜单工具（第三方，非 TikTok）：[Kalodata Creator](https://www.kalodata.com/creator)、Charm.io、Fastmoss 等——榜单常把 **品牌官方号** 与 **个人联盟号** 混排，解读时务必先区分身份。

## 5. 真实例子（便于对号）

> 数据来自公开报道/榜单工具，会随月份波动；**仅作类型示意，非 Moras 客户背书或效果承诺。**

### 例 A — 品牌自营达人（Brand-Creator / Official 向）

**[@based](https://www.tiktok.com/@based)** · **BASED Bodyworks**

| 点 | 事实 |
|----|------|
| 是谁 | 男士个护品牌官方 TikTok；创始人理发师 Lance Baker 另有个人号 |
| 卖什么 | **只卖自家 SKU**（发胶粉、洗护、眼霜等）；TikTok Shop 有品牌商品页 |
| 公开表现 | [WWD 2026-03](https://wwd.com/beauty-industry-news/beauty-features/based-bodyworks-tiktok-shop-viral-looksmaxxing-1238648316/)：Charm.io 显示 2026 年 2 月美区 TTS 美妆约 **$5M** GMV，当月美妆品牌约第 4；品牌号粉丝量级约数百万；全天直播带货常见 |
| 为何不算 Affiliate | 核心路径是 **品牌店利润 + 自播/自产内容**，不是「给别家挂链拿佣」 |
| Moras 叙事 | **「品牌 + 达人合一的 DTC」**——用 AI 把自家 SKU 批量生成可购短视频，补内容产能 |

同类对照：

- **[@maelyscosmetics](https://www.tiktok.com/@maelyscosmetics)**：品牌官方号自营内容 + 大规模 **Affiliate 计划**（公开激励活动）——说明一家品牌可同时跑「自营账号」与「第三方达人军」。

### 例 B — 第三方联盟达人（Affiliate），且挂机构

**[@hannahbentley](https://www.tiktok.com/@hannahbentley)** · 家居垂类 · 关联 [The Fast Track Girl](https://thefasttrackgirl.com/)

| 点 | 事实 |
|----|------|
| 平台身份 | **Affiliate Creator**（帮多品牌挂链拿佣） |
| 组织形态 | 公开内容中与 **Fast Track** 社区/Agency 强关联（非品牌自营号） |
| 是谁 | 个人创作者（bio 常见 Cozy Home Finds / TTS Home Creator） |
| 卖什么 | **多品牌**家居/软装等，走联盟挂链 |
| 公开表现 | 行业报道称其曾进入 TTS 创作者 GMV 榜前列（百万级月 GMV 量级；随月变化） |
| 与 @based 的差异 | 不拥有品牌库存；收入主靠 **佣金**；背后可有 MCN/社群支持，但**不是** Official/Marketing |
| Moras 叙事 | **选品 + 批量成片 + 多 SKU 测佣**；机构侧还可讲「多达人矩阵出片」 |

同类对照：

- **[@cakedfinds](https://www.tiktok.com/@cakedfinds)**：Kalodata / 社区讨论中的 **高 GMV 联盟达人**，典型第三方带货。
- **[@thefasttrackgirl](https://www.tiktok.com/@thefasttrackgirl)**：机构/教育主理人本人也是头部 Affiliate——「达人 + 做 MCN」可叠加。

### 例 C — 榜单混排陷阱（Kalodata 等）

[Kalodata Creator 美区榜](https://www.kalodata.com/creator) 公开列表可见 `@based`、`@hannahbentley`、`@cakedfinds`、`@crocsshop_us` 等并列——其中：

- `@based`、部分 `@*shop_us` → 更偏 **品牌自营 / 官方店**
- `@hannahbentley`、`@cakedfinds` → 更偏 **个人联盟**

**做 ICP 或案例页时：不要把 Brand-Creator 榜的人套进 Affiliate 故事，反之亦然。**

### 例 D — 合作关系叠加（同一品牌）

**MAËLYS**：官方号 `@maelyscosmetics` 做品牌内容；同时开 Affiliate Incentive（高佣 + 奖金池）拉第三方达人——  
→ 账号身份上既有 Brand-Creator，又有大量 Affiliate；业务上叠加 Open/Target/活动激励。

## 6. 一张总图：怎么选人、怎么讲 Moras

```text
平台身份
├── Official / Marketing  → 品牌自营达人  → 例：@based
└── Affiliate             → 第三方带货达人 → 例：@hannahbentley, @cakedfinds

合作关系（主要叠在 Affiliate / 部分 Marketing 上）
├── Open 纯佣
├── Target 定向
├── Ambassador 长期
├── One-time 付费
└── UGC 交片（素材归品牌发）

内容形态：短视频 | 直播 | 双栖
体量：Nano → Mega
组织：独立 Affiliate | MCN/Agency 旗下 Affiliate（例：Hannah × Fast Track）
```

### 与 Moras 产品叙事的映射

| ICP / 页面方向 | 典型身份 | 真实例子方向 | Moras 主打价值 |
|----------------|----------|--------------|----------------|
| TikTok Sellers / Brand DTC | Official / Marketing | `@based` | 自家 SKU → 多版本可购短视频 |
| Affiliates（独立或机构旗下） | Affiliate | `@hannahbentley`、`@cakedfinds` | 选品 + 批量挂链成片、测佣 |
| Creators / KOC | Affiliate 或 UGC | 小粉垂类、交片型 | 少实拍、日更产能 |
| MCN / Agency | 管理多 Affiliate | Fast Track、High Roller Media 类 | 规模化出片、分账号模板 |

## 7. 常见误解

1. **「Creator 榜 = 全是联盟达人」** — 否。榜上常有品牌官方号（如 `@based`）。  
2. **「有 Shop 挂车就是 Affiliate」** — 否。Official 也挂车，但是卖自家店。  
3. **「Marketing 号 = Affiliate」** — 否。Marketing 先绑自家店；开 Marketplace 才是「兼做联盟」。  
4. **「Ambassador 是第四种平台身份」** — 否。那是合同/合作模型。  
5. **「Seller 和 Creator 互斥」** — 品牌可同时有店铺 + Official/Marketing 号，再外挂 Affiliate 军。  
6. **「进了 MCN 就不是 Affiliate 了」** — 否。MCN/Agency 是组织层；账号在 Shop 后台多半仍是 Affiliate（例：Hannah × Fast Track）。  
7. **「Fast Track = 品牌方」** — 否。它是联盟教育/社群/机构，不是卖货品牌的 Official 店。
