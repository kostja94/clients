## 1. 产品边界（先定义 Moras 是什么）

- **不是** 通用长视频编剧工具为主，而是 **短内容 + 内容电商/带货** 全链路。  
- **强叙事**：**多代理 OS**、A2A、**飞轮**（发现→生产→数据→再发现），与单点「生成一条视频」工具区分。  
- **商业**：订阅 + **收入分成 / MCN 绑定** 等（视套餐），偏 **结果与规模化**，而非仅 SaaS 席位。

---

## 2. 直接 / 高重叠竞品（类别）

| 类型 | 代表方向 | 与 Moras 关系 |
|------|------------|----------------|
| **AI 短视频广告生成器** | 多 SKU 的模板化、商品链接进视频 | 功能重叠在「成片」；Moras 强调 **选品+编排代理+数据闭环** |
| **TikTok/电商向 AI 工具** | 各区域出现的 Shop 侧助手类 | 需按区域更新名单；比「是否含联盟分佣/托管档」 |
| **MCN 内部工具** | 自研或采购批量化工具 | Moras 部分套餐**面向 MCN 合作**（以官网为准） |

## 3. 间接竞品

| 类型 | 说明 |
|------|------|
| **传统 UGC 中介** | 人工寄样、排期、成本高；Moras 主打 **低样品依赖 + AI 规模化**（叙事侧） |
| **通用可剪映类 / 长剪** | 重剪辑界面；Moras 重 **从选品到发布的代理任务流**（若用户只要剪辑，可能不选 Moras） |
| **仅数据分析选品** | 不做成片；可与其 **组合** 或 **替代** 取决于用户是否要一站式 |

---

## 4. 差异化（对外话术草稿，需与法务核对）

- **Agent OS 叙事**：**Orchestrator + 多专精代理 + A2A**，对技术买家/投资人更清晰。  
- **Harness + Skills**（报道层）：**产业 know-how 原子化**，利于讲「可复现、可验证」的产出。  
- **商业捆绑**：**MCN / 高分成全托管** 档是差异化 SKU，也带来**渠道依赖**与**条款复杂度**（竞品对比时需透明）。
