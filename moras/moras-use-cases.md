## 1. 核心 ICP（归纳）

| 人群 | 特征 | 与 Moras 的契合点 |
|------|------|-------------------|
| **TikTok Shop 卖家/品牌（美区）** | 需持续短视频供给、测款压力大 | 链接→多素材、快测 hook |
| **联盟客 / 高佣带货达人** | 多商品、要产量与一致性 | 批量视频、分佣相关套餐（MCN 等，以实际条款为准） |
| **KOC/兼职创作者** | 时间少、不擅长拍摄 | 「无样品/少实拍」叙事实例在官网与报道中均出现 |
| **MCN / 机构** | 要规模化、账号矩阵 | 合作档、账户经理、分析（见官网定价区） |
| **Dropship / POD**等 | 多 SKU、快迭代 | App Store 描述中明确覆盖 |

## 2. 场景矩阵

| 场景 | 用户任务 | 内容/产品叙事角度 |
|------|----------|-------------------|
| **冷启动** | 无样片、新号 | 日更能力、从 0 到首单（Wall of Love 中「Day-1/Day-2 首单」类故事） |
| **扩量** | 同一品多视频 A/B | 多 hook、多模板、数据回流 |
| **选品** | 不知卖什么 | 趋势/数据驱动发现（与「预测爆款」类文案一致） |
| **托管/机构** | 要人盯盘 + AI | Managed / MCN 档（**分成与绑定条款** 需单页说清） |
