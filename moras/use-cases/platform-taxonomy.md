## 1. 平台账号身份

信源：[Creator Eligibility Policy](https://seller-us.tiktok.com/university/essay?knowledge_id=6939143037667118&lang=en) · [Before Becoming a Creator](https://seller-us.tiktok.com/university/essay?knowledge_id=7608640301074219&lang=en) · [Official Account Rights](https://seller-us.tiktok.com/university/essay?knowledge_id=6837877346993921)

### 1.1 Official Shop Creator

| 项 | 说明 |
|----|------|
| 绑定 | **official creator bind**；一店 1 个官方号；账号名须与店铺名一致 |
| 能卖什么 | **仅绑定店商品**；不能进 Affiliate Marketplace |
| 粉丝门槛 | 绑定无最低粉丝（须过合规） |
| 资料页 | **Store Page**；商品可与 Seller Center 同步 |
| 收入 | 店铺利润（DTC），非联盟佣金 |

### 1.2 Marketing Creator

| 项 | 说明 |
|----|------|
| 绑定 | **marketing creator bind**；一店最多约 **4** 个；不必与店同名 |
| 能卖什么 | 主卖绑定店；粉丝够（美区常见 **~5,000**）可申请 Marketplace 选品 |
| 资料页 | **Showcase**；商品手动加入 |
| 典型用途 | 创始人号、垂类矩阵测号 |

### 1.3 Affiliate Creator

| 项 | 说明 |
|----|------|
| 绑定 | **不绑店**；进 Creator / Affiliate 体系 |
| 能卖什么 | **Product Marketplace** 多品牌 |
| 粉丝门槛 | 美区 **≥1,000** 自助申请（2026-07-31 政策） |
| **Pilot**（&lt;5,000 粉） | 每天最多 **3** 条带货视频、每周 **3** 场带货 LIVE、不能参加 campaign；毕业：**5,000 粉 + 满 30 天** |
| 收入 | 成交抽佣（类目常见约 10%–25%） |
| 履约 | 不管货、不管售后 |

> **SSOT 注记**：站内 `blog/02-tiktok-shop-setup` 写标准路径 **5,000 粉**，与上表「1,000 申请 + Pilot」并存——对外以 Seller University 为准，blog 待对齐。

### 1.4 对照表

| | Official | Marketing | Affiliate |
|--|----------|-----------|-----------|
| 卖谁的货 | 只自家 | 主自家，可开 Marketplace | 多品牌 |
| 收入 | 商品利润 | 利润为主 + 可佣金 | 佣金 |
| Moras 常见 slug | `tiktok-sellers` | `tiktok-sellers` | `affiliates` + Layer B |

## 2. 合作关系（品牌侧选人 — 通常无独立 use-case 页）

[MomentIQ 等框架](https://bemomentiq.com/blog/tiktok-shop-ambassador-vs-affiliate-vs-one-time-influencer-which)：

| 类型 | 长度 | 结算 | 品牌要什么 |
|------|------|------|------------|
| Open Affiliate | 松散 | 纯佣 | 内容量与发现 |
| Target Collaboration | 邀请制 | 更高佣 + 寄样 | 指定 SKU |
| Brand Ambassador | 3–12 月 | 月费 + 佣 + 寄样 | 信任、稳定出片 |
| One-time Influencer | 1–3 条 | 一口价 | 节点曝光 |
| UGC Creator | 按条 | 按条付费 | 素材归品牌发；**未必自有大粉** |

卖家入口：**Open Collaboration** / **Target Collaboration**（Seller Center Affiliate 文档）。

UGC 交片者与 Shop Affiliate 可重叠也可不重叠 — Moras `creators` slug 覆盖交片场景，平台身份仍可能是 Affiliate 或纯 UGC 合同。

## 4. 体量与组织

### 4.1 粉丝层级（行业通称）

| 层级 | 量级 | 常见用法 |
|------|------|----------|
| Nano | ~1K–10K | 高转化、低成本测 |
| Micro | ~10K–100K | 垂类信任 |
| Mid–Mega | 100K+ | 品类头 / 品牌叙事 |

另有 **GMV Badge**（Bronze→Diamond），与粉丝层级不是同一套。

### 4.2 组织形态：独立 vs MCN / Agency

| 形态 | 说明 |
|------|------|
| 独立 Affiliate | 自谈佣、选品、发片 |
| MCN / CAP 旗下 | 平台身份**仍多为 Affiliate**；非第四种 Creator 身份 |

**Agency 一词混三种生意**（Moras `agencies` 页须分话术）：

| 类型 | 服务谁 | 例子 |
|------|--------|------|
| A. 达人侧 MCN/CAP | Affiliate | Fast Track、High Roller Media |
| B. 品牌侧联盟代理 | 卖家/品牌 | Hamster Garage、MediaLabs 类 |
| C. 教育/社群 | 入门达人 | 付费课 + Discord；未必官方 CAP |

**Fast Track Girl**（[@thefasttrackgirl](https://www.tiktok.com/@thefasttrackgirl)）：联盟教育 + 社群 + Agency；**不是**品牌 Official 店。成员例 [@hannahbentley](https://www.tiktok.com/@hannahbentley) 仍是 Affiliate + 机构体系。

榜单工具（Kalodata、Charm.io 等）常混排品牌号与个人联盟号 — 解读前先分 A 层身份。

## 7. 常见误解

1. Creator 榜 ≠ 全是联盟达人（常有 `@based` 类官方号）
2. 挂车 ≠ Affiliate（Official 也挂车，卖自家店）
3. Marketing ≠ Affiliate（先绑店；开 Marketplace 才是兼联盟）
4. Ambassador ≠ 第四种平台身份（是合同模型）
5. Seller 与 Creator 不互斥（店 + Official + Affiliate 军）
6. 进 MCN 仍是 Affiliate（组织层 ≠ 平台身份）
7. Fast Track ≠ 品牌方
8. 护士号 ≠ 必然职业权威（证货须对齐）
9. `affiliates` 页 ≠ 覆盖所有劳动模型（要 Layer B 子页）
