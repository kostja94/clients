### 4.5 内链原则

| 原则 | 说明 |
|------|------|
| **自然优先** | 只在读者需要下一步阅读时出现；语境不通则不加 |
| **不强求双向** | 入链为 0 的 spoke 仅在确有相关段落时补 1 条；不为凑图谱互链 |
| **禁 G6 路径** | 不链 `/use-cases/*` `/app/*` `/auth/*` `/admin/*` 及未上线页 |
| **Pillar 覆盖** | #01 须链向全部 Cluster A spoke（#02–#09）；缺 #07 则补 |
| **同 slug 上限** | 同篇链同一目标 slug 通常 ≤2 次；第 2 次仅在结论或最强语境处 |
| **禁链区域** | `## TL;DR` 与 `## Frequently asked questions` 内不加内链 |
| **跨簇桥接** | A→B 仅在话题自然交汇时（如 setup→2SV、诊断→SPS、客服→买家指南） |
| **锚文本** | 描述性短语；禁 "click here" / "learn more" / "this article" |

**当前入链薄弱、仅在有语境时补链**：#09 influencer-marketing（品牌/seller 决策）、#16 2SV（账号安全/setup）、#22 domestic-seller（US 实体注册）、#18 buyer guide（买家/support 流程）。
