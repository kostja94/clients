## 1. 价值主张（官网归纳）

- **两项核心能力**：① **AI 选品**（TikTok Shop 美区数据驱动选品/趋势发现）；② **TT 商品视频生成**（商品链接/卖点 → 自动生成可购短视频，批量/多版本）  
- **专注美区 TikTok Shop**：面向 TikTok Shop 美区卖家、联盟客、达人，不覆盖其他区域或平台  
- **增长飞轮**：选品洞察 → 成片 → 表现数据回灌选品策略，多轮迭代

## 2. 多代理与编排（公开展示层）

| 概念 | 说明（基于官网与报道用语） |
|------|-----------------------------|
| **Orchestrator** | 理解目标、分解任务、按阶段分发给合适代理。 |
| **多阶段 / 多代理** | 公开材料中曾出现 **11 个**专精代理、**3 个**阶段等说法；代理间通过 **A2A（Agent-to-Agent）** 协议传递上下文。 |
| **反馈闭环** | 分析/表现数据反馈至「发现」或策略层，每轮调优。 |
| **Harness + Agent Skills**（报道） | 将市场洞察、选品、卖点、分镜、剪辑、风控、发布等沉淀为可编排 **Skills**；意图解析、任务编排与执行验证。 |

*技术白盒细节以公司官方技术博客或文档为准。本文档不替代法务/合规承诺。*

## 3. 功能块（与官网/ App Store 对齐）

| 模块 | 能力摘要 | 说明 |
|------|-----------|------|
| **AI 选品** | TikTok Shop 美区实时/近实时市场数据，发现潜力商品与趋势 | 覆盖选品、趋势洞察、数据驱动决策，降低「拍脑袋」选品 |
| **TT 商品视频生成** | 商品链接或卖点 → 自动生成面向 TikTok 的竖屏可购短视频，支持批量/多版本 | 含脚本、视觉、字幕、口播等，侧重互动与转化结构 |

> 两项为核心功能。多代理编排（Orchestrator + A2A）为底层技术架构而非独立功能模块，技术细节见 §2。

## 4. 应用端（iOS 摘要，来自 App Store 列表）

- 一句话：面向 **TikTok Shop 卖家、联盟客、达人** 的 **AI 增长**；**无实拍/弱剪辑** 工作流。  
- 点列能力（列表转述，非承诺）：**爆款发现、链接→多视频、模板与 hook、口播/字幕/画面、数据追踪、批量生成** 等。  
- **Pro** 在商店描述中常对应更高限额、更多模板/优先级等（以订阅页为准）。
