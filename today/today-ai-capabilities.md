# Today AI — 能力（Capabilities）分析

---

## 1. Capabilities 官方文案核对（`/landing#capabilities`）

> **Built to actually work.** — Today 由严肃、持续的底层投入支撑：更好的模型、更强的任务执行、可靠的算力、更丰富的集成，以及在实际使用中持续改进的系统。

| 官方能力 | 官方文案要点 | 核对 |
|---------|-------------|------|
| **Frontier models** | 模型层持续优化，将前沿智能与每项任务的最佳匹配结合；含 **Harness Layer / Frontier Interaction Model / Today Bench** | ✅ 已覆盖 |
| **Powerful task execution** | 能规划工作、使用工具、检查进度、回报结果——请求变成完成的结果而非建议；含 Understand requests / Plan and use tools / Deliver results | ✅ 已覆盖 |
| **A growing connector ecosystem** | 连接日历、邮件、笔记、文件、消息、项目工具等，生活已运行的 app 与服务 | ✅ 已覆盖 |
| **Always-on cloud computers** | 云端稳定算力，随时开浏览器、处理文件、跑代码、持续处理任务；含 Operate Applications / 24 Hours Available / Work with files | ✅ 已覆盖 |
| **Cross-device control** | 在已有设备上工作，让下一步发生在合适的地方、合适的时间 | ✅ 已覆盖 |
| **Community Skills** | 社区 Skills 可接入 Today，更多工作流可选，更容易带入已有工具 | ✅ 已覆盖 |

> 结论：现有「核心功能模块」表已完整覆盖官方 Capabilities 全部能力点，无缺失。官方文案新增要素为区块开场的 **Built to actually work**（底层投入叙事）与各能力的细分标签（Harness Layer、Understand requests、Operate Applications 等），已在上表补录。
