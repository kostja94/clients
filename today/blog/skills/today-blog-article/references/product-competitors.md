## 3. 场景对比框架（Comparison / Alternative 用）

### Memory + Proactive + Execution 三轴

| 维度 | Today | ChatGPT | Apple Intelligence |
|------|-------|---------|-------------------|
| Living memory 叙事 | ★ 主轴 | 有记忆，非生活 OS | 系统整合 |
| Proactive | ★ 主打 | 有限定时/通知 | 系统通知 |
| 做到完成态 | ★ 任务+云电脑 | Agent 演进中 | 受限 |
| 多端客户端 | Mac/iOS/Android | Web/App | Apple 生态 |
| 健康信号 | HealthKit/Health Connect | 弱 | ★ 近源 |

### 何时不选 Today（A3/T 客观性 — 每篇 Comparison 必填）

- 只需单次问答、不需长期记忆 → ChatGPT/Claude 可能足够
- 纯 Apple 生态、不需 Android → Apple Intelligence 分发更强
- 纯工作流自动化、不需生活场景 → Lindy 等工作流 Agent
- 只需情感陪伴、不需任务执行 → Pi 类伴聊产品
