## 1. 竞品总览

| 竞品 | 定位 | 目标用户 | 核心功能 | 价格区间 | 与本品差异 |
|------|------|---------|---------|---------|-----------|
| **ChatGPT** | 通用对话 + 记忆/Agent 能力演进 | 大众 | 聊天、记忆、部分自动化 | Free–Plus/Pro | 缺「全生活 proactive + 多端执行」一体体验 |
| **Claude** | 长上下文助手/编程向 | 知识工作者 | Projects、Artifacts、电脑使用能力演进 | Free–Pro | 偏工作会话；生活记忆与健康信号弱 |
| **Apple Intelligence / Siri** | 系统级助手 | Apple 用户 | 系统整合、隐私叙事 | 硬件捆绑 | 分发强；跨 App 深度 Agent 仍受限 |
| **Pi (Inflection)** | 伴聊式个人 AI | 大众情感/日常 | 对话陪伴 | 免费/订阅 ⚠️ | 主动执行与云电脑弱于 Today 叙事 |
| **Limitless / 记忆向设备或助手** | 会议/生活记忆捕捉 | 专业用户 | 录音摘要、记忆检索 | 硬件+订阅 ⚠️ | 偏捕获；Today 偏记忆+主动+执行 |

## 2. 直接竞品详细拆解

### 2.1 ChatGPT（OpenAI）

- **优势**：心智占有率第一；持续加记忆、定时任务与 Agent 能力。  
- **劣势**：仍以聊天为中心；「了解你的整天并先行动」需用户自行编排。  
- **SEO**：霸占 *best AI assistant* 评测。  
- **与 Today**：对比页应强调 living memory + proactive + 本地多端客户端体验。  

### 2.2 Claude（Anthropic）

- **优势**：长任务、电脑使用、开发者口碑；Privacy 显示 Today 也可能调用 Anthropic。  
- **劣势**：产品形态仍是对话产品，非「日启 Morning Brief」生活 OS。  
- **与 Today**：可共存（模型层）+ 应用层差异（Today 是壳与编排）。  

### 2.3 Apple Intelligence / 系统助手

- **优势**：默认入口、隐私品牌、Health 数据近水楼台。  
- **劣势**：能力节奏受系统约束；跨生态（Android/多云工具）弱。  
- **与 Today**：Today 已接 HealthKit，可打「比系统助手更会执行跨 App 任务」。  

### 2.4 记忆/主动向独立产品（Pi、Saner、Limitless 等）

- **优势**：品类叙事接近（memory / proactive）。  
- **劣势**：各有偏科（陪伴、笔记、录音）。  
- **与 Today**：Capabilities（cloud电脑、Community Skills、任务闭环）是切割点。

## 3. 场景级对比表

### 场景 A：希望助手「记得我的人和目标」

| 维度 | Today | ChatGPT | Pi |
|------|-------|---------|-----|
| Living memory 叙事 | ★ 产品主轴 | 有记忆，非生活 OS 叙事 | 会话记忆/陪伴 |
| 用户控制感 | 官网强调 in control | 设置项演进中 | 中 |
| 多端客户端 | Mac/iOS/Android | Web/App | App |

### 场景 B：希望「没问就帮忙」并做完事

| 维度 | Today | ChatGPT | Lindy |
|------|-------|---------|-------|
| Proactive | ★ 主打 | 有限定时/通知 | 工作流触发 |
| 做到完成态 | ★ 任务执行 + 云电脑 | Agent 能力演进中 | ★ 工作自动化 |
| 生活+健康场景 | ★ 强 | 弱–中 | 弱 |

## 4. 差异与机会

| 类型 | 内容 |
|------|------|
| **S** | Memory + Proactive + Execution 三件套清晰；多端已发；隐私/健康条款完整 |
| **W** | 品牌知名度低；无 sitemap/内容；Beta；媒体硬件叙事可能干扰认知 |
| **O** | 「acts before you ask」可注册心智；用例 SEO |
| **T** | 大厂把记忆+定时任务做进主产品；系统助手变强；Agent 安全/幻觉事件 |

### 可攻切入点

1. **Chat 之后谁替我盯着生活** — Proactive + Morning Brief。  
2. **记得还不够，要做完** — Cloud computers + task execution。  
3. **系统助手不够跨生态** — 多端客户端 + 连接器。
