## 1. 产品定位

| 维度 | 内容 |
|------|------|
| 品类 | Proactive personal AI assistant（带长期记忆与可执行 Agent 能力） |
| 价值主张 | Less starting from scratch / less keeping everything in your head — **more help before you have to ask** |
| 竞争替代 | ChatGPT/Claude 聊天窗口（无持续生活上下文）；日历/待办 App 堆叠；Siri/系统助手；笔记+人工提醒 |
| 差异化锚点 | ★ Living Memory；★ Proactive；★ Task execution + cloud computers；★ Health 信号（合规读写边界清晰） |
| 市场位置 | 早期精品 Beta（免费获客）；未来可能订阅；中文媒体资本叙事偏 Agent 终端，官网偏全生活助手软件 |

### 1.1 定位简述

个人 AI 助手赛道已从「会聊天」转向「有记忆、会主动、能把事做完」。Today 把差异钉在三点：living memory 降低重复交代；proactive 在睡眠、日程、需求变更等节点先出手；capabilities 层强调工具调用、云端电脑与跨设备，使请求变成完成态而非建议列表。

ICP 是日程与信息过载的个人用户——设计师、创始人、自由职业者、带娃/带宠的人——官网用大量生活切片（旅行、西语、爬岩、宠物、税务）表达「整天陪跑」而非纯办公 Copilot。部分媒体报道偏 Agent 终端，官网偏全生活助手软件，产品线叙事 ⚠️ 待官方对齐。

## 2. 产品信息

**Today**（Today AI）Slogan：*Your personal assistant that actually knows you — and acts before you ask.*

能力摘要（详见 [capabilities](./today-ai-capabilities.md)）：Living Memory、Proactive、Morning Brief/Body Signals、强任务执行、连接器生态、Always-on cloud computers、跨设备、Community Skills；多端下载；Beta 免费。

隐私侧披露可对接 HealthKit / Health Connect，并可能经 AWS/Anthropic/OpenAI 等推理；声明不将健康数据用于广告，且不允许 Provider 用可识别内容训练公开基模。
