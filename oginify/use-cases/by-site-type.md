## 1. SaaS

### 典型用户画像

SaaS 创始人、产品营销经理、增长负责人。有产品落地页、定价页、博客、文档站，OG 图的核心诉求是"品牌一致 + 能 A/B 测试 + 每次发布新功能/新博文要快速出图"。

### 核心页面与 OG 图策略

| 页面 | 级别 | 策略 | 为什么 |
|------|------|------|--------|
| Homepage | A | 品牌贴合风格，突出价值主张 | 品牌门面，被分享最多的 URL |
| Blog Post | S | 杂志风/报纸风，每篇单独 | 内容天生为分享，占 SEO 流量大头 |
| Pricing | A | 品牌贴合 + 价格锚点 | 用户分享定价给决策者 |
| Feature 页 | A | 品牌贴合，突出功能亮点 | 被分享时代表"这个功能好用" |
| Use Case / Solution | A | 场景化视觉 | 被分享时代表"这个方案适合你" |
| Comparison / vs 页 | A | 品牌贴合 + 对比结构 | "X vs Y"高频搜索+高频分享 |
| Changelog | S | 终端风，标注版本号 | 产品更新天生为分享设计 |
| Docs | B | 终端风 | 开发者社区中偶尔被引用 |
| Integration | B | 品牌贴合 | 被分享时代表"支持这个集成" |
| About | B | 杂志风 | PR 引用时展示品牌形象 |

### 使用路径

```
发布新功能 → 粘贴 feature 页 URL → 品牌贴合风 × 4 → 挑一张 → 配置 og:image
发布博文 → 粘贴文章 URL → 杂志风 × 4 → 挑一张 → 配置
更新定价 → 粘贴 pricing URL → 品牌贴合风 带价格信息 → 配置
发新版本 changelog → 终端风 标注版本号 → 配置
```

### 为什么选 Oginify 而不是自己做

- SaaS 团队没有设计师专门做 OG 图——每次博文/功能/changelog 都找设计是瓶颈
- 需要 A/B 测试不同风格——截图+模板覆盖日常，AI Regenerate 补充创意
- 6 张/天免费——SaaS 早期每一分钱都要用在刀刃上
- 对比：请设计师单张 OG 图 $50–150$；用 Canva 自己做 $0 但要 20–30 分钟

## 2. 电商 / DTC

### 典型用户画像

电商运营、DTC 品牌方、Shopify 店主。有大量商品详情页和分类页，OG 图的核心诉求是"商品信息上图 + 批量效率 + 品牌调性统一"。

### 核心页面与 OG 图策略

| 页面 | 级别 | 策略 | 为什么 |
|------|------|------|--------|
| PDP（商品详情页） | A | 品牌贴合 + 产品名/价格 | 被分享时直接带货 |
| Category / Collection | B | 品牌贴合，品类整体调性 | 分享时代表"逛这个品类" |
| Campaign Landing | S | 大胆风格，快速 A/B | 投放页预览决定 CTR |
| Blog Post | S | 杂志风 | 内容营销引流 |
| Homepage | A | 品牌贴合 | 品牌门面 |
| About | B | 杂志风 | 品牌故事被分享 |

### 使用路径

```
热门商品 → 粘贴 PDP URL → AI 提取产品名+价格+卖点 → 品牌贴合风 → 配置
品类页 → 粘贴 category URL → AI 读品类调性 → 品牌贴合风 → 配置
活动 → 粘贴 campaign URL → 大胆风格 × 4 → 选点击最高的 → 配置
```

### 为什么选 Oginify

- SKU 多的店不可能每个商品手动作图——成本不可承受
- AI 自动提取商品信息比手动填模板快 10 倍
- 6 张/天免费对电商是刚需——有 OG 图预算的电商通常不是小商家
- 对比：Bannerbear API $49–299/月；MyOG.social ~$20/月

| Long-form Guide | S | 杂志风 + 阅读时长标注 | 深度内容被分享为"这篇值得收藏" |
| Research Report | S | 报纸风 + 关键数据点 | 研究报告是社交传播硬通货 |
| Newsletter | A | 报纸风，标注期号 | 被转发到社媒时需吸引订阅者 |
| Case Study | S | 品牌贴合 + 数据 | 证明内容价值 |
| Category / Hub | B | 品牌贴合 + 话题主题 | 内容发现入口 |

### 使用路径

```
日常发文 → 粘贴 URL → 杂志风 × 1（风格统一）→ 配置 → 发布
批量（规划中）→ 提供 sitemap → Oginify 批量生成 → 批量下载配置
```

### 为什么选 Oginify

- 内容站文章量大（几千篇），不可能每篇手动做图
- AI 读内容自动生成比套模板有辨识度——每篇文章的图都不一样
- 6 张/天免费对内容站是基础需求——订阅制对几百篇体量的站不划算
- 对比：OG Image API 25 张免费 → $14.99/月起；MyOG.social ~$20/月

### 典型用户画像

独立开发者、设计师、自由职业者、学生。只有几个页面，OG 图的核心诉求是"快速做几张 + 不用学设计工具 + 不花钱"。

### 核心页面与 OG 图策略

| 页面 | 级别 | 策略 | 为什么 |
|------|------|------|--------|
| Homepage（个人站） | A | 六种风格，每次 4 张，挑最喜欢的 | 个人品牌第一印象 |
| Portfolio / Project | A | 品牌贴合 + 作品展示 | 被分享时展示作品 |
| About / Bio | B | 杂志风/个人风格 | 个人介绍被引用 |
| Blog Post | S | 杂志风/报纸风 | 个人博客被分享 |

### 使用路径

```
访问 oginify.com → 粘贴个人站 URL → 每次 2 张（截图 + 模板）→ 下载配置
新 project / 改版 / 换活动图 → 再粘贴 URL 生成即可
```

### 为什么选 Oginify

- 页数虽少，homepage / portfolio / 每篇 blog 仍值得独立预览图——6 张/天免费够试用，不必为几张图学 Canva 或订 $49/月 API
- 零门槛——不需要学 Canva/Figma
- 6 风格库 + 每次 4 张——个人站不必局限于单一风格
- 对比：Canva 要自己设计，15–30 分钟；Figma 学习成本更高；Bannerbear 要 $49/月——对个人站完全不合理

## 6. 代理 / 服务商

### 典型用户画像

SEO 代理、网页设计公司、营销服务商。自己站需要 OG 图，客户的站也需要 OG 图，OG 图的核心诉求是"批量 + 帮客户做 + 专业感"。

### 核心页面与 OG 图策略

**自己的站：**

| 页面 | 级别 | 策略 |
|------|------|------|
| Homepage | A | 品牌贴合 |
| Case Study | S | 品牌贴合 + 数据可视化 |
| Service 页 | A | 品牌贴合 |
| Blog Post | S | 杂志风 |
| About | B | 杂志风 |

**客户的站：**Oginify 是给客户做 OG 图的最佳工具——免费、不用登录、粘贴 URL 就行。给客户交付的时候可以直接说「用这个免费工具自己就能做」，比自己手动做一百张图有说服力。

### 使用路径

```
自己站 → 同上 SaaS 类使用路径
客户站 → 推荐 Oginify → 客户自己贴 URL → 生成 → 下载 → 代理帮配置
或者 → 代理帮客户做 → 粘贴 URL → 生成 → 下载 → 交付 → 客户满意
```

### 为什么选 Oginify

- 帮客户做 OG 图不需要自己掏 API 钱——$0 免费
- 给客户的交付物更专业——不是"我帮你做了张图"，是"我推荐这个工具，你自己也能做"
- 代理的案例页（S 级）本身是获客工具——OG 图做好了对获客有直接帮助

### 核心页面与 OG 图策略

| 页面 | 级别 | 策略 | 为什么 |
|------|------|------|--------|
| 每篇新闻/文章 | S | 杂志风/报纸风，每篇单独 | 文章天生为分享，社媒引流命脉 |
| 专题/深度报道 | S | 报纸风 + 关键视觉元素 | 深度内容被分享为"这篇值得看" |
| 首页 | A | 品牌贴合 | 品牌门面 |
| 栏目/频道页 | B | 报纸风 + 栏目名 | 被分享时代表"看这个频道" |
| 数据新闻/图表 | S | 品牌贴合 + 数据可视化 | 数据驱动分享的硬通货 |

### 使用路径

```

- 对比：大多数新闻站用自动截取文章第一张图做 OG——效果很差；手动设计每篇不现实

发布健康科普 → 粘贴文章 URL → 杂志风（专业可信）→ 配置 → 社媒分发

研究报告 → 粘贴报告 URL → 杂志风 + 关键发现 → 配置
```

### 为什么选 Oginify

- 医疗机构一般没有设计团队做社交图——内容团队身兼数职
- 健康内容需要专业感——模板化和随意截图都会降低可信度
- $0 免费对非营利医院和公共健康机构是刚需
- 对比：WebMD 等大平台有专职设计；地方医院/诊所几乎零预算
