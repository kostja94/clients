# Milestone 首发帖模板

> **本文档职责**：M1–Mn 系列帖的三平台结构模板。填具体事实前必读 [voice-and-messaging.md](../voice-and-messaging.md)。  
> **引用**：[repurpose-matrix.md](./repurpose-matrix.md) | [playbook.md](../playbook.md)

---

## 通用结构（三平台共享的故事弧）

1. **Hook** — Milestone X + 第一个产品 / Build in Public
2. **Why** — 本次新事实或起源故事（OG / pSEO 作为支撑）
3. **What** — 产品交付或进展（简短）
4. **Learnings** — vulnerable：还在 early stage、不确定、真实踩坑
5. **Next** — 下一 Milestone 预告 + follow
6. **CTA** — follow > try > DM

## LinkedIn 模板（英文 · Carousel）

```
I shipped [milestone hook — e.g. my first product / Milestone 2 update].

[1–2 sentences: personal / vulnerable context]

[Wrong belief → correction about OG / pSEO / distribution — optional if not M1]

[Client or user story — 2–3 sentences, AI Notes Generator generic if origin story]

[What Oginify is — one sentence: paste URL → 4 content-aware OG images]

Swipe through the carousel — [describe demo: same URL, four visuals].

I'm building in public. I'll post here at every milestone.

Try it, tell me what's missing, or just follow along — link in the first comment.

[Open question for replies]

#buildinpublic #firstproduct #SEO #OpenGraph #programmaticSEO #indiehacker
```

**Carousel**：3–4 张生成图 + 可选 Before 截图。  
**第一条评论**：oginify.com / validator / GitHub / Enterprise DM。
