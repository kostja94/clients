# 即刻 · Oginify 发帖规格

> **本文档职责**：Oginify 在即刻的发帖规格与特例。通用即刻文案规则见 [元文档-即刻文案生成](../../通用知识库/元文档-即刻文案生成.md)。  
> **引用**：[voice-and-messaging.md](../voice-and-messaging.md) | [playbook.md](../playbook.md)

---

## 账号与节奏

| 项 | 说明 |
|----|------|
| **频率** | BiP **Daily**（产品日志）+ Milestone 可与 LinkedIn/X **同日或次日**补发 |
| **语言** | **中文** |
| **调性** | 口语、真实、有观点；忌营销腔 |

---

## 形态选择

| 风格 | 字数 | 适用 |
|------|------|------|
| **省流摘要** | 300–500 | Milestone 官宣、配合 LinkedIn/X 二次触达 |
| **深度长文** | 800–2000 | 技术决策、成本账、踩坑（更贴近 BiP 日志） |

BiP 日常帖（技术踩坑、产品思考）用 `published/bip-{slug}/`，仅含 `jike.md` + `post.meta.yaml` 即可。Milestone 首发见 [templates/milestone-launch.md](../templates/milestone-launch.md)。

---

## 格式规格

| 维度 | 规格 |
|------|------|
| **格式** | **纯文本**；emoji 数字分段（1️⃣ 2️⃣）；段落空行 |
| **禁止** | 井号标题、星号加粗、反引号等 Markdown |
| **链接** | 末尾 **最多 1 个 URL**，单独一行 |
| **活跃高峰** | 21:00–23:00；次选工作日 9:00–10:00 |

---

## 链接策略

即刻对正文中链的惩罚弱于 X；Milestone 帖可在末尾一行放 `https://oginify.com`。

---

## Milestone 省流模板

```
Milestone X 🚀

（1–2 句本次进展）

1️⃣ 为什么重要
2️⃣ 做了什么 / 学到了什么
3️⃣ 下一步

Build in Public，下一个 milestone 继续更。

https://oginify.com
```
