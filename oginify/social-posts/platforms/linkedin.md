# LinkedIn · Oginify 发帖规格

> **本文档职责**：Oginify 在 LinkedIn（Kostja 个人号）的发帖规格与特例。通用 LinkedIn 知识见 [09-LI-增长策略与实践](../../通用知识库/LinkedIn/09-LI-增长策略与实践.md)。  
> **引用**：[voice-and-messaging.md](../voice-and-messaging.md) | [playbook.md](../playbook.md)

---

## 账号与节奏

| 项 | 说明 |
|----|------|
| **账号** | Kostja 个人号（无 Company Page） |
| **频率** | 每个 **Milestone** 一篇 |
| **语言** | **英文** |
| **调性** | Build in Public + professional vulnerable |

---

## 推荐形态：Carousel + 文字

| 项 | 规格 |
|----|------|
| **首行钩子** | 前 **210–235 字符**内：Milestone / 第一个产品 / 认知纠正 |
| **正文** | 故事 > 功能清单；产品由 carousel **图演示** |
| **图片** | 3–4 张 Oginify 生成 OG 图（同 URL 不同风格）；可选 Before 截图 |
| **Hashtag** | 文末 3–6 个，见 [voice-and-messaging.md](../voice-and-messaging.md) |

---

## 链接策略

| 做法 | 说明 |
|------|------|
| **推荐** | 正文写「link in the first comment」；**第一条评论**放 oginify.com / validator / GitHub |
| **可选** | 正文末尾软链一句；与 carousel 并存时版面略挤 |
