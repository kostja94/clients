# X · Oginify 发帖规格

> **本文档职责**：Oginify 在 X（@kostjazhang）的发帖规格与特例。通用 X 规则见 [marketing-skills X SKILL](https://github.com/kostja94/marketing-skills/blob/main/skills/platforms/x/SKILL.md)。

## 账号与节奏

| 项 | 说明 |
|----|------|
| **账号** | @kostjazhang |
| **Premium** | **必需**（Articles 门槛） |
| **频率** | 每个 Milestone：1 篇 **Article** + 可选 teaser |
| **语言** | **中文**（Article）；teaser 同中文 |
| **调性** | Build in Public 主轴 + Milestone 系列 |

---

## 形态：X Article（主力）

| 项 | 规格 |
|----|------|
| **入口** | x.com → 侧栏 **Articles** → Write |
| **标题** | 单独标题栏，如「我发布了第一个产品。这是 Milestone 1。」 |
| **正文排版** | 大段小标题用编辑器 **Heading**（非 Subheading）；URL 可直接粘贴 |
| **篇幅** | 约 1,200–2,000 字中文 |
| **配图** | Cover + 正文 2–4 张；demo 常用 `https://oginify.com`；X 单图建议 1200×675 |

官方说明：[About Articles](https://help.x.com/en/using-x/articles)

---

## 发布后行为

发布 Article 后，X **自动生成一条 Feed Post**（时间线可见），同时全文在 Profile → **Articles Tab** 存档。

| 位置 | 作用 |
|------|------|
| Feed Post | 发现与互动 |
| Articles Tab | Evergreen 归档 |

若自动 Post 的 hook 不够理想，可另发 teaser 或引用转发；避免与自动 Post 完全重复。

---

## 链接策略

| 场景 | 策略 |
|------|------|
| **Article 正文** | 可放 oginify.com、validator、GitHub（官方支持 links） |
| **Teaser 短帖** | 链到 **Article URL**；oginify.com 放**回复** |
| **算法** | 短帖正文外链仍有惩罚；Article 内链无此限制 |

---

## Teaser 短帖模板（可选）

```
Milestone 1 🚀

我发布了第一个产品 Oginify。

写了一篇长文，记录从 0 到 1 的起点——为什么做、目前上线了什么、以及接下来会在这里持续发每一个 milestone。

Build in Public，unfiltered 版本。

👇 全文
（附 Article 链接）
```

**第一条回复**：试用 / Validator / 开源链接 + Enterprise DM。

## 首小时互动

发布后 **60 分钟内**回复所有评论；作者回复链权重高（见 X 算法公开信号）。
