# Oginify

Open Graph 配图生成器。粘贴任意 URL，2 张 1200×630 社交分享图（截图 + 模板），AI 按需补生成。

- **线上地址**：[oginify.com](https://oginify.com)
- **开源产品**：[social-cards-skills](https://github.com/kostja94/social-cards-skills)（MIT）
- **文档同步**：2026-05-31
