# Oginify Writing Style — Voice 标准与句段指标

> 加载时机：Phase 4 / Phase 5
> 主文件：SKILL.md §9 指针

---

## 1. 品牌 Voice 五项

| # | 维度 | 达标标准 |
|---|------|---------|
| 1 | **Clear** | 非专业读者能复述核心观点 |
| 2 | **Evidence-led** | 强判断有依据或限定（likely / as of Aug 2026） |
| 3 | **Practitioner-grade** | 有具体对象：URL、1200×630、og:image tag、定价、版本号 |
| 4 | **Calm but opinionated** | ≥1 处承认非 Oginify 方案更适合的场景 |
| 5 | **Category-building** | 产品首次出现前已提供独立价值 |

---

## 2. 禁止措辞（零容忍）

| 禁词/模式 | 替代 |
|----------|------|
| revolutionary / game-changing | 具体改进（native reasoning、text rendering） |
| seamless / magic / unlock | 具体机制 |
| only platform / unbeatable / best-in-class | 限定 "strongest for {job shape}" |
| guaranteed / 100% | 诚实边界 |
| "in today's digital world" | 直接进主题 |
| "It is important to note that" | 删掉 |
| "Let's dive in" | 删掉 |

**空泛句阈值**：flagship/standard ≤2 处；Track T ≤3 处。

---

## 3. 句段指标

| 指标 | 达标 |
|------|------|
| 平均句长 | 15–24 words |
| 长段落（≥4 句，80–200 词） | ≥3 个 |
| 段落长度标准差 | 能目测长短交替（≥1.5） |
| 连续短段（≤2 句） | ≤2 个连续 |
| 列表占比 | ≤类型上限（presentation-rhythm §5.4） |
| 段间衔接率 | ≥70% |

---

## 4. Oginify 专属 Voice 规则

| 规则 | 说明 |
|------|------|
| 产品自述 | 用「Oginify 是 URL-first 生成器」而非「我们最棒」 |
| 竞品表述 | 客观分类（通用生图 / 代码驱动 / 模板自动化），禁贬义 |
| 技术准确 | URL、尺寸、meta tag、as-of 精确 |
| 品牌措辞 | "Open Graph cards, instantly" 可用于 one-liner |

---

## 5. AI 原创性

- 核心论点必须是作者（Agent 按 skill 工作流）从 R2/R3 合成的原创判断
- 禁全文复述 SERP Top3 的论点排序（信息增量审计 serp-audit §2）
- 原创框架（三分类）标注为 P2 原创分析
