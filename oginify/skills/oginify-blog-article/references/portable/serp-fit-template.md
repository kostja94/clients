# SERP Fit Template

> 便携参考 · Phase 0R 使用

---

## 模板

```markdown
## SERP Fit — {keyword}

| 项 | 值 |
|----|-----|
| Keyword | {primary keyword} |
| Intent | Informational | Commercial | Transactional |
| Top 1 | {URL} — {title} |
| Top 2 | {URL} — {title} |
| Top 3 | {URL} — {title} |
| PAA | 1. … 2. … 3. … |
| Reader gap | {Top3 未回答的问题} |
| Our differentiation | {≥1 独有增量} |
| Gate 0R | PASS | FAIL |
```

---

## 填写规则

- Top1–3 来自 R2 搜索实时结果
- PAA 来自 SERP 的 People Also Ask 区块（FAQ 题源）
- Reader gap = 读者搜索时最想解决、但 Top3 没答的问题
- Our differentiation 必须对应 skill 的信息增量清单
- Gate 0R-6：One-line thesis 不得与 Top5 同句
