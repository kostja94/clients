# Perfect Article Checklist — S 级标杆清单

> 便携参考 · Phase 5（flagship）使用

---

## 清单

### 结构
- [ ] TL;DR 3–5 bullet，bullet 1 = snippet 定义句
- [ ] 编号 H2 + Conclusion + FAQ（固定 6 题）
- [ ] 无 Related articles 区块；内链全为上下文内链
- [ ] Ranking：编号 H3 + `articleFormat: Ranking`

### 内容
- [ ] 三分类框架（URL-first / 通用生图 / 代码驱动）完整呈现
- [ ] Moat Asset 已兑现（Brief 中声明的原创框架/表/案例）
- [ ] Answer Blocks 3–5 个均可独立成 40–60 词段
- [ ] 每竞品 ≥1 优势 + ≥1 非 Oginify 更合适场景
- [ ] 产品数字含 as-of + 来源
- [ ] 1200×630 规格有来源

### 表达
- [ ] 长段落 ≥3（4–8 句）
- [ ] 伪列表 0
- [ ] 列表占比 ≤类型上限
- [ ] 衔接率 ≥70%
- [ ] Voice 5 项全满足；禁词零触发
- [ ] Intro 非模板化三段式

### 质量信号
- [ ] BLUF 三处全 Pass
- [ ] Claim 原子性 Pass
- [ ] Judgment J1–J2 Pass
- [ ] Excellence 已标注（Yes + 类型 / No）
- [ ] Post-publish Metric Spec 已写入 Brief

---

## S 级判定

全部勾选 + 加权 12 维总分 ≥90 → S 级标杆稿。
