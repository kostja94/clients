# Outline Cross-Check — Phase 3.5 交叉检查

> 便携参考 · Phase 3.5 使用（同批 ≥2 篇强制）

---

## 检查项

| # | 检查点 | Fail 条件 | Pass 条件 |
|---|--------|----------|----------|
| 1 | H2 标题重复度 | 同 cluster ≥2 篇同一 H2 措辞 | 各篇 H2 差异化 |
| 2 | 叙事弧相似 | 都是「定义→列表→对比→FAQ→CTA」且无角度差异 | 至少 1 篇用不同弧线 |
| 3 | Canonical 越界 | 非 canon 文展开 hub 才该全量写的概念 | canonical 概念 1–2 句 + link |
| 4 | Synthesis 冲突 | 两篇 One-line thesis 重叠 >50% | 差异 ≥50% |
| 5 | 内链缺口 | Spoke 未链回 Hub / 互链不足 | 满足 content-graph 互链矩阵 |

---

## 流程

```
1. 并排放置各篇 Outline 的 H2 列 + Reader mental state 列
2. 逐项检查（5 项）
3. Fail → 改 Outline / 改 Synthesis / MERGE 建议 / 补内链 → 重过 3.5
4. Pass → 输出 `Outline cross-check: PASS — {slugs}` → Phase 4
```
