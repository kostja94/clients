# Oginify EEAT Framework — E-E-A-T 四信号

> 加载时机：Phase 4 / Phase 5
> 主文件：SKILL.md §9 指针

---

## 1. 四信号定义

| 信号 | Oginify Blog 做法 | Gate 关联 |
|------|------------------|-----------|
| **Experience** | URL-first workflow 步骤来自产品实测；use-case 文章写真实场景（launch feature / refresh blog / defend landing page / ad set） | G5 |
| **Expertise** | 三分类框架（URL-first / 通用生图 / 代码驱动）技术准确；1200×630 规格 + 平台裁剪行为准确 | P3 |
| **Authoritativeness** | P0 数字官方来源（oginify.com、ogp.me、各平台官方定价页）；外链权威 | G3 |
| **Trustworthiness** | 诚实竞品优势（P5）、as-of 标注（P1）、无 CTR 虚假承诺（P6）、AI 生成视觉标注 | P1/P5/P6 |

---

## 2. 按类型来源数要求

| 类型 | 最低外部来源 | 说明 |
|------|:---:|------|
| Ranking / Comparison | 3+ | 每竞品 ≥1 官方来源 + 竞品优势来源 |
| HowTo | 1–2 | 产品机制官方页 + 可选平台规格 |
| Glossary（Hub） | 2+ | ogp.me + 产品官方页 |
| SizeGuide | 2+ | ogp.me + 平台官方 |
| Alternative | 3+ | 双方官方页 + 定价 |
| DeveloperGuide | 2+ | 官方 docs + GitHub |
| TrendAnalysis | 3+ | 数据源 + 平台官方 |
| ToolGuide / Announcement | 1–2 | 工具页 + 产品页 |

---

## 3. 署名与作者池

| 作者 | 适用 | 说明 |
|------|------|------|
| Oginify | 默认 | 品牌署名 |
| Kostja | 创始人署名 | 增加个人 EEAT（社交账号可链接） |
| {团队具体成员} | 如有 | 需确认 |

**EEAT 提升**：创始人署名文可含一手产品判断（"in building Oginify, we found…"）——这是最高价值的 P2 证据。

---

## 4. 自检清单（Phase 5）

- [ ] 每个可验证 claim 有来源（G3）
- [ ] 竞品描述基于官方资料（G4/P5）
- [ ] 产品数字含 as-of（P1）
- [ ] ≥1 竞品优势段（P5）
- [ ] 无未验证的 CTR/转化承诺（P6）
- [ ] 署名正确（作者池）
- [ ] 文章内有具体对象（URL、平台名、版本号、定价）
