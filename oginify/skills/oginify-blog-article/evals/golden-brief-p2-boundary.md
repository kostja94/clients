# Golden Brief — P2 URL-first 边界回归（E05）

**关联 Eval**：E05

## 期望输出断言

- [ ] 正文承认通用生图工具（Gemini / GPT Image / Midjourney）**能**做 OG 卡片
- [ ] 明确说明通用工具需要用户手动处理：尺寸（1200×630）、文字渲染、导出 PNG、托管、meta tags
- [ ] Oginify 差异表述为「以 URL 为唯一输入」而非「唯一无需 prompt」
- [ ] 决策表述为「选择取决于你想让工具替你完成多少步骤」

## 反例（FAIL 触发 — P2）

- "Gemini cannot make OG images"
- "GPT Image is not suitable for OG cards"
- "Only Oginify works without a prompt"
- "General-purpose tools are useless for this"
