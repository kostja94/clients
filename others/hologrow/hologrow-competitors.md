## 3. 直接竞品详解

### 3.1 Nosto

| 项目 | 内容 |
|------|------|
| **定位** | 电商个性化、推荐、搜索 |
| **优势** | 成熟个性化引擎、多平台集成 |
| **限制** | 偏推荐与内容，非实时意图识别 |
| **Hologrow 机会** | 意图识别差异化；94% 准确率、<100ms；AI Shoppable Video |

### 3.2 Yotpo

| 项目 | 内容 |
|------|------|
| **定位** | 评论、忠诚度、UGC、邮件 |
| **优势** | 评论+忠诚度一体化、Shopify 集成 |
| **限制** | 忠诚度为规则驱动，非意图驱动 |
| **Hologrow 机会** | Loyalty Program Generator 意图驱动、实时优化；意图识别前置 |

### 3.3 Smile.io

| 项目 | 内容 |
|------|------|
| **定位** | 忠诚度、推荐计划 |
| **优势** | Shopify 生态、易用 |
| **限制** | 忠诚度设计为一次性，非持续优化 |
| **Hologrow 机会** | AI 自动设计、持续学习、意图触发激励 |

### 3.4 Dynamic Yield

| 项目 | 内容 |
|------|------|
| **定位** | 个性化、A/B 测试、推荐 |
| **优势** | 企业级、全渠道 |
| **限制** | 偏企业、定价高；非意图识别 |
| **Hologrow 机会** | 意图识别、Shopify 原生、中小品牌友好 |

## 4. Hologrow 差异化

| 维度 | Hologrow | 竞品 |
|------|----------|------|
| **意图识别** | 94% 准确率、200+ 微行为、<100ms、4 层框架 | 多为规则/历史行为，非实时意图 |
| **忠诚度** | AI 自动设计、意图驱动触发、持续学习 | 多为规则设定、静态分层 |
| **AI Shoppable Video** | 根据浏览即时生成演示 | 竞品多为静态视频 |
| **Shopify** | 原生 App、一键安装 | 部分竞品有集成 |
| **数据** | 500M+ 会话、实时 | 依赖自有数据 |
