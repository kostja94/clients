# Hologrow Use Cases 总结

> 关联：[hologrow.md](./hologrow.md) | [hologrow-features.md](./hologrow-features.md) | [hologrow-solutions.md](./hologrow-solutions.md) | [hologrow-competitors.md](./hologrow-competitors.md) | [hologrow-keywords.md](./hologrow-keywords.md) | 基于官网 [hologrow.ai](https://hologrow.ai/)

**产品形态**：Web 主站（hologrow.ai）+ Shopify App。各 Use Case 页面 CTA 链至 Book a Demo 或 Get Shopify App。

**Use Cases 与 Features、Solutions 严格区分**（三者不重叠）：

| 类型 | 回答的问题 | 示例 |
|------|------------|------|
| **Features** | 产品**能做什么**？ | Intent Recognition、Loyalty Program Generator |
| **Use Cases** | **谁**在**什么情境**下用？ | For Shopify merchants、Cart abandonment recovery |
| **Solutions** | 该**行业**能获得什么业务结果？ | E-commerce 30%+ 转化、DTC +47% LTV |

**边界**：Use Cases = **Persona**（谁）+ **情境**（何时/为何）；Solutions = **按行业**、调用 Features、链接 Use Cases；见 [hologrow-solutions.md](./hologrow-solutions.md)。

## 四、场景合理性分析

| 场景 | 合理性 | 说明 |
|------|--------|------|
| **Shopify 商家** | 高 | 官网强调 Shopify App；一键安装；电商核心受众 |
| **DTC 品牌** | 高 | 独立站、品牌直营；匿名流量、购物车放弃痛点 |
| **电商品牌** | 高 | 通用电商；意图识别、转化优化 |
| **营销/增长团队** | 中 | 关注转化、ROI、广告效率；Buyer Intent Report 契合 |
