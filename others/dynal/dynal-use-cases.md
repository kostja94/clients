## 1. 目标用户与使用场景（调研）

| 人群 | 使用场景 |
|------|----------|
| **创始人 / 高管** | 将公司经验与业务叙事转化为**个人品牌**与思想领导力内容 |
| **咨询师 / 教练** | 建立专业权威，吸引潜在客户（框架、案例、洞见可见化） |
| **市场 / 运营人员** | 将营销洞察、战役复盘与市场观察转化为**可感知**的专业内容 |
| **代理机构 / 代笔人** | 管理多个客户的 LinkedIn 内容流程（多声音、审核、排期） |
| **销售** | LinkedIn 社交销售：非硬广话术、跟进内容、建立行业可信度 |
| **招聘** | 用内容吸引被动候选人；雇主品牌帖、团队文化展示 |
| **求职者** | 用 LinkedIn 内容建立专业可见度，吸引雇主与面试机会 |
| **组织 / EGC** | 员工为**公司**做内容增长、背书与曝光（*employee-generated content*）；需与 **个人 IP** 叙事区分。**管理者与员工**诉求常不一致（个人影响力 vs 组织背书、线索与招聘等）；对外文案与功能引导上应分开考虑（与多账号、Brand DNA、**审批后再发布** 等组合）。 |

## 2. 官网「Who Dynal is for」摘要（英文叙事对照）

| Persona | 核心情境 | 价值表述（与主定位一致，意译可落地英文） |
|---------|----------|----------------------------------------|
| **Founders & executives** | 公司教训、发布、领导力思考 | **Agent** 学其品牌与立场；**计划**周内容；**用你的声音**发文；**放大**领英存在感——无需全职内容岗 |
| **Consultants & coaches** | 框架、客户工作、专业洞见 | 品牌与声音被记住；内容有计划；帖子像本人、权威感更强 |
| **Marketers & operators** | 战役心得、市场观察 | 团队/个人品牌上下文一致；节奏可执行；思考可见且不拖慢执行 |
| **Agencies & ghostwriters** | 多客户声音、审核、排期 | 每客户一套「学品牌 + 计划 + 其声音」的代理式工作流，审核与排期合一 |

## 3. 情境故事线（内容/落地页可用）

1. **学品牌 + 从素材到帖**：保存的文章、会议笔记、PDF 报告 → 强化 Brand DNA → 一周可执行选题与草稿。  
2. **你的声音**：多轮编辑仍像「本人」，非泛化 AI 腔。  
3. **计划而不仅是生成**：周计划视图降低「每天想选题」的认知负荷。  
4. **增长且可控**：代笔或团队流程中，批准后再发；存在感累积而非单次爆款赌博。  
5. **多品牌/多创始人**：代理在同一 workspace 为不同客户切换「学品牌 / 声音 / 计划」上下文。

---

## 4. 与 Features 的分工

- **Features**：回答产品**能做什么**（**AI LinkedIn agent**：学品牌、计划、你的声音发文、存在感闭环；以及摄取、Brand DNA、审核、多账号、发布、图片/轮播、话题推荐等）。  
- **Use Cases**（本文）：回答**谁**在**什么业务情境**下需要上述能力。
