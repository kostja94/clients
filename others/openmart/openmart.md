## 1. 产品信息

### 产品定位

**OpenMart** 是本地商业智能与获客数据平台，提供 200M+ 经过验证的本地商业联系人数据，覆盖 200+ 国家、500+ 行业类别。通过 Google Maps 抓取、预建数据库、REST API 及 AI 数据增强，帮助增长、销售和营销团队高效触达本地中小型企业（SMB）。

### 目标受众

- **增长/销售/营销团队**：需要本地商业线索的 B2B 团队
- **房地产**：物业数据与本地商业洞察
- **媒体**：行业洞察与本地数据
- **能源与公用事业**：能源领域数据
- **零售与消费**：零售机会发现
- **私募股权**：投资标的与尽职调查数据

### 核心产品线

| 产品 | 说明 |
|------|------|
| **Google Maps Scraper** | 从 Google Maps 抓取商户数据（含 reviews、phone、email），导出 CSV/XLSX |
| **Owner Finder** | 查找决策者/老板联系方式，邮箱/电话验证 |
| **Local Business Database** | 200M+ 预验证记录，97–99% 准确率，80+ 品类，地域+品类 |
| **Local Business Data API** | RESTful API，Google Places API alternative，实时数据 |
| **Enrichments** | 数据补充/验证，contact enrichment，lead enrichment |
| **Download** | 批量导出/下载，export to CSV/Excel |
| **Monitoring** | 监控新商户/变更，new business alerts |
| **Prospecting** | SMB prospecting tool，AI 驱动获客 |

*功能页见 [openmart-features.md](./openmart-features.md)；Use Cases 见 [openmart-use-cases.md](./openmart-use-cases.md)；Solutions 见 [openmart-solutions.md](./openmart-solutions.md)；关键词见 [openmart-keywords.md](./openmart-keywords.md)；竞品见 [openmart-competitors.md](./openmart-competitors.md)；Database 见 [openmart-database.md](./openmart-database.md)*

### 差异化优势

- **200M+ 本地商业数据**：覆盖 ZoomInfo 等企业级工具较少覆盖的实体店/本地商户
- **97–99% 准确率**：多源验证 + AI 校验 + 实时邮箱/电话验证
- **决策者联系人**：通过网站、税务记录、评论等获取，而非仅依赖 LinkedIn
- **丰富数据点**：收入估算、技术栈、广告支出信号等 40+ 字段
- **合规**：符合 GDPR、CCPA 及国际数据保护法规
