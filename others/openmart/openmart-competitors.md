## 2. 直接竞品详解

### 2.1 ZoomInfo

| 项目 | 内容 |
|------|------|
| **定位** | 企业级 B2B 联系人数据库 |
| **优势** | Fortune 500 覆盖、企业决策者、销售智能 |
| **限制** | 价格高；本地商户、SMB 实体店覆盖弱 |
| **OpenMart 机会** | local business、SMB leads、restaurant database、dentist database—ZoomInfo 较少覆盖；官网已有 [vs ZoomInfo](https://www.openmart.com/comparison/openmart-vs-zoominfo) |

### 2.2 Apollo

| 项目 | 内容 |
|------|------|
| **定位** | B2B 销售智能、联系人发现 |
| **优势** | ~50M 企业、多决策者、销售自动化、免费层 |
| **限制** | 聚焦企业级，非本地 SMB 实体店 |
| **OpenMart 机会** | Apollo alternative local business、local business database、SMB prospecting；官网已有 [vs Apollo](https://www.openmart.com/comparison/openmart-vs-apollo) |

### 2.3 Outscraper

| 项目 | 内容 |
|------|------|
| **定位** | Google Maps 抓取、数据提取 |
| **优势** | $3/1K、免费 500 条/月、API、按量付费 |
| **限制** | 抓取为主，无 200M 预建库；需自建抓取任务 |
| **OpenMart 机会** | 200M 预建库 + 实时抓取 + API 一站式；**建议新建 vs Outscraper 对比页** |

### 2.4 Apify

| 项目 | 内容 |
|------|------|
| **定位** | 自动化平台、Google Maps Extractor |
| **优势** | 按用量计费、开发者生态、多数据源 |
| **限制** | 需技术配置；无预建本地商户数据库 |
| **OpenMart 机会** | 预建数据库 + 即用 API；**建议新建 vs Apify 对比页** |

## 7. 对比页内容要点（新建时参考）

### vs Outscraper

| 维度 | OpenMart | Outscraper |
|------|----------|------------|
| 预建库 | 200M+ 即用 | 需抓取 |
| 决策者 | Owner Finder | 有限 |
| 准确率 | 97–99% | 抓取质量依赖 |
| 定价 | 订阅 + credits | $3/1K 按量 |
| 适用 | 规模化、需决策者、需 enrichment | 按需抓取、技术团队 |

### vs Apify

| 维度 | OpenMart | Apify |
|------|----------|-------|
| 即用性 | 预建库 + API | 需配置 Actor |
| 本地商户 | 核心 | 需自建 |
| 决策者 | Owner Finder | 有限 |
| 适用 | 销售/营销团队 | 开发者、自动化 |
