## 1. 产品 One-line

```
FinalRound is the #1 real-time AI interview assistant for job seekers—Interview CoPilot™
in the desktop app for live help, practice interviews, and automatic debriefs after each
session. Stealth Mode is on by default during screen sharing.（10M+ users, official claim）
```

## 2. 核心产品与能力（2026-08 产品形态）

| 能力 | 说明 |
|------|------|
| **Interview CoPilot™** | 桌面应用；实时面试中结构化答案；基于简历/职位个性化 |
| **Practice Interview** | 从 Goal 启动；8 类题型；Re-drill 定向复练 |
| **Interview Debrief** | 自动复盘：问了什么、怎么答的、如何改进 |
| **Screen Help** | Auto-capture / Solve screen / Results panel |
| **Stealth Mode** | 默认开启；隐藏悬浮窗口于屏幕共享/录制 |
| **Phone Interview** | Preflight 选 This computer / Another device；一次性语音样本 |

## 3. 产品流程关键事实

| 项目 | 事实 |
|------|------|
| **Goal** | 角色 + 公司 + JD + 简历/材料 + 练习 + 会话 + 复盘；Overview / Prep / Sessions |
| **工作流** | Prepare → Perform or Practice → Review |
| **Preflight** | Go Live/Practice → Preflight → Start session；本次会话可调简历/材料/语言 |
| **桌面应用** | 实时/练习/报告/屏幕帮助均在桌面端；旧网页版与旧桌面版行为不同 |

## 4. 定价（2026-08，无免费试用）

| 计划 | 说明 |
|------|------|
| **Free** | 有限功能；含 Practice interviews；**不含** live Copilot、Stealth、AI reports、高级题型 |
| **Pro** | 实时 Copilot、Stealth Mode、自动复盘、练习面试、高级面试类型 |

**红线（F1）**：无免费试用；实时会话需付费订阅。CTA 用 Download App / Get Interview CoPilot™ / See Plans。

## 5. 竞品公平摘要

| 竞品 | 优势（写作必须承认） | 限制 |
|------|---------------------|------|
| **Verve Copilot** | 实时 Copilot、20+ 领域、角色专用、编码支持 | 定价 $38–$60/月；无免费试用透明度待核实 |
| **OphyAI** | Whisper Mode 半透明 overlay、7 语言、性价比高 | 无 stealth 全隐；功能广度有限 |
| **Interview Sidekick** | Real-Time Assistant（Stealth overlay）+ Mock Practice（10K+ 真题、STAR） | 免费 tier 2 分钟/场限制 |
| **LockedIn AI** | 实时辅导、Resume、LinkedIn、Job 追踪、Phone Interview Copilot | $54.99/月起；定价高 |
| **Parakeet AI** | 隐形应用、Web 平台（Meet/Chime） | Zoom 全屏共享时可被检测 |
| **Beyz AI** | 实时建议、编码助手、隐形桌面应用、Mock 练习 | 功能广度有限 |
| **Huru** | AI Mock Interview、多难度、多语言 | 无实时面试帮助 |

**FinalRound 差异化（可写）**：10M+ 用户（官方宣称）、多平台（LeetCode、HackerRank、CodeSignal 等编码平台）、全流程（Resume、Auto Apply）、桌面应用 + Stealth 默认开启。

**E-E-A-T 注意**：竞品描述基于官方资料（非二手博客）；竞品状态以官网验证为准（G4）。
