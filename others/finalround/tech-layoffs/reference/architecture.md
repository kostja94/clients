## 2. 路由结构

| 路由 | 行为 | 说明 |
|------|------|------|
| `/` | 301 redirect → `/tech-layoffs` | 子站根路径自动跳转 |

## 3. 部署架构

```
用户浏览器 → https://www.finalroundai.com/tech-layoffs
                    ↓ Rewrite（反向代理，Mohit 维护）
           https://finalround-nextjs.vercel.app/tech-layoffs
                    ↑
               Bella 维护的 Vercel 项目
```

- 用户看到的始终是 `www.finalroundai.com`
- 实际内容由 Vercel 子域名提供
- **主站 Rewrite 规则由 Mohit 维护**，Bella 不需要修改
- 子站 Vercel 环境变量由 Kostja 管理

## 4. Asset Prefix（资源路径）

`next.config.ts` 通过 `resolveAssetOrigin()` 自动检测部署环境并设置 `assetPrefix`：

| 环境 | 资源路径示例 |
|------|------------|
| Vercel Production | `https://finalround-nextjs.vercel.app/_next/static/...` |
| Vercel Preview | `https://{deployment-url}/_next/static/...` |
| 本地开发 | `/_next/static/...`（相对路径） |

可手动覆盖：设置 `ASSET_PREFIX` 环境变量。

## 5. 数据流

```
src/data/companies/{slug}.json (146 个文件)
        ↓
    index.ts（barrel，auto-generated by scripts/generate-company-index.mjs）
        ↓
    company-layoffs.ts（loader: all / bySlug / forBrowse）
        ↓
    queries.ts（async wrapper for page components）
        ↓
    [slug]/page.tsx（SSG: generateStaticParams + Metadata + JSON-LD + render）
        ↓
    CompanyLayoffPage.tsx（React 组件渲染所有模块）
```

**关键规则**：
- `index.ts` 自动生成，绝不手动编辑
- 新增/删除 JSON 后必须 `npm run build`（prebuild 自动重新生成 barrel）
- 所有消费者通过 `@/lib/local-data/company-layoffs` 获取数据

## 6. JSON-LD（自动生成）

每个公司详情页自动生成三种结构化数据：

| Schema 类型 | 来源字段 |
|------------|----------|
| BreadcrumbList | Hardcoded: Home → Tech Layoffs → {company_name} |
| FAQPage | `content.faq.items` |
| NewsArticle | `content.seo` + `updated_at` |

生成逻辑在 `src/app/tech-layoffs/[slug]/page.tsx`，Bella 不需要手动维护 JSON-LD。

## 7. SEO 配置

| 配置项 | 来源 |
|--------|------|
| `metadataBase` / `siteUrl` | `NEXT_PUBLIC_SITE_URL` 环境变量（默认 `https://finalroundai.com`） |
| canonical | `content.seo.canonical`，未填则自动生成 `{siteUrl}/tech-layoffs/{slug}` |
| OG Image | `content.seo.ogImage`，未填则使用 `defaultOgImage`（R2 存储） |
| Hub Title | Hardcoded: `2026 Tech Layoffs Tracker — 146 Companies | Final Round AI` |
