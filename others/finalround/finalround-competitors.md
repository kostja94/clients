## 1.7 Interview Sidekick 详情（优先构建页）

> 用于构建 Interview Sidekick alternative / 对比页。URL 建议：`/interview-sidekick-alternative` 或 `/interview-sidekick-vs-final-round`。

| 项目 | 内容 |
|------|------|
| **官网** | interviewsidekick.com |
| **Slogan** | Practice Better, Interview Easier |
| **定位** | AI 面试练习 + 实时面试助手（双模式） |
| **用户规模** | 170K+ 活跃用户；案例：Amazon、Google、Meta |
| **核心功能** | **Real-Time Assistant**：Stealth overlay（屏幕共享不可见）、Live 音频转录、基于简历的上下文答案建议；**Mock Practice**：10K+ 公司真题、按目标公司与岗位定制、即时 AI 反馈（grammar、clarity）、STAR 框架；行为/技术/案例面试 |
| **定价** | 免费：1 场、2 分钟录制限制；付费：无限场次、无时长限制、全公司/岗位、详细反馈、优先支持；无需信用卡即可开始 |
| **免费工具** | Tell Me About Yourself 等答案生成器；interviewsidekick.com/tools |
| **关键页面** | /realtime_interview_assistant（实时助手）、/interview_prep（Mock 练习） |
| **Final Round 差异化** | 10M+ vs 170K 用户（均为官方宣称）；多平台（LeetCode、HackerRank、CodeSignal 等编码平台）；全流程（Resume、Auto Apply）；60 分钟/场 vs 2 分钟免费限制 |
| **可强调对比点** | 场次/时长限制、平台覆盖、编码面试支持、全流程价值 |

## 4. Final Round AI 差异化与 Gaps

| 差异化点 | 说明 |
|----------|------|
| **100% Invisible** | 屏幕共享时不可见；部分竞品（Parakeet）可被检测 |
| **10M+ 用户（官方宣称）** | 规模背书；多数竞品为新兴 |
| **全流程** | Copilot + Mock + Report + Resume + Auto Apply |
| **多平台** | Meet、Zoom、Teams、LeetCode、HackerRank、CodeSignal、CoderPad、CodePen、Mercor |
| **合规** | SOC 2、CCPA、GDPR 进行中 |

| Gap（竞品可 exploit） | Final Round 应对 |
|----------------------|------------------|
| 定价高（Premium $99/月）、场次有限 | 强调品牌、10M+ 用户（官方宣称）、全流程价值 |
| 部分来源称无 post-session analytics | 官网有 Interview Report；需核实 |
| AI hallucination（案例题） | 持续优化模型 |
