## 四、程序化 SEO 模板设计

### 4.1 模板结构

| Section | 内容要求 | 数据字段 |
|---------|----------|----------|
| **Intro** | H1「{X} Music Generator」+ 1–2 段匹配搜索意图 | genre_name, description |
| **Explore More** | 4 个相关风格/维度内链 | related_slugs[4] |
| **Evidence block** | 子风格/子类列表（4–8 项）+ 每项简短描述 | subgenres[] |
| **Why You Need** | 5 个通用卖点（可微调） | — |
| **Discover More Tools** | 工具内链（Music Agent、Virtual Artist、MV 等） | — |
| **How to Make** | 3 步流程（对话式创作） | — |
| **FAQ** | 4–5 个问题，含「What is {X} Music Generator?」「Is it royalty-free?」 | genre_name |
| **CTA** | Create {X} Music Now | genre_name |

### 4.2 数据字段定义

| 字段 | 类型 | 说明 |
|------|------|------|
| slug | string | URL 路径，如 funk、80s、guitar |
| genre_name | string | 显示名称，如 Funk、80s、Guitar |
| description | string | 1–2 段专属描述，300+ 词 |
| subgenres | array | 子风格列表，每项含 name、description、link |
| related_slugs | array | 4 个相关页 slug |
| target_keywords | array | 目标关键词 |

### 4.3 内容要求（Programmatic SEO）

- **300+ 词/页**：避免 thin content
- **Evidence block**：每页专属子风格/子类列表，非通用互换
- **内链**：Hub → 各 spoke；Spoke → Hub；同维度互链
- **Schema**：FAQPage、ItemList（子风格列表）
- **Tunee 差异化**：强调对话式创作、无需 prompt、无需乐理、AI music agent

## 五、内链规划（Hub-and-Spoke）

```
/music-agent（Hub）
  ├── /music-generator/funk
  ├── /music-generator/jazz
  ├── /music-generator/rock
  ├── /music-generator/edm
  └── ... 所有 music-generator 页

/music-generator/funk
  ├── /music-agent
  ├── /music-generator/jazz（相关风格）
  ├── /music-generator/disco（相关风格）
  ├── /music-generator/rnb-soul（相关风格）
  ├── /features/music-video-generator
  └── 子风格 → /music-agent（带 genre 参数）
```

**原则**：Hub → 各 spoke；Spoke → Hub + 同维度 3–4 个；子风格链至创作入口。
