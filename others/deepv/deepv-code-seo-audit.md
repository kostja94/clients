## 一、SEO 问题检查

### (一) Technical 技术优化

1. **索引情况检查**
   - 绑定 Google Search Console，查看已索引与未索引页面。
   - 分析未收录原因并逐项优化（目前除首页外无收录）。

2. **Canonical 标签配置**
   - 确保每个页面设置唯一且正确的 Canonical 标签。
   - 解决内容重复带来的权重分散问题。

3. **URL 规范化**
   - 统一 URL 结尾格式：要么全部加 "/"，要么全部不加。
   - 例如：`https://dvcode.deepvlab.ai/` 和 `https://dvcode.deepvlab.ai/login` 需要统一。

4. **301 重定向 / 内链优化**
   - 将 `https://www.deepvlab.ai/products/code` 重定向到 `https://dvcode.deepvlab.ai/`。
   - 所有指向旧 URL 的内链替换为新 URL。

### (二) 页面内容优化

1. **H 标签结构规范**
   - 页面仅保留 1 个 H1。
   - 副标题使用 H2/H3，保证层级清晰。
   - H 标签内容包含核心关键词，提升相关性。

2. **Meta 信息优化**
   - 为每个页面配置唯一的 Title 和 Description。
   - Title：控制在 55-60 字符，覆盖核心关键词。
   - Description：150-160 字符，兼顾自然与长尾关键词。
   - 避免重复，确保差异化展示。

### (三) 多语言优化

1. **小语种单独页面**
   - 为小语种用户建立独立页面（如西语、德语等）。
   - 例如：`https://dvcode.deepvlab.ai/zh`。

2. **Hreflang 标签配置**
   - 在页面中添加 Hreflang 标签，帮助搜索引擎识别不同语言/地区版本。
   - 确保语言版本之间互相关联，避免重复收录。
   - 参考：[Google Hreflang 指南](https://developers.google.com/search/docs/specialty/international/localized-versions?hl=zh-cn)

## 三、分阶段 SEO 执行计划

### 第一阶段（1–3 个月）：技术打底与内容起步

**目标**
- 完成技术优化，保证收录基础
- 启动长尾流量获取，用博客快速测试关键词覆盖

**核心任务**

1. 技术优化
   - GSC & Bing Webmaster 接入，检查收录与索引情况
   - 统一 URL 规范，修复 Canonical，避免重复收录
   - 合并低质量页面，做好 301 重定向
   - 内链梳理：从首页和功能页指向核心博客文章

2. 内容布局
   - 明确定位：以 "AI coding assistant" 为核心，主攻「编程学习 + 工具使用 + 提效技巧」场景
   - 启动博客内容：每月输出 8-10 篇教程/实操文，覆盖低竞争长尾词，例如：
     - "Best AI tools for Python beginners"
     - "How to debug code with AI assistants"
     - "AI tools for faster JavaScript coding"
   - 功能页保持最小化，仅做产品介绍和转化承接

3. Schema 优化
   - 给博客添加 FAQ、HowTo Schema，提升 AI & Google 收录率

### 第二阶段（4–6 个月）：内容集群与权威建设

**目标**
- 通过长尾内容形成集群，增加网站权威度
- 借助外链与社区曝光，提升收录和信任度

**核心任务**

1. 内容扩展 — 建立主题集群：
   - 「AI + 编程语言」系列：AI for Python / Java / C++ / Frontend / Backend
   - 「AI + 开发场景」系列：AI for debugging / testing / documentation / code review
   - 「AI + 学习者」系列：Best AI coding tools for students / bootcamps / self-learners
   - 每个集群至少产出 5-8 篇内容，互链形成内链闭环

2. 外链与 PR
   - 在 Reddit (r/learnprogramming, r/coding)、Hacker News 发起教程话题
   - 在 AI 工具导航站和 SaaS 工具目录上架，增加外链
   - 投放 Guest Post，面向 "developer productivity / AI tools" 博客

3. AI 收录优化
   - 在长尾博客中自然埋设问答式段落（What is the best AI tool for debugging?）
   - 增加截图、代码片段，提升可读性与 SEO 新鲜度

### 第三阶段（7–12 个月）：长尾收割与行业话语权

**目标**
- 在 "AI coding assistant" 类相关搜索中形成高频曝光
- 让博客成为开发者寻找「AI 编程解决方案」时的内容首选

**核心任务**

1. 长尾词收割 — 扩展覆盖「工具榜单 + 教程 + 对比」三类长尾：
   - "Top 10 AI coding assistants in 2025"
   - "Deepcode vs Cursor: Which AI coding tool is better?"
   - "Step-by-step: Using AI to build your first website"
   - 每月更新高表现文章，增加关键词变体

2. 品牌曝光
   - 在知名编程媒体（Dev.to、Medium、Hashnode）发布二次内容，导流回站
   - 参与开发者大会/社区话题，让品牌主动出现在开发者讨论中

3. 数据监控与优化
   - 重点关注排名 20-50 的文章，通过小幅优化（内部链接、关键词覆盖）推动进入前 10
   - 跳出率高的内容增加 FAQ、实操案例，降低流失
