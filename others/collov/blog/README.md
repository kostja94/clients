## 命名与 Frontmatter

| 约定 | 说明 |
|------|------|
| 文件 | `NN-{slug-kebab}-2026.md`（序号 + slug + 年份） |
| `slug` | **不含年份**，常青 URL，例如 `best-virtual-staging-software` → `/blog/best-virtual-staging-software` |
| `title` | 可含年份与主意图词，供 SERP 使用 |
| `author` | 统一 **`Kostja`** |
| `related` | 其他博文的 `slug` 数组 |

**内链与外链规范**：[internal-external-links-checklist.md](./internal-external-links-checklist.md)（对齐 [内容-信息增量-笔记.md](../../内容-信息增量-笔记.md) 的成稿自检）
