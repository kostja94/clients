## 2. 直接竞品详解

### 2.1 BoxBrownie

| 项目 | 内容 |
|------|------|
| **定位** | 房产照片编辑、虚拟软装、平面图、360° 虚拟软装 |
| **优势** | 人工设计、复杂场景、定制风格、360° 虚拟软装、无限修改、无订阅按张付费 |
| **限制** | 48 小时交付；$24/张起，规模化成本高；非 AI 实时 |
| **Collov 机会** | 15 秒 vs 48 小时；$19/月 60 张 vs $24/张；AI 实时、多工具（季节/Twilight/泳池/草坪） |

### 2.2 Apply Design

| 项目 | 内容 |
|------|------|
| **定位** | AI 虚拟软装、家具移除、多角度一致性 |
| **优势** | 18,000+ 家具目录、10 分钟交付、无限修改、多角度一致性 |
| **限制** | $10.50/张，高于 Collov 按量；10 分钟 vs Collov 15 秒 |
| **Collov 机会** | 速度（15 秒）、订阅制性价比、多工具链（Virtual Tour、Photo Editing） |

### 2.3 REimagineHome

| 项目 | 内容 |
|------|------|
| **定位** | AI 室内设计全栈—虚拟软装、家具替换、杂物移除、景观、对话式 AI |
| **优势** | 功能广度、对话式 AI、批量上传、$14/月起 |
| **限制** | 与 Collov 功能重叠度高；Collov 有 Furniture Finder、Design Callout、360° 虚拟看房 |
| **Collov 机会** | 73% 更快售出数据、10,000+ 经纪信任、MLS 合作、多风格（Scandinavian/Modern/Luxury） |

### 2.4 StageHQ

| 项目 | 内容 |
|------|------|
| **定位** | AI 虚拟软装、30 秒出图 |
| **优势** | $0.28/张低价、30 秒、30+ 风格、73% 更快售出 |
| **限制** | 工具链可能不及 Collov（无 Virtual Tour、Cabinet/Flooring、Furniture Finder） |
| **Collov 机会** | 多工具一体化、1M+ 用户、MLS 合作、企业级支持 |

### 2.5 Palazzo

| 项目 | 内容 |
|------|------|
| **定位** | 低价 AI 虚拟软装 |
| **优势** | <$1/房间、30 秒、对标 BoxBrownie/Stuccco/PadStyler |
| **限制** | 功能深度可能不及头部 |
| **Collov 机会** | 品牌信任、10,000+ 经纪、多风格、照片编辑+虚拟看房 |
