## 4. 品牌 SEO 优化（collov.com 首位）

### 4.1 品牌搜索现状

| 来源 | 典型结果 |
|------|----------|
| **collov.com** | Collov Labs — Visual Intelligence Substrate |
| **collov.ai** | Collov AI — 虚拟软装、房产视觉 |
| **第三方** | Growjo、Tracxn、Trustpilot、SaaSCounter、LinkedIn 等 |

**问题**：collov.com 与 collov.ai 可能同时竞争「Collov」；第三方页面分散点击；历史实体可能造成混淆。

### 4.2 品牌搜索意图（Moz 框架）

| 意图 | 用户行为 | 优化重点 |
|------|----------|----------|
| **Navigational** | 直接访问官网 | collov.com 首页、Title 明确 |
| **Informational** | 了解公司、研究、产品 | About、Research、News、FAQ |
| **Transactional** | 试用/购买产品 | 链至 collov.ai，不抢产品页 |

## 5. 优化清单

### 5.1 collov.com On-Page

| 项目 | 建议 |
|------|------|
| **Title** | `Collov Labs — The Visual Intelligence Substrate \| AI Research & Products` |
| **Meta Description** | 含「Collov Labs」、Research、Products、Partners，150–160 字符 |
| **H1** | 明确「Collov Labs」或「The Visual Intelligence Substrate」 |
| **URL** | 首选 https://www.collov.com/，确保 www 与非 www 301 统一 |
| **Canonical** | 首页 canonical 指向首选 https://www.collov.com/ |

### 5.2 collov.com 内容与结构

| 项目 | 建议 |
|------|------|
| **About 页** | 独立 /about，公司介绍、创始人、成立时间、定位；链至 collov.ai、CozyAI |
| **Products 页** | 产品矩阵（Collov AI、CozyAI、Intelligent Capture），每产品链至对应官网 |
| **Research 页** | 论文列表、会议、链接；可考虑 collov.com/research 或链至 collov.ai/research |
| **News/Events** | 活动、合作、媒体报道；增加「Collov Labs」品牌提及 |
| **FAQ** | 如「What is Collov Labs?」「What is Collov AI?」等，FAQ Schema |

### 5.3 collov.ai 差异化（不抢品牌首位）

| 项目 | 建议 |
|------|------|
| **Title** | 保持 `Collov AI — ...` 或 `AI Virtual Staging \| Collov AI`，避免首页 Title 仅「Collov」 |
| **About** | 增加「Collov AI is a product of [Collov Labs](https://www.collov.com)」 |
| **Footer** | 增加「© Collov Labs」或「A Collov Labs Product」+ 链至 collov.com |
| **Schema** | SoftwareApplication 中 `author` 或 `publisher` 指向 Collov Labs 组织 |

### 5.4 其他渠道

| 渠道 | 优化建议 |
|------|----------|
| **LinkedIn** | 公司页名称「Collov Labs」、官网链接 collov.com |
| **GitHub** | 组织 README 含「Collov Labs」、链至 collov.com |
| **Hugging Face** | 组织简介链至 collov.com |
| **Crunchbase / 新闻稿** | 统一使用「Collov Labs」、官网 collov.com |
| **品牌 SERP** | 自有资产（官网、社媒、GitHub）尽量占据首屏 |

## 6. 技术 SEO 要点

### 6.1 Title / Meta

- **Title**：`Collov Labs — The Visual Intelligence Substrate | AI Research & Products`
- **Description**：`Collov Labs builds self-evolving visual intelligence systems. Research at ICLR, AAAI, ICML. Products: Collov AI (real estate), CozyAI. Intel, Qualcomm, Epic partners.`

### 6.2 Schema（JSON-LD）

```json
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "Collov Labs",
  "url": "https://www.collov.com",
  "description": "The Visual Intelligence Substrate. Self-evolving AI systems for high-fidelity creativity.",
  "foundingDate": "2021",
  "sameAs": [
    "https://github.com/collovlabs",
    "https://huggingface.co/Collov-Labs",
    "https://www.linkedin.com/company/collov-labs/"
  ],
  "subOrganization": [
    {
      "@type": "SoftwareApplication",
      "name": "Collov AI",
      "url": "https://collov.ai",
      "applicationCategory": "DesignApplication"
    }
  ]
}
```

### 6.3 内链与权威（Hub-Spoke）

- collov.com 作为 **Hub**，链至 collov.ai、CozyAI、Intelligent Capture
- collov.ai 在 About/Company 等页明确标注「Collov Labs 旗下」，链回 collov.com
- 避免 cannibalization：collov.com 不抢 collov.ai 的「virtual staging」等产品词

### 6.4 技术

- **Sitemap**：collov.com/sitemap.xml 含所有重要页
- **robots.txt**：允许爬取
- **Core Web Vitals**：LCP、FID、CLS 达标
