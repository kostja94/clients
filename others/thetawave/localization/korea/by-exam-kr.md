## 二、各考试页详情

### 2.1 공무원 9급 — P0

**URL**: /ko/use-case/korean-civil-service-9-prep

**痛点**：
- **5과목 동시 부담**：국어·영어·한국사 + 선택 2과목(행정법·행정학·경제학 등)을 한 시험에서 동시에 대비 — 과목마다 요구하는 정리 방식이 다르다（문법 암기 vs 그래프 해석 vs 판례 구조화）
- **방대한 암기량**：행정법 조문 번호·한국사 연호·국어 한자성어·영어 숙어 등 순수 암기 요소가 수천 개에 달함
- **단권화 문제**：과목별 교재+강의노트+기출오답이 흩어져 시험 직전 통합 정리가 어려움
- **기출 회독 관리**：과목별 기출 회독 횟수와 오답률을 체계적으로 추적할 도구 부족
- **MZ 공시생 증가**：대면 학원보다 인강+독학 비중 증가 → 디지털 도구 전환 수요 높음（출처: 공단기·해커스공무원 트렌드 리포트）

**ThetaWave 能力**：
- 5과목 통합 지식 베이스：국어 문법·한국사 사건·행정법 판례 → `/feature/notes-generator` 에서 PDF 교재·필기노트 업로드 → 과목별 구조화 노트 자동 생성
- 실시간 강의 캡처：인강/현강 수강 중 → **AI Note Taker（홈페이지）** 로 음성→텍스트 변환 → LaTeX 수식 지원（경제학 그래프 수식도 자동 인식）
- 과목별 플래시카드：한국사 연표·행정법 조문·영어 숙어 → `/feature/flashcard-maker` 로 생성 → 간격 반복（Spaced Repetition）자동 적용
- 기출 오답 퀴즈：기출문제 PDF 업로드 → `/feature/quiz-maker` 로 과목별 모의고사 자동 생성 → 오답 문항만 재시험
- 비교 인포그래픽：경제학 이론 비교·행정학 모형 비교 → `/feature/infographics-generator` 로 한 장 정리
- 출퇴근 청취：정리한 노트 → `/feature/podcast-generator` 로 오디오 변환 → 이동 시간 활용

**Proof**：2025년 공무원 9급 출원 105,339명（인사혁신처）；2026년 경쟁률 105:1, 7년 만의 반등；한국 공시생 평균 준비 기간 2년；「공무원 시험」「공무원 공부법」네이버 월간 검색량 10만+（네이버 데이터랩）

**vs ChatGPT / NotebookLM**：
- vs ChatGPT：한국 공무원 시험 특화 과목（행정법·행정학）맥락 이해 부족；5과목 통합 학습 관리 기능 없음
- vs NotebookLM：무료이나 한국어 특화 부족；행정법 조문·한국사 연표 특화 플래시카드 자동 생성 없음；과목별 진도 추적 불가

**竞品参考**：

| 竞品 | 模式 | ThetaWave 差异化 |
|------|------|-----------------|
| 공단기（Gongdangi） | 1위 공무원 인강 플랫폼, 기출문제 앱 제공 | 강의 플랫폼; ThetaWave는 어떤 인강/현강이든 음성→노트 변환 |
| 해커스공무원（Hackers） | 인강+교재+모의고사, 공무원 커뮤니티 1위 | 학습 콘텐츠 제공자; ThetaWave는 내 자료를 정리·변환하는 도구 |
| Orzo（Sling） | 80만+ 다운로드, 태블릿 기반 문제풀이+AI 첨삭 | 수능·공무원 문제풀이 특화; ThetaWave는 강의→노트→카드 전환에 강점 |
| 나는공시생（카페） | 공시생 정보 공유 커뮤니티 | 커뮤니티; ThetaWave는 학습 생산성 도구 |

**关键词**：공무원 시험 공부법, 공무원 노트 정리, 공무원 플래시카드, 행정법 암기, 한국사 연표 암기, 공시생 AI 도구, 9급 공무원 독학, 공무원 시험 과목별 정리

**长尾机会**：「행정법 조문 플래시카드」「경제학 그래프 노트 정리」「국어 문법 한 장 요약」「공무원 오답노트 AI」「9급 영어 숙어 암기카드」「한국사 왕조별 정리 노트」「행정학 이론 비교 인포그래픽」

### 2.2 공무원 7급 — P0

**URL**: /ko/use-case/korean-civil-service-7-prep

**痛点**：
- **1차 PSAT 장벽**：9급과 달리 1차에 PSAT（공직적격성평가）통과 필수 — 언어논리（독해+논증）·자료해석（표/그래프 계산）·상황판단（법규 해석+의사결정）, 단순 암기로 풀 수 없는 추론형 문제
- **자료해석 시간 압박**：25문항 60분 — 복잡한 표·그래프를 빠르게 분석·계산해야 함, 실전 속도가 합격을 좌우
- **2차 주관식 전환**：전통적 객관식 과목들이 주관식（서술형）으로 전환 중 — 키워드 암기 넘어 논리적 서술 능력 필요
- **판례·조문 데이터베이스**：7급 행정법은 판례 출제 비중 높음 — 판례 요지·쟁점·결론의 구조화된 정리 필요

**ThetaWave 能力**：
- PSAT 자료해석 특화：복잡한 통계표·그래프 PDF → `/feature/infographics-generator` 로 시각화 → 주요 수치·증감률·비율 한눈에 정리
- PSAT 언어논리：지문 → `/feature/mind-map-maker` 로 논증 구조 시각화 → `/feature/quiz-maker` 로 논리 추론 연습 문제 생성
- PSAT 상황판단：법령·규정 텍스트 → 구조화 노트 → `/feature/mind-map-maker` 로 의사결정 트리 생성
- 2차 주관식 답안 연습：모범답안 → `/feature/notes-generator` 로 「목차·논점·결론」템플릿화 → 반복 학습
- 판례 데이터베이스：판례 PDF 업로드 → `/feature/flashcard-maker` 로 사건명·판결요지·쟁점·적용법조 자동 생성

**Proof**：2025년 7급 출원 약 26,000명（인사혁신처）；PSAT 합격선 매년 상승 추세；5급·7급·민경채 PSAT 동일 출제 경향 — 7급 합격 후 5급 도전 시 재활용 가능

**vs ChatGPT / NotebookLM**：
- vs ChatGPT：PSAT 자료해석 표 계산·그래프 해석 정확도 낮음；한국 공무원 시험 제도 최신 정보 부족
- vs NotebookLM：PDF 기반 노트 가능하나, PSAT 추론 훈련·자료해석 속도 훈련 기능 없음

**竞品参考**：

| 竞品 | 模式 | ThetaWave 差异化 |
|------|------|-----------------|
| PSAT 전문 인강（윌비스·베리타스） | PSAT 특화 강의 + 기출문제 | 강의 콘텐츠; ThetaWave는 내 학습 자료를 내 방식으로 변환 |
| 해커스 PSAT | PSAT 전문 교재+인강 | 교재 기반; ThetaWave는 기출 오답을 플래시카드화 |
| 5급 공채 카페 | 합격 수기·자료 공유 | 커뮤니티; ThetaWave는 학습 관리 도구 |

**关键词**：7급 공무원 PSAT, PSAT 자료해석 공부법, PSAT 언어논리 정리, 7급 행정법 판례, 공무원 2차 주관식, PSAT 상황판단 연습, 7급 공무원 독학

**长尾机会**：「자료해석 표 계산 연습」「PSAT 기출문제 노트 정리」「행정법 판례요지 플래시카드」「7급 행정학 주관식 답안 연습」「PSAT 60분 시간 관리」「상황판단 법령 해석 연습」

### 2.3 한국사능력검정시험 — P0

**URL**: /ko/use-case/korean-history-exam-prep

**痛点**：
- **순수 암기의 압박**：선사~현대까지 방대한 한국사 지식을 연대기·제도·인물·사건별로 암기 — 이해보다 「누가·언제·무엇을」이 핵심
- **시대별 분리와 통합**：고대·고려·조선·근현대 각 시대의 정치·경제·사회·문화사를 분리 학습 후 통합해야 함
- **헷갈리는 제도·연호**：조선 행정제도·토지제도, 일제강점기 조직, 현대 헌법 개정사 등 유사 항목 간 혼동
- **사료 해석 문제**：제시된 역사 사료를 읽고 시대·사건·의미 추론 — 단순 암기 넘어 문맥 이해 필요
- **단기 집중 수요**：많은 수험생이 시험 1-2개월 전 벼락치기 준비 — 고효율 암기 도구 필요

**ThetaWave 能力**：
- 시대별 플래시카드：고대·고려·조선·근현대별 정치·경제·사회·문화 카드 → `/feature/flashcard-maker` 로 자동 생성 → 간격 반복 알고리즘으로 효율적 암기
- 연표 인포그래픽：주요 사건 연표 → `/feature/infographics-generator` 로 시각화 → 왕조별 변천사 한눈에 정리
- 사료 분석 노트：사료 PDF/TEXT 업로드 → `/feature/notes-generator` 로 구조화 → 「시대·주체·사건·의미」4단계 프레임 정리
- 오답 퀴즈：기출문제 PDF 업로드 → `/feature/quiz-maker` 로 모의시험 생성 → 틀린 문제만 반복 테스트 → 시대별 약점 파악
