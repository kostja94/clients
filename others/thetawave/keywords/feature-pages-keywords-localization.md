## 说明

| 列 | 用途 |
|----|------|
| **界面短名** | 按钮 / 导航 / 模块标题可用 |
| **P1** | **全站可重复**的头词、类目词（title / H1 / 首屏）；允许与竞品、类目共有。 |
| **P2 · P3** | **建议每页唯一主推**：P2=该功能场景与格式；P3=再长尾、再具体；**勿在多张功能页复制同一句**。 |

**站内分工原则（防 cannibalization）**

- **P1**：可出现「AI、笔记、generate」等泛词；无需强行全站不重复。  
- **P2 / P3**：按 **输入形态 + 使用场景 + 产物形态** 拆分——例如「讲座 / 线下课堂」只给 Lecture 页；「时间轴 / 合集」只给 YouTube；「教材引用 / OCR」只给 PDF；「间隔重复 / 闭卷」只给 Flashcard 与 Quiz 各管一半。  
- 若产品与文案一致，同一意图只在一个 URL 承担「主优化」，其它页面用 **参阅 / 内链** 交接，勿重复堆同一长尾。

**语种代码**：`en` `de` `es` `fr` `it` `pt` `ja` `ko` `zh-Hans` `zh-Hant`。**简繁勿混用**。

**复核**：各语言市场用 Keyword Planner / Trends 看 P1；P2/P3 以 **站内唯一性** 优先于「多塞同义词」。
