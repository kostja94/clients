### 1. 段落节奏多样性

#### 1.1 段落类型与功能

| 类型 | 长度 | 功能 | Glossary 文角色 |
|------|:---:|------|------|
| **长段落（论证型）** | 4–8 句，80–200 词 | 解释机制、case walkthrough、深度分析 | **主干**——承载工程案例和失败模式分析 |
| **中段落（过渡型）** | 2–4 句，40–80 词 | 引出话题、桥接论证 | **关节**——连接定义节和深度节 |
| **短段落（节奏型）** | 1–2 句，15–40 词 | 强调关键观点 | **锚点**——技术文章也需要阅读节奏 |

#### 1.2 健康标准

| 检查项 | 健康 | 警告 | 红线 |
|------|------|------|------|
| 长段落（≥4 句） | ≥3 个 | 1–2 个 | 0 个 |
| 连续短段（≤2 句） | ≤2 个连续 | 3 个 | ≥4 个 |
| 短段全文占比 | 15%–25% | 25%–35% | >35% |
| 段落标准差（句数） | ≥1.5 | 1.0–1.5 | <1.0 |
| 每节叙事重量 | 每 H2 至少 1 个 ≥3 句段落 | 个别节全是短段 | 3+ 节全是短段 |

### 2. 列表使用策略

#### 2.1 决策框架

| 信息特征 | 格式 |
|------|------|
| 有序/优先关系 | **有序列表** |
| 并列、无顺序 | **无序列表** |
| 多维对比 | **表格** |
| 需逻辑连接才能理解 | **段落** |
| 去掉连接词会损失含义 | **段落** |

#### 2.2 列表质量检查（7 项）

| # | 检查项 | 标准 |
|---|------|------|
| LQ1 | 有前导句 | 列表前必须有完整句子说明目的 |
| LQ2 | 并列结构 | 所有项语法结构一致 |
| LQ3 | 项长度相近 | 最长/最短 ≤3 倍 |
| LQ4 | 项 ≤2 句话 | 超过即应写成段落 |
| LQ5 | 列表后有分析 | ≥2 句分析 |
| LQ6 | 无单一项 | 1 bullet = 段落 |
| LQ7 | 重复词提取 | 多项同词开头→提取到前导句 |

#### 2.3 列表占比上限

| 类型 | 上限 | 说明 |
|------|:---:|------|
| GlossaryTerm | **25%** | 定义文以叙事段落为主 |
| GlossaryComparison | **25%** | 对比表不算列表；对比分析须段落 |

### 3. 碎片化反模式（6 类）

| 类型 | 检测方法 | 红线 |
|------|------|:---:|
| **连续短段集群** | ≥3 个连续 ≤2 句段落 | ≥2 处 ❌ |
| **片段拼贴** | 连续 3 段可互换顺序 | 打乱后通顺 ❌ |
| **列表轰炸** | 相邻 2+ H2 各含列表无分析 | ≥3 连续 ❌ |
| **裸表格** | 表格前后无分析段落 | ≥3 处 ❌ |
| **过渡缺失** | 抽样 10 段衔接率 | <50% ❌ |
| **段落标准差过低** | 全段句数标准差 <1.0 | <1.0 ❌ |

**不通过项加权合计 >30% → Presentation 维度 ≤4/10。**

### 4. 段间衔接

#### 4.1 衔接手段

| 手段 | 示例 | 频率 |
|------|------|:---:|
| 过渡词 | "然而""此外""具体来说" | 每 3–4 段 ≥1 次 |
| 句子桥 | 上段关键信息开下段 | 关键论证必用 |
| 关键词重复 | 下段开头重复上段核心词 | 每节 2–3 次 |
| 逻辑推进 | 因果/递进/转折 | 全文主线 |

#### 4.2 衔接率

连续 10 段，每对相邻段至少一种衔接手段。**健康线 ≥70%。**

### 5. Glossary 文特有节奏模式

#### 5.1 定义节（§1 canonical）节奏要求

定义节是 glossary 文最重要的 SEO 段。必须：
- 前导段（2–4 句）引入术语背景
- blockquote 定义（150–200 词 snippet-ready）
- 分析段（3–5 句）展开定义边界、what it is not
- 禁止：H2 后直接 blockquote → 裸 blockquote = 裸列表的变体

#### 5.2 对比表（§3 GlossaryComparison）节奏要求

- 表前导语说明"这个表回答什么问题"
- 表后 ≥3 句分析："哪一行适合什么场景、为什么"
- 禁止：表格 + 一句话跳到下节

#### 5.3 深度节（§5–7 GlossaryTerm）节奏要求

每节至少 1 个 4–8 句长段落做 case walkthrough 或失败模式分析。深度节是 glossary 文区别于教科书的核心——如果深度节只有 bullet point，整篇退化为列表罗列。

### 6. Phase 5 SelfCheck — Presentation 维度打分

| 分数 | 标准 |
|:---:|------|
| **10** | 长/中/短段自然交替；列表 ≤25% 且有分析；≥3 长段；衔接率 ≥70%；0 碎片化集群 |
| **7** | 节奏基本合理；列表未过度（≤35%）；1–2 长段；衔接偶有断裂 |
| **4** | ≥2 碎片化区域；列表 >40%；衔接率 <50% |
| **1** | 全文 bullet 堆砌；零叙事节奏 |

### 7. 12 项 Master Checklist

**Block 1：段落节奏（4 项）**

| # | 检查项 | 标准 |
|---|------|------|
| P1 | 长段落 ≥3 | 全文 ≥3 个 ≥4 句段落 |
| P2 | 连续短段 ≤2 | 无 ≥3 连续 ≤2 句段 |
| P3 | 标准差 ≥1.5 | 句数有显著差异 |
| P4 | 每节 ≥1 中/长段 | 每 H2 至少 1 个 ≥3 句段 |

**Block 2：列表（4 项）**

| # | 检查项 | 标准 |
|---|------|------|
| P5 | 列表有前导句 | 无裸列表 |
| P6 | 列表后有分析 | ≥2 句分析 |
| P7 | 项并列结构 | 语法一致 |
| P8 | 列表 ≤25% | GlossaryTerm / Comparison 上限 |

**Block 3：衔接与表格（4 项）**

| # | 检查项 | 标准 |
|---|------|------|
| P9 | 表格前后有分析 | 前后各 ≥2 句 |
| P10 | blockquote 有上下文 | 定义 blockquote 前后有引导/分析段 |
| P11 | 衔接率 ≥70% | 连续 10 段 ≥7 对有衔接 |
| P12 | H2 后有引导 | 首段说明本节回答什么 |
