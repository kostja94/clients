## 1. 产品信息

### 产品定位

**Medeo** 是典型的 **AI Video Agent**（AI 视频智能体）：通过聊天理解意图、自主规划工作流、端到端生成视频，无需传统拍摄、剪辑软件或技术背景。用户用文字描述想法，AI 自动完成脚本、配音、画面、音乐、剪辑，3–10 分钟产出 HD 1080p 即用视频。100+ 专用生成器覆盖博客、脚本、社交、游戏、营销、教育等全场景。

*AI Video Agent 定义*：理解用户意图、分解任务、自主执行多步工作流、支持迭代优化，区别于单次 prompt→输出的简单生成器。*来源：[Personate](https://blog.personate.ai/how-to-use-ai-video-agent-the-2026-guide-to-personate/)、[LifeInside](https://www.lifeinside.io/insights/ai-video-agents-vs-traditional-video)*

### 目标受众

- **内容创作者**：短视频、营销素材、TikTok/Reels/Shorts
- **营销/品牌**：广告、宣传片、UGC、产品视频
- **教育**：解说视频、课程、培训
- **创作者**：动画短片、Meme、游戏剪辑、创意内容

### 核心产品线

| 产品/功能 | 说明 |
|-----------|------|
| **Chat-based Creation** | 文字聊天即创作，If you can text, you can create；**Agent 式**：理解意图→规划→执行→输出 |
| **Chat-based Editing** | 语音/文字指令编辑：「加快这部分」「换音乐」即时生效；**迭代优化**，无需重做 |
| **Character Consistency** | 锁定角色身份，在新场景/动作/情绪中保持视觉一致 |
| **100+ AI Generators** | 博客、脚本、图片、URL、Idea、Meme、游戏、营销、教育等 |
| **Content Repurposing** | Blog/Article/PDF/Slides/URL/Tweet/LinkedIn/Podcast → Video |
| **The Visual Track** | 可视化轨道，音轨、字幕、素材同步 |
| **Flexible Exports** | 16:9、9:16 多比例，MP4、GIF |
| **移动端应用** | iOS、Android，手机端创作、即拍即用；[Download](https://www.medeo.app/download) |

### 差异化优势

- **AI Video Agent 形态**：理解意图、自主规划、端到端执行，非单次 prompt 生成器；支持迭代优化
- **聊天即创作**：If you can text, you can create；无需时间线编辑、无需技术背景
- **100+ 专用生成器**：按场景/任务选择，覆盖娱乐、营销、教育、内容再利用
- **3–10 分钟**：从概念到 HD 1080p 即用视频；传统制作 $5,000–15,000/条可降至数十美元
- **角色一致性**：AI 生成角色保持视觉一致性
- **多模型**：Sora 2、Kling、Minimax Hailuo 等
