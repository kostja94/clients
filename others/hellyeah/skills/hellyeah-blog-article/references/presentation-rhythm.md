### 1. 段落节奏多样性

#### 1.1 段落类型与功能

| 类型 | 长度 | 功能 | 在 blog 中的角色 |
|------|:---:|------|------|
| **长段落（论证型）** | 4–8 句，80–200 词 | 解释机制、论证观点、展开案例 | **主干**——承载核心论证 |
| **中段落（过渡型）** | 2–4 句，40–80 词 | 引出话题、总结前文、桥接论证 | **关节**——保持阅读流畅 |
| **短段落（节奏型）** | 1–2 句，15–40 词 | 强调观点、制造节奏断点 | **锚点**——让关键信息凸显 |

> **核心原则**：单一节奏 = 单调。全文段落都在 3–4 句 → 读者 30 秒进自动驾驶。

#### 1.2 段落节奏健康标准

| 检查项 | 健康标准 | 警告线 | 红线 |
|------|------|------|------|
| 长段落（≥4 句）数量 | ≥3 个 | 1–2 个 | 0 个 |
| 连续短段落（≤2 句）上限 | ≤2 个连续 | 3 个连续 | ≥4 个连续 |
| 短段落在全文占比 | 15%–25% | 25%–35% | >35% 或 <5% |
| 段落长度标准差（句数） | ≥1.5 | 1.0–1.5 | <1.0 |
| 每节段落多样性 | 每 H2 至少 1 个中或长段落 | 个别节全是短段落 | 3+ 节全是短段落 |

### 2. 列表使用策略

**列表是 blog 中被滥用最严重的格式。问题不是列表本身——是用列表逃避论证。**

#### 2.1 列表使用决策框架

| 问题 | 如果是 → |
|------|------|
| 信息之间有顺序或优先关系？ | **有序列表**（1. 2. 3.） |
| 信息之间是并列关系、无顺序？ | **无序列表**（bullet） |
| 信息之间有对比/多维度关系？ | **表格** |
| 信息之间需要逻辑连接才能理解？ | **段落** |
| 去掉连接词会损失含义或 nuance？ | **段落** |
| 读者需要快速扫描而非深度理解？ | **列表** 或 **表格** |
| 这是需要论证的观点而非事实罗列？ | **段落** |

#### 2.2 列表质量检查（7 项）

| # | 检查项 | 标准 | 常见 Fail |
|---|------|------|------|
| LQ1 | 有前导句 | 每个列表前必须有完整句子说明目的 | 裸列表——H2 后直接跟 bullet |
| LQ2 | 并列结构 | 所有列表项语法结构一致 | 混用动词/名词开头 |
| LQ3 | 列表项长度相近 | 最长项与最短项差异 ≤3 倍 | 一项 5 词、一项 40 词 |
| LQ4 | 列表项 ≤2 句话 | 超 2 句本质是段落——去掉 bullet | 列表项是完整段落 |
| LQ5 | 列表后必有分析 | 紧跟 ≥2 句分析（"这意味着什么？"） | 列表后直接跳到下个 H2 |
| LQ6 | 无单一项列表 | 1 bullet = 段落不是列表 | 单 bullet 当列表用 |
| LQ7 | 重复词提取 | 多项同词开头 → 提取到前导句 | 每项 "You can..." |

#### 2.3 列表占比上限（按文章类型）

| 文章类型 | 列表段落上限 | 说明 |
|------|:---:|------|
| Pillar | 25% | 深度分析应以叙事段落为主 |
| Framework | 30% | 方法论可适度列表，核心论证须段落 |
| CommercialEducational | 35% | 教育文列表可稍多 |
| PlatformExplainer | 35% | 平台能力可列表呈现 |
| Alternative | 30% | 对比表非列表；对比分析须段落 |
| UseCase | 30% | 场景 + 能力列表可接受 |
| Diagnosis | 30% | 瓶颈排查可列表 |
| Compliance | 25% | 决策者需要完整论证 |

> **计算方式**：包含列表的段落数 ÷ 正文总段落数。编号 H2 不计入——只计内容段落中的列表块。

### 3. 碎片化反模式检测

碎片化 = 大量短段落 + 孤立列表拼贴，缺乏叙事脉络。AI 生成 blog 的头号特征。

#### 3.1 碎片化 6 类型

| 类型 | 表现 | 检测方法 | 阈值 |
|------|------|------|:---:|
| **连续短段落集群** | ≥3 个连续 ≤2 句段落 | 扫描全文标注 | ≥2 处 → ❌ |
| **片段拼贴** | 连续 3 段可互换顺序 | 打乱段落检查语义 | 打乱后通顺 → 拼贴 |
| **列表轰炸** | 相邻 2+ H2 各含列表无分析 | 扫描相邻 section | ≥2 个连续 → ⚠️；≥3 → ❌ |
| **裸表格/列表** | 表格/列表前后无分析段落 | 前后 50 词检测 | ≥3 处 → ❌ |
| **过渡缺失** | 相邻段无衔接手段 | 抽样 10 段检查衔接率 | <50% → ❌ |
| **段落标准差过低** | 全文段落长度标准差 <1.0 | 计算全段句数标准差 | <1.0 → ❌ |

#### 3.2 碎片化综合评分

| 检测项 | 权重 | 通过 | 部分通过 | 不通过 |
|------|:---:|------|------|------|
| 连续短段落集群 | 30% | 0 处 | 1 处 | ≥2 处 |
| 过渡衔接率 | 25% | >70% | 50%–70% | <50% |
| 列表轰炸 | 20% | 0 处连续 | 1 处连续 | ≥2 处连续 |
| 裸表格/列表 | 15% | 0 处 | 1–2 处 | ≥3 处 |
| 段落长度标准差 | 10% | ≥1.5 | 1.0–1.5 | <1.0 |

不通过项加权合计 **>30% → Presentation 维度直接 ≤4/10**。

### 4. 段间衔接与过渡

#### 4.1 衔接手段分类

| 手段 | 示例 | 频率 |
|------|------|:---:|
| **过渡词/短语** | "然而""此外""因此""具体来说" | 每 3–4 段 ≥1 次 |
| **句子桥** | 上段关键信息开下段："这种模式不仅出现在 A——在 B 中更为明显。" | 关键论证段之间必用 |
| **关键词重复** | 下段开头重复上段核心词或变体 | 每节 2–3 次 |
| **指代词回指** | "这个发现""这些数据""这种策略" | 适度，确保指代明确 |
| **逻辑推进** | 因果/递进/转折/例证关系自然推进 | 全文主线 |
| **预告/回望句** | 段末一句话预告下段 | 重大转折 1–2 次 |

#### 4.2 衔接率检测

连续 10 个正文段，每对相邻段至少一种衔接手段 → 衔接率。**健康线 ≥70%**（Yoast 建议 30% 句子含过渡词；段落层面应更严格）。

#### 4.3 常见衔接断裂

| 模式 | 表现 | 修复 |
|------|------|------|
| **H2 后直接列表** | H2 → 立即 bullet，无过渡 | 加 1–2 句引导段 |
| **表格后直接下节** | 表格 → 空行 → 下个 H2 | 表格后 ≥2 句分析 |
| **连续裸转折** | 连续段以 "However""But" 开头 | 中间加正面论述 |
| **段落跳话题** | 上段竞品能力，下段突然定价 | 加桥接句 |

### 5. 表格使用规范

#### 5.1 何时用/不用

**用表格**：多维度对比、信息按两轴定位、读者需并排比较数值

**不用表格**：仅 1–2 行数据、内容全为完整句子、仅为 "看起来更丰富"

#### 5.2 表格质量检查

- [ ] 表前有导语（"这个表告诉你什么"）
- [ ] 表后有 ≥2 句分析（"这个表意味着什么"）
- [ ] 表头清晰、列名非技术缩写
- [ ] 禁止 "表格 + 一句话然后跳下节" 空壳

### 6. Phase 5 SelfCheck — Presentation 维度打分

| 分数 | 标准 |
|:---:|------|
| **10** | 长/中/短段自然交替；列表 ≤ 类型上限且有前后分析；≥3 长段；衔接率 ≥70%；0 碎片化集群；读起来像人写的 blog |
| **7** | 节奏基本合理；列表未过度（≤35%）；1–2 长段支撑论证；衔接偶有断裂但整体流畅 |
| **4** | ≥3 处碎片化区域；列表 >40%；≥3 连续段 <3 句；衔接率 <50% |
| **1** | 全文 bullet 堆砌；零叙事节奏 |

**Health Check 维度 #3 (Presentation & Rhythm) 评分即基于此标准。**

### 7. Phase 5 快速自检（12 项 Master Checklist）

#### Block 1：段落节奏（4 项）

| # | 检查项 | 标准 |
|---|------|------|
| P1 | 长段落 ≥3 | 全文 ≥3 个 ≥4 句分析性段落 |
| P2 | 连续短段 ≤2 | 无 ≥3 个连续 ≤2 句段落 |
| P3 | 段落标准差 ≥1.5 | 句数有显著差异 |
| P4 | 每节 ≥1 中/长段 | 每 H2 section 至少 1 个 ≥3 句段落 |

#### Block 2：列表使用（4 项）

| # | 检查项 | 标准 |
|---|------|------|
| P5 | 列表有前导句 | 无裸列表 |
| P6 | 列表后有分析 | ≥2 句分析段 |
| P7 | 列表项并列结构 | 语法一致 |
| P8 | 列表占比合理 | ≤ 类型上限 |

#### Block 3：衔接与多媒体（4 项）

| # | 检查项 | 标准 |
|---|------|------|
| P9 | 表格前后有分析 | 前后 50 词各 ≥2 句分析 |
| P10 | 多媒体间有段落 | 相邻多媒体元素间 ≥1 分析段 |
| P11 | 衔接率 ≥70% | 连续 10 段 ≥7 对有衔接手段 |
| P12 | H2 后有引导 | H2 后首段说明本节回答什么问题 |
