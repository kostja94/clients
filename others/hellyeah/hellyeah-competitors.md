## 7. AI Ads Manager 子品类（公开页面参考）

**用途**：AIMA 落地页（[/aima](https://www.hellyeahai.com/aima)）将自身与 agency/SaaS/chat 对照（见 [hellyeah-platform-aima.md](./hellyeah-platform-aima.md)）。本节归档市场上典型 **「AI 广告管理 / 优化 / 统一视图」** 产品的**官网公开表述**，供 battlecard、博客教育稿、与 AIMA 边界说明使用。**非完整竞品清单**；功能与定价以各站为准，引用前须二次核实。

### 7.1 跨渠道视图 + 归因 + 站内操作（例：Cometly）

| 维度 | 摘要 |
|------|------|
| **页面** | [AI Ads Manager \| Cometly](https://www.cometly.com/features/ads-manager) |
| **定位** | 用准确数据做更聪明的投放决策；发现头部计划、AI 放量建议、挖掘易忽略洞察。 |
| **能力要点（页面模块）** | **Chat AI**：围绕广告表现与策略问答；**Manage & Optimize**：在 Cometly 内调预算、暂停差计划、放量优质计划，无需切换广告平台；**Unified Ad View**：多广告平台同一仪表盘 + 一致归因；**多触点归因**：模型与转化窗口可切换；转化画像（Conversion Profiles）、客户旅程（Customer Journeys）、LTV 持续追踪；自定义指标/列、按日拆解、广告层级下钻、交易与 LTV 归因等。 |
| **明示接入的广告平台** | Meta、Google、TikTok、LinkedIn、Pinterest、Microsoft Bing、Snapchat、X 等（站内 *Ad Platform Integrations* 区）。 |
| **与 AIMA 叙事对照** | 偏 **测量 + 统一控制台 + AI 分析师/建议**；全站另有 Server-Side Tracking、Conversion Sync、Analytics 等。Hellyeah 若强调 **增长资本跨渠道自主配置 + 多代理编排**，需在内容中写清与「广告账户操作台」类产品的**层级差异**（须产品确认）。 |

### 7.2 Meta 侧放量与自动化（例：Koast）

| 维度 | 摘要 |
|------|------|
| **站点** | [Koast](https://koast.ai/) |
| **定位** | 面向规模化团队的 **Meta 广告**发布与自动化（*Profit Focused Media Buying*）；加快上线、自动化琐事、不增人头扩产出。 |
| **能力要点** | 模板化文案/定向/预算；多广告账户同步发布；与 Drive/Dropbox 等素材库；约 **每 5 分钟**预算检查、日内调整、止损类自动化；角色权限、按账户活动日志、中心化创意库。 |
| **主渠道** | 文案聚焦 **Meta / Facebook Ads**；非「全渠道增长栈」表述。 |
| **定价叙事** | 订阅制，强调 **不按广告消耗百分比收费**（以官网当前页为准）。 |
| **与 AIMA 叙事对照** | **单平台深度运营 / 发布效率** vs **全栈增长引擎中的资本配置层**；Koast 页脚对比 [Madgicx](https://www.madgicx.com/)、Revealbot 等，选题时可并列参考。 |
