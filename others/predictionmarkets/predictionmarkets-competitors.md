## 1. 竞品概览

### 1.1 交易平台（predictionmarkets.org 覆盖对象）

| 竞品 | 网站/应用 | 核心定位 | 主要优势 | 定价/费用 |
|------|-----------|----------|----------|-----------|
| **Polymarket** | [polymarket.com](https://polymarket.com/) | 全球最大预测市场 | $21.5B+ 年交易量（2025）、零交易费、政治/宏观/地缘、94%+ 准确率、YES/NO 合约、加密原生 | 0% 交易费、1.5% 提现费 |
| **Kalshi** | [kalshi.com](https://kalshi.com/) | CFTC 持牌预测市场 | $17.1B+ 年交易量（2025）、美国合规、央行/政策引用、体育/经济/政治、91% 体育量 | ~1.74% 有效费率（$17.4/千$） |
| **PredictIt** | predictit.org | 学术/政治预测 | 93% 准确率（Vanderbilt）、政治市场、$850 限注 | 10% 利润费 + 5% 提现费 |
| **B3（巴西）** | b3.com.br | 巴西首个获批预测市场 | CVM 批准、金融证券 | 待定 |
| **Opinion** | opinion.xyz | Web3/BNB 预测市场 | 去中心化、BNB Chain、社区治理 | 待定 |
| **Manifold** | manifold.markets | 免费虚拟货币预测 | play-money、社区创建、无真实资金 | 免费 |
| **Metaculus** | metaculus.com | 社区预测平台 | 非交易、预测锦标赛、研究导向 | 免费 |

*2025 年预测市场总交易量超 $44B，Polymarket + Kalshi 约占 85–90%。*

**结算规则**：Polymarket 国际用 UMA Oracle / 美国用平台判定；Kalshi 用 Source Agencies（NFL/NBA、BLS、NOAA 等）。详见 [predictionmarkets-events.md](./predictionmarkets-events.md) §3、[predictionmarkets-features.md](./predictionmarkets-features.md) §八。

## 2. 直接竞品详解

### 2.1 Polymarket

| 项目 | 内容 |
|------|------|
| **定位** | 全球最大预测市场，加密原生，二元 YES/NO 合约 |
| **优势** | 零交易费、$21.5B+ 年交易量（2025）、周交易量超 $1.5B、政治/宏观/地缘/加密货币、94%+ 准确率（提前一月评估）、Gnosis Conditional Token、实时 API |
| **市场类型** | 政治、经济、地缘（伊朗、$425M 单周地缘）、加密货币价格区间（BTC/ETH/SOL）、娱乐、体育 |
| **限制** | 美国前端受限；监管模糊；近期内幕交易争议（Bloomberg、NPR 报道） |
| **定价** | 0% 交易费、1.5% 提现费 |
| **predictionmarkets.org 机会** | 中立指南、平台对比、监管解读、事件专题（地缘、大选） |

*来源：[Polymarket](https://polymarket.com/)、[predictionmarkets.org](https://www.predictionmarkets.org/)、Bloomberg、CoinDesk*

### 2.2 Kalshi

| 项目 | 内容 |
|------|------|
| **定位** | 美国 CFTC 持牌 Designated Contract Market，合规预测市场 |
| **优势** | $17.1B+ 年交易量（2025）、美国合规、央行/政策制定者引用（经济预测）、91% 体育量、选举/经济/政策/天气/体育/娱乐/加密货币 |
| **市场类型** | 2026 世界杯、2028 总统提名、体育冠军、地缘事件、特朗普 SOTU 演讲（$11.97M 单日量） |
| **限制** | 仅美国用户、KYC、交易费率约 1.74%；近期内幕交易案（MrBeast 编辑、加州州长候选人） |
| **定价** | 约 $17.40/千$ 仓位（50% 赔率） |
| **predictionmarkets.org 机会** | 合规解读、Kalshi vs Polymarket 对比、经济预测应用 |

*来源：[Kalshi](https://kalshi.com/)、[predictionmarkets.org](https://www.predictionmarkets.org/)、NPR、Bloomberg*

### 2.3 PredictIt

| 项目 | 内容 |
|------|------|
| **定位** | 学术/政治预测市场，小规模 |
| **优势** | Vanderbilt 研究 93% 准确率（高于 Kalshi 78%、Polymarket 67%）；$850 限注或有助于价格发现 |
| **限制** | 规模小、10% 利润费 + 5% 提现费、政治为主 |
| **predictionmarkets.org 机会** | 准确率对比、政治市场专题 |

## 3.2 监管与法律（CLARITY Act、No-Action）

| 项目 | 内容 |
|------|------|
| **CLARITY Act** | 2025 年立法，确立联邦预测市场框架；event contracts 归类为商品衍生品 |
| **CFTC 管辖** | Kalshi 持牌；Polymarket 美国前端受限；PredictIt 宽松监管 |
| **Kalshi 胜诉** | 2025.5 CFTC 撤诉；选举预测不构成「博彩」 |
| **No-Action Letters** | 2025.12 Polymarket、PredictIt 等获豁免 |
| **州级** | 亚利桑那、加州、乔治亚、伊利诺伊等州有诉讼 |

*详见 [predictionmarkets-features.md](./predictionmarkets-features.md) §十、[predictionmarkets.md](./predictionmarkets.md) §5.2*
