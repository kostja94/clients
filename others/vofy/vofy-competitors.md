## 一、赛道坐标

| 类型 | 代表产品 | 与 Vofy 的重叠 |
|------|-----------|----------------|
| **多模型创作工作台** | [Leonardo.ai](https://leonardo.ai/)、部分 [Kaiber](https://kaiber.ai/) 历史心智 | 强：一站式生成、模型上新运营；差异看 **视频广度** 与 **Apps 长尾密度** |
| **视频-first 生成** | [Runway](https://runwayml.com/)、[Pika](https://pika.art/)、[Luma Dream Machine](https://lumalabs.ai/) | 强：短片、运动与镜头语言；Vofy **同时吃进图像工作流与数百微工具** |
| **开发者向媒体 API** | [fal](https://fal.ai/)、各家云原生 | 重叠：接上类似 **Kling/Veo**/开放模型管线；Vofy **偏消费 Web + Credits**，非典型 API-first |
| **换脸 / 特效工具站** | 各类 「AI filter」「AI hug video」单站 | Vofy **`/apps` 合集**可把流量留在同一品牌漏斗 |
| **官方模型 Playground** | OpenAI ChatGPT/DALL-E、Google AI Studio… | 关系：底层模型提供方 vs **第三方聚合 UI** |

## 二、差异化叙事（站面可引用方向）

| 维度 | Vofy 公开主张线索 | 撰写时注意 |
|------|-------------------|------------|
| **breadth（广度）** | 图像 **+** 视频 **+** Motion Control **+** Inpaint **+** `/apps` 海量场景 | 「工具数量」会变 — 抓取日期标注 |
| **模型新鲜度** | What's New **密集**挂载多家前沿名 | 上新节奏快则 SEO 短文机会多，也需防止页面过时 |
| **价格心智** | Veo **Lite**、「Flash speed」、Credits 明码示例（2.5） | 与用户分辨率/时长耦合，勿写死绝对最便宜 |
| **社区** | 首页 Community + Discord | UGC 与教程生态若持续运营可形成复利 |
| **风险面** | 亲密互动、身体塑形类工具偏多 | **青少年 / 肖像权 / 平台政策** 为竞品也常踩的红线 — 内容上主动合规 |

## 三、可能的内容角度（SEO / PLG）

- **教程**：Seedance vs Kling vs Sora——同一 prompt 三本对比（水印与版权自理）。  
- **Apps 聚类**：Outfit & Hair、Headshots——做「hub 页」统领内链至子工具。  
- **转化**：Credits 计算器（估算 10 条短片成本）——需与后端报价同步。

## 四、监视列表（情报）

- Runway/Pika/Kling/Veo/Sora **公众开放档位与比价**月度快照。  
- Google / TikTok **AI 合成内容披露政策**对各「爆款模版」广告投放的影响。  
- 竞品是否加码 **移动端 App** 或 **API**，稀释「纯 Web 合集」护城河。
