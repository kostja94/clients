## 2. 直接竞品详解

### 2.1 ElevenLabs（官网 Leaderboard 对比对象）

| 项目 | 内容 |
|------|------|
| **定位** | 高质量 TTS、语音克隆 |
| **优势** | 音质行业领先；盲测 9/12 无法区分真人；ELO 1548 |
| **限制** | 单一模型；需单独注册；名人声音有限 |
| **VoiSpark 机会** | 多模型聚合——ElevenLabs 作为选项之一；700+ 声音；15 秒克隆；一站式切换 ElevenLabs/Cartesia/MiniMax |

### 2.2 PlayHT

| 项目 | 内容 |
|------|------|
| **定位** | TTS、语音克隆、多语言 |
| **优势** | API、流式、多语言 |
| **限制** | 与 VoiSpark 场景重叠 |
| **VoiSpark 机会** | 多模型、名人库、情感标签、15 秒克隆 |

### 2.3 Murf AI

| 项目 | 内容 |
|------|------|
| **定位** | TTS、视频配音、团队协作 |
| **优势** | 易用、模板、企业功能 |
| **限制** | 偏视频配音，非纯 TTS 聚合 |
| **VoiSpark 机会** | 创作者专注、多模型、名人声音 |

### 2.4 Cartesia（VoiSpark 集成模型）

| 项目 | 内容 |
|------|------|
| **定位** | 实时 TTS、40ms 延迟 |
| **优势** | 超低延迟、context-aware、adaptive voice |
| **限制** | 需 API 单独集成 |
| **VoiSpark 机会** | VoiSpark 已集成 Cartesia；用户无需单独注册 |
