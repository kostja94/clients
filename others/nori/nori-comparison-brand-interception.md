# Nori — 对比页与品牌词截留全图

> **本文档职责**：汇总**所有可能与 Nori 形成搜索交集的竞品**（Web / 移动 App / 硬件 / 单功能工具），用于 **Nori vs X**、**X alternative**、**best …** 等页面的选题与 URL 规划，**截留竞品品牌词与替代意图流量**。  
> **引用**：深度矩阵与定价见 [nori-competitors.md](./nori-competitors.md)；Photo/Email/Voice→Calendar 工具链见 [nori-calendar-converter.md](./nori-calendar-converter.md)；关键词落地见 [nori-keywords.md](./nori-keywords.md)；**对比 slug 与整站优先级对齐**见 [nori-site-structure.md](./nori-site-structure.md)；产品形态见 [nori.md](./nori.md)。  
> **维护规范**：[元文档-通用文档规范.md](../../../通用知识库/元文档-通用文档规范.md) | 通用-多文件文档联动精炼与增量循环.md

**原则**：事实描述竞品；价格与功能以对方官网为准并标注更新日期；避免贬损商标。单功能竞品优先用 **功能页 + 文内对比** 或 **独立 Nori vs 短文**；全场景家庭组织竞品优先 **独立对比页**。

## 0. 优先级定义（流量 / 品牌认知）

| 级别 | 含义 | 定性依据（具体 MSV 以 Ahrefs / SEMrush / GSC 校准） |
|------|------|-----------------------------------------------------|
| **P0** | 最先做 | **全球或美国大众级认知**（Google、Amazon、OpenAI）；或 **垂直品类头部**（Cozi、Skylight、Paprika、AnyList）；或 **下载/曝光量级第一梯队**共享日历（TimeTree）；或 **功能词下第一品牌**（Photo2Calendar、Sense 邮件日历） |
| **P1** | 其次 | 品类重要玩家、墙显第二梯队、高意向垂直工具、购物/餐食细分头部 |
| **P2** | 再后 | 长尾品牌、区域/小众 App、仅适合 listicle 一条 |
| **P3** | 按需 | 提及即可、不单独建站 |

## 6. 统一对比维度（可复用）

**全场景 App**：共享日历、任务/家务、餐食/食谱/购物、输入方式（语音/照片/邮件）、价格与免费边界、平台（Web/iOS/Android）、硬件路线。  
**单功能工具**：输入类型、是否支持家庭共享、是否与日历/餐食打通、价格。  
**硬件**：屏幕尺寸、挂载方式、订阅、日历来源、是否含任务/餐食、与手机 App 协同。
