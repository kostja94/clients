## 3. 直接竞品

**核心区分**：Lessie 采用 **Agent 形态**（理解意图、多源搜索、全流程自主、反馈学习）；部分竞品以数据库+筛选器为主，用户需手动构建条件、分步提取。

| 竞品 | 优势领域 | Lessie 机会 |
|------|----------|-------------|
| **Apollo** | B2B lead generation、sales intelligence | people search AI agent、自然语言、多场景、全流程 agent |
| **LinkedIn Sales Navigator** | find people、LinkedIn search | LinkedIn alternative、replace manual search、AI agent 自动化 |
| **Lusha / RocketReach** | 联系人查找、数据库+提取 | Agent 形态：批量+全流程+AI 触达+反馈学习 |
| **Grin / CreatorIQ / Aspire** | influencer marketing platform | AI influencer discovery、automate influencer outreach、全流程 |
| **Clay** | 数据工作流、多源 | 可组合使用；Lessie 专注「找人」场景 |

## 6. Lessie 差异化

**核心定位**：找人（任何人）**Agent**——理解意图、多源搜索、维护上下文、全流程自主执行、从回复/预约等结果中反馈学习（[来源](https://lessie.ai/blog/why-build-people-search-ai-agent-part-2)）。相较数据库+筛选器模式，Agent 形态可贯穿全流程并持续优化。

| 维度 | Lessie | 市场常见形态 |
|------|--------|--------------|
| **产品形态** | AI agent：理解意图、自主执行、反馈学习 | 数据库+筛选器：用户构建条件、分步提取 |
| **搜索方式** | 自然语言、输入描述即出结果 | 手动筛选、多步操作 |
| **上下文** | 全流程维护上下文（intent→discovery→score→outreach→learn） | 各步骤相对独立 |
| **场景** | 找人（任何人）：网红、B2B、投资人、人才、Partner 一站式 | 多为单一场景（如 B2B 销售） |
| **自动化** | 发现→评分→触达全流程自主 | 多为发现或触达单点 |
| **数据源** | 100+ 数据源（LinkedIn、社交媒体、播客、公司网站、GitHub、YouTube 等） | 多为单一或有限数据源 |
| **程序化 SEO** | Profile Directory（500+ 人物档案）+ List Directory（100+ 预建列表）双子域 | 多为单点工具，无规模化程序化页 |
| **定价** | Basic $34 起，低于企业级工具 | 企业级工具多为 $100+/月 |
