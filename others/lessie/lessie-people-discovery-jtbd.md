## 3. Hub/Spoke、搜索意图与搜索量×商业化

八条 Solutions 为 **hub**；缺 **spoke** 则意图过泛，由 **lists**、**profile**、博客、垂直页承接。

### 3.1 何时拆成更细人群、场景或 URL

| 信号 | 说明 |
|------|------|
| **搜索量与转化集中** | 垂类词稳定且与注册/付费相关，值得独立承接（例：投资人主题、[/real-estate](https://lessie.ai/real-estate)） |
| **意图与泛页不一致** | 含地域、资产、赛道等；进泛 Client 易高跳出 |
| **可沉淀差异化内容** | ICP、示例 query、合规、案例可写清 |
| **适合可扩展 URL** | 与既有 **lists.*** / **profile.*** 信息架构一致时优先 spoke，而非堆导航 |

检索量极低、意图重复、无独立价值主张时 **不宜硬拆**。

### 3.2 Hub + Spoke 结构

- **Hub**：八条 Solutions（路径 **§2.2**）——品类/品牌、**commercial / transactional** 总述、信任、统一 CTA。  
- **Spoke**：程序化 → **lists.***；人物与主题 → **profile.***（含投资人等主题子站）；**informational** → **博客**；高价值垂直 → 行业/用例页（**独立承接例见 §3.1**）。  

**informational** 与 **transactional** 用 **页型** 拆分，非复制多个平级 Find X。

### 3.3 执行优先级

以 **GSC**、关键词规划工具与内部词表为依据：高展现低点击、高跳出时，再开 **垂直 spoke** 或加强内链；关键是 **spoke 与真实 query 对齐**。搜索量×商业化分预算与 **§1.2** 契合度三维叠用。

### 3.4 两维度定义

| 维度 | 含义 | 典型信号（站内为准） |
|------|------|---------------------|
| **搜索量 / SEO** | 需求广度与可承接 URL 量 | 月搜、SERP、GSC；lists/profile/博客是否可规模化 |
| **商业化价值** | 付费意愿、客单价、续约、与线索/融资/招聘的紧密度 | 定价、销售周期、竞品 ARPU |

### 3.5 公开市场（定性）

仅作赛道温度；**解读落到 §3.6「策略含义」列**，不在此重复逐条 Solutions。

- 红人平台：[Grand View Research](https://www.grandviewresearch.com/industry-analysis/influencer-marketing-platform-market)、[Fortune Business Insights](https://www.fortunebusinessinsights.com/influencer-marketing-platform-market-108880)  
- B2B lead gen：[Business Research Insights](https://www.businessresearchinsights.com/market-reports/lead-generation-software-market-120963)、[WiseGuyReports](https://www.wiseguyreports.com/reports/b2b-lead-generation-software-market)  

### 3.6 八条 Solutions 示意矩阵（定性）

| Solutions | 搜索量/SEO | 商业化 | 策略含义 |
|-----------|------------|--------|----------|
| Find Influencer | **高** | **中高** | 流量与列表/博客 spoke 主投之一 |
| Find Client | **中高**（大词卷） | **高** | SEO 差异化 + 销售/PLG |
| Find Investor | **中**（长尾强） | **高** | 权威内容 + Profile/List |
| Find Talent | **中高** | **中高** | recruiting 词簇、替代手动 LinkedIn 叙事 |
| Find Partner | **中偏低** | **中** | 垂直 spoke + 案例 |
| Find Coach | **中偏低** | **中偏低** | 长尾与品牌 |
| Find Distributor | **中偏低** | **中**（大单则高） | 与行业目录、列表协同 |
| Find Property Leads | **中**（地域×资产长尾） | **中高** | 垂直页 + 地产列表；合规与数据可信度影响转化 |

### 3.7 四象限决策（简）

1. **高搜索 + 高商业化**（部分 Influencer、Client 词簇）：P0；竞品多，突出 Agent、自然语言、一站式与相对「纯筛选器 + 导出」工具的差异化。  
2. **高搜索 + 中低商业化**（纯 how-to）：博客/FAQ 承接，导流至高商业化 Solutions。  
3. **中低搜索 + 高商业化**（典型 Investor、部分地产/大客户）：案例、销售素材、程序化长尾、精准页重于铺头词。  
4. **两维都偏低**：保留导航或合并子场景，避免独立大项目。

### 4.4 适合与需谨慎

与 **§4.3** 对照阅读；地产细节见 **§2.2**。

#### 4.4.1 高适合

- **营销/增长/电商**：多平台找红人、减手动整理。  
- **销售/BD**：规模化 cold outreach。  
- **招聘/HR**：自然语言描述候选人。  
- **创始人/融资**：筛投资人 + Investor 程序化页。  
- **合作拓展/活动/播客**：嘉宾、主办方、代理商。  
- **地产经纪/机构/开发商**：与 **§2.2** `/real-estate` 一致；依赖数据与合规。

**共性**：公开痕迹可聚合；任务可重复；「找到 + 能联系上」有 KPI。

#### 4.4.2 中等适合

- **教练/导师**：发现 + 首触为主；深度匹配与履约多在线下。  
- **学者背书**：先列发声者再建联；深度评价需专业源。  
- **仅专家名单、无 outreach**：发现层价值有限。

#### 4.4.3 低适合或需谨慎

强合规背调、金融级 KYC；强私域关系；极窄「只差一邮」场景。

## 5. 扩展落地页与红线

### 5.1 红线（有流量也不做 Lessie 营销页）

| 意图示例 | 搜索（定性） | 不适合原因 |
|----------|-------------|------------|
| 找前任/挽回/跟踪私人关系 | 情绪驱动词量**不低** | 非商业、骚扰与法律风险。**不做。** |
| 人肉、私人住址、非自愿联系方式、监控配偶 | people search 类**流量大** | data broker 赛道；与 GDPR/CCPA 叙事冲突；[GeeksforGeeks](https://www.geeksforgeeks.org/websites-apps/10-best-people-search-sites-to-find-someone-online/)、[HeroHunt](https://www.herohunt.ai/blog/10-best-people-search-apis-full-in-depth-guide/)。**划清界限。** |
| 纯私人失联同学 | informational 存在 | 供给在社交/校友网；冷 outreach 易侵扰。**不做主 spoke**；博客须中立。 |

**有搜索量 ≠ 可做页**：须过品牌、ToS、合规、产品匹配四筛。**People Search** 对外锚定 **professional / business / creator**；上表类 query 若有自然量，**noindex** 或**不建页**。

### 5.2 灰区：修表师等

| 变体 | 搜索（定性） | Lessie |
|------|-------------|--------|
| watchmaker near me / 修表附近 | 本地**强**，地图与点评占 SERP | **弱** |
| 品牌/机构找制表师合作 | 长尾**中偏低**；商业化**可高** | **中**：公开职业身份+机构+工作邮箱 → Partner/Client **垂直 spoke**；与「附近修表」**拆 URL** |

### 5.3 与 §6.2 的关系

尽调专家等仍在 **§6.2** 主表；**非「找人」主轴**（供应商名录、纯 ABM 岗、平台垂类达人、家办/合规等变体）已从主表 **删除**，改 **§3.2** lists、Hub 内模块或 **§6.3** 候选。全表 **承接 Hub** 仅 **§6.1** 已上线路径。
