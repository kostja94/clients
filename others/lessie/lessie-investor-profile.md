## 三、人物筛选原理与维度（供后续使用）

选人时优先覆盖**搜索量大的具体投资人姓名**，以下维度字段可用于排序与筛选：

| 维度 | 说明 | 字段（待用） |
|------|------|--------------|
| **搜索量** | [name] contact、[name] profile 月搜索量 | `search_volume` |
| **知名度** | 媒体曝光、社交媒体、投资案例 | `fame_score` |
| **可触达性** | 公开邮箱/Calendly、天使/早期、主动发声 | `approachability_score` |
| **信息丰富度** | 官网、Crunchbase、LinkedIn 等公开资料 | `info_richness` |
| **近期热度** | 新基金、新闻、榜单、热门赛道 | `recency_score` |
| **细分领域** | AI / FinTech / Biotech / Consumer 等 | `category` |
| **阶段** | Angel / Seed / Series A+ | `stage` |
| **国家/地区** | 不同国家的知名投资人；覆盖 US、UK、EU、India、China、SEA 等 | `country` / `region` |

**筛选流程**：按 `search_volume` 筛出高搜索量姓名 → 按 `info_richness` 确保可写内容 → 按 `approachability_score`、`recency_score` 加权排序。

**新主题页/人物选型**：基于新闻热度、搜索量、现有覆盖的完整逻辑见 §5.8。

### 5.8 新主题页/人物选型逻辑（供后续寻找）

> **用途**：定期寻找新主题页、新人物时，按此逻辑筛选，避免遗漏高价值机会。

#### 选型维度

| 维度 | 说明 | 信息来源 |
|------|------|----------|
| **搜索量** | [theme] investor、[name] contact 月搜索量 | Ahrefs、Semrush、Google Keyword Planner |
| **现有覆盖** | 177 人中可归入该主题的人数 | §1.4 类型统计、投资人名单 |
| **新闻热度** | 机构募资、大额融资、人物曝光 | Crunchbase、TechCrunch、Reuters、Fortune |
| **关键词意图** | 用户搜索「找谁」「找哪类」 | 竞品页面、GSC 查询 |
| **与 List 联动** | 是否有对应 List 可内链 | [lessie-lists.md](./lessie-lists.md) §2.2 |

#### 思考流程

```
1. 新闻追踪 → 哪些机构/人物/赛道近期有重大事件？
2. 关键词验证 → 对应搜索词（如 a16z crypto investor）是否有量？
3. 覆盖检查 → 现有 177 人能否支撑该主题页？
4. 优先级排序 → 搜索量 × 覆盖度 × 新闻热度
5. 决策 → 新建主题页 / 扩人后建 / 仅优化现有人物页
```

#### 新闻追踪思路

| 事件类型 | 示例 | 可产出 |
|----------|------|--------|
| **机构募资** | a16z $15B、a16z crypto $2B | 强化 a16z、a16z-crypto-investors 主题页 |
| **大额融资** | OpenAI $110B、Anthropic $30B | AI mega-deal investors、参与方人物页 |
| **人物曝光** | Marc Andreessen 2026 展望、Chris Dixon 领投 crypto 基金 | 优先/新增该人物页 |
| **赛道热点** | Voice AI（ElevenLabs）、World Model（AMI） | voice-ai-investors、alternative-ai-investors |
| **政策/趋势** | American Dynamism、Defense tech | defense-investors、american-dynamism-investors |

#### 信息源

- **融资/机构**：Crunchbase、TechCrunch、Reuters、Fortune、PitchBook
- **人物动态**：a16z Blog、机构官网、LinkedIn、播客（如 The a16z Show）
- **搜索量**：Ahrefs、Semrush
