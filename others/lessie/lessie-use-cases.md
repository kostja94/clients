## 六、场景合理性分析（基于网络搜索）

> 市场与竞品信息来源于 2025 年网络搜索；关键词与竞品见 [lessie-keywords.md](./lessie-keywords.md) §8。

### 6.1 Find Influencer

| 维度 | 分析 |
|------|------|
| **市场** | AI influencer discovery 为成熟赛道；78% 品牌使用多平台；influencer finder 与 influencer marketing platform 并存 |
| **竞品** | InfluencerMarketing.ai (IMAI)、Speeedy.ai、RoboGather、Gleemo（150M+ profiles）、Modash（350M+） |
| **关键词** | influencer finder, influencer discovery, AI influencer discovery, influencer marketing tool |
| **Lessie 契合度** | **高**。50M+ 网红、自然语言、跨 10+ 平台、全流程自动化；与竞品差异化在 People Search 多场景一站式 |
| **建议** | 强化 AI influencer discovery、automate influencer outreach；List 程序化覆盖 beauty/fitness/tech 等细分 |

### 6.2 Find Client

| 维度 | 分析 |
|------|------|
| **市场** | B2B lead generation 为高竞争赛道；Apollo 500K+ 公司、210M+ contacts；AI 自动化成标配 |
| **竞品** | Apollo、Salesly AI、Outlyst、Telescope（900M+ profiles） |
| **关键词** | B2B lead generation, AI lead generation, B2B lead generation tool, sales intelligence |
| **Lessie 契合度** | **高**。自然语言、100+ 数据源、3x 回复率；Basic $34 低于 Apollo 企业级定价 |
| **建议** | 布局 Apollo alternative、AI to find B2B leads；强调「replace manual LinkedIn search」 |

### 6.3 Find Investor

| 维度 | 分析 |
|------|------|
| **市场** | 找投资人工具增长快；AngelSearch、Fundverse、Getpantom、Doriot AI 等；Lessie 已被列为竞品 |
| **竞品** | AngelSearch（101K+ investors）、Fundverse（13K+）、Getpantom（200K+）、Doriot AI（70K+） |
| **关键词** | find investors, angel investor, AI investor matching, investor scouting, find angel investors for startups |
| **Lessie 契合度** | **高**。Lessie 官网已覆盖 investor-scouting；List 有 Early-stage AI Investors、Angel Investors 等 |
| **建议** | 强化 find angel investors、AI investor scouting；Profile 含主题聚合页（angel-investors、ai-investors 等），见 [lessie-investor-profile.md](./lessie-investor-profile.md) |

### 6.4 Find Talent

| 维度 | 分析 |
|------|------|
| **市场** | AI recruiting 成熟；Gem（650M+）、RecruitBot（655M+）、ScoutHub（400M+）；自然语言搜索成趋势 |
| **竞品** | Gem、Metaview、RecruitBot、Talen.ai、ScoutHub |
| **关键词** | talent sourcing AI, AI recruiting, AI recruiting tool, AI candidate sourcing |
| **Lessie 契合度** | **中高**。Lessie 有 recruiting 页、300K+ 候选人；竞品多为 ATS 集成、招聘专用 |
| **建议** | 差异化在「People Search 多场景」；可强调 replace Upwork/Fiverr/LinkedIn 手动搜索 |

### 6.5 Find Partner

| 维度 | 分析 |
|------|------|
| **市场** | Channel partner 发现工具较少；Airstride、PartnerOptimizer、PARTNER2B 等专注 B2B 渠道 |
| **竞品** | Airstride（AI partner sourcing）、PartnerOptimizer（NeuralPartner AI）、PARTNER2B（10K+ 公司） |
| **关键词** | find partners, channel partner finder, AI partner sourcing, business partner discovery |
| **Lessie 契合度** | **中**。Lessie 覆盖 event organizers、podcast hosts、agencies；与 Airstride 等偏渠道商不同 |
| **建议** | 明确「Partner」定义：活动组织者、播客主、代理商、合作方；与 Find Distributor 区分 |

### 6.6 Find Coach

| 维度 | 分析 |
|------|------|
| **市场** | Coach finder 为细分赛道；CoachFinder.ai、FindACoach.ai、Coacher 等；多为人工匹配或 AI 排名 |
| **竞品** | CoachFinder、FindACoach（ICF 认证）、Coacher（AI 排名） |
| **关键词** | find coach, coach finder, executive coach finder, find mentor |
| **Lessie 契合度** | **中**。Lessie 用 People Search 找教练，与竞品「平台匹配」模式不同 |
| **建议** | 强化 find coach、coach finder；List 有 Certified Fitness Coaches；可扩展 executive coach、career coach |

### 6.7 Find Distributor

| 维度 | 分析 |
|------|------|
| **市场** | 制造商找分销商；FindADistributor.com、Find-Distributor.com、Expandia 等；多为目录或顾问服务 |
| **竞品** | FindADistributor（北美物料搬运）、Find-Distributor（全球）、Expandia（500+ 分销商、60+ 国） |
| **关键词** | find distributor, distributor finder, channel partner directory, find distributors worldwide |
| **Lessie 契合度** | **中**。Lessie 用自然语言找 health tech、medical devices 等分销商；与行业目录互补 |
| **建议** | 明确目标：制造商/品牌方找渠道商；与 Find Partner（活动/播客/代理）区分 |
