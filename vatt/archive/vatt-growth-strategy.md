## 3. 战役节奏

### 短期（0–90 天）— 基建 + 种子用户

- **SEO 紧急补课**：
  - 添加 robots.txt + sitemap.xml
  - Features 页上线（展示 AI 高光检测 + 编辑流程 + 界面截图）
  - Privacy / Terms / About 页面
- **站外 SEO**：
  - Blog 启动，**优先 P0 五篇**（Try Not to Laugh → Types Hub → Live → Movie → TikTok）
  - 见 [vatt-reaction-video-types.md §11](../vatt-reaction-video-types.md)
  - 核心页面 meta title/description 优化
- **种子用户获取**：
  - 在 TikTok/YouTube 创作者社群中定向发放邀请码
  - 与 3-5 位中小型 reaction 创作者合作试用
- **产品 Demo 视频**：制作官方 2 分钟 Demo（传统 3 小时 vs Vatt 10 分钟 对比）

### 中期（90–180 天）— 口碑 + 内容飞轮

- **创作者合作扩大**：
  - 10-20 位 reaction 创作者正式合作，发布评测/教程
  - 在 TikTok/YouTube 上形成「Vatt 加速了我的 reaction 剪辑」的 UGC 口碑
- **内容 SEO 深化**：
  - Blog 扩至月度 4-6 篇
  - 制作 "Vatt vs [X]" 系列对比内容（vs Descript / vs Revid / vs 手动剪辑）
  - 制作 reaction 视频创作 101 系列教程
- **Product Hunt 发布**：选择合适时机正式发布
- **邀请裂变机制**：现有用户邀请新用户双方获 credits
- **定价透明化**：公开明确的套餐价格，降低决策摩擦

### 长期（180 天+）— 品类领导者

- **品类定义者地位巩固**：
  - 发布「Reaction Video Creator Report 2026」行业报告
  - 与 TikTok/YouTube 官方合作（创作者工具推荐）
- **团队/企业市场**：
  - 优化 Team 套餐功能（协作编辑、权限管理、批量处理）
  - 切入 MCN / 内容工作室客户
- **功能扩展**：
  - 字幕自动生成（Reaction 专属特效字幕模板）
  - 多机位同步（Reaction 面 + 被看画面自动时间对齐）
  - 直播 Reaction 实时高光标记
- **国际市场**：日/韩/东南亚 reaction 文化浓厚的市场本地化

## 4. 变现与留存

### 变现

- **Freemium → 付费**：免费 credits 体验 → 依赖形成 → 订阅 Starter/Pro
- **订阅层级**：推测 Starter（个人）→ Pro（重度用户）→ Team（团队）
- **年度折扣**：Annual 选项降价推年付锁定

### 留存

- **效率依赖**：一旦习惯 Vatt 的 10x 剪辑速度，回到手动剪辑几乎不可能（高切换成本）
- **素材积累**：媒体库中积累的 reaction 素材越多，换平台成本越高
- **作品成就感**：AI 帮找到自己都没注意到的高光反应 → 惊喜感 → 持续使用
- **社区**：构建 Vatt 创作者社区（Discord/Slack），分享剪辑技巧和作品
- **内容培育**：Blog 持续输出 reaction 创作技巧，培育创作者全生命周期

## 5. 技术 SEO 注意

| 项 | 现状 | 建议 |
|----|------|------|
| robots.txt | 404 不存在 | **紧急添加**，Allow 所有主要页面 |
| sitemap.xml | 未配置 | **紧急添加**，覆盖首页/定价/Features/Blog |
| meta description | **待验证** | 首页 + 所有子页添加 meta description |
| 结构化数据 | 无 | 添加 Organization / SoftwareApplication / FAQ Schema |
| Blog | 无 | 启用 `/blog`，建议用 MDX 或 CMS |
| 页面速度 | **待验证** | SPA 预渲染 / SSR 确保 SEO |
| 移动端 | **待验证** | 响应式设计确认 |
| 页面收录 | 仅 3 页 | 扩展至 20+ 页（Features + Blog + 合规） |
| Trust 页面 | Privacy/Terms 缺失 | **紧急添加**（Google 排名因素 + 用户信任） |
