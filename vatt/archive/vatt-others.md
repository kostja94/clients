## 5. Reaction 视频赛道背景（品类分析）

### 赛道规模

- **Reaction Video** 是 TikTok/YouTube Shorts/Instagram Reels 上最高互动率的内容格式之一
- YouTube 上 "reaction" 相关频道数以万计，头部频道订阅量可达千万级
- TikTok #reaction 标签浏览量数千亿次

### 创作者分布

| 平台 | Reaction 内容特征 | 剪辑痛点 |
|------|------------------|---------|
| TikTok | 短 reaction（1-3 分钟），快节奏 | 需快速出片追热点 |
| YouTube Shorts | 短 reaction（1 分钟以内），竖屏 | 同上 + 多平台分发 |
| YouTube（长视频） | 长 reaction（10-30 分钟），内容深度 | 素材 30-60 分钟，剪辑耗时巨大 |
| Instagram Reels | 短 reaction，偏视觉 | 同 TikTok |

### 创作者工作流（传统）

```
选题 → 录制（20-60 分钟）→ 回看素材（1-2 小时）→ 找高光（30 分钟-1 小时）
→ 粗剪（1-2 小时）→ 精修（30 分钟-1 小时）→ 导出 → 发布

总计：3-6 小时 / 条
```

### Vatt 优化后工作流

```
选题 → 录制（20-60 分钟）→ 上传 Vatt → AI 找高光+粗剪（数分钟）
→ 人工精修（10-20 分钟）→ 导出 → 发布

总计：20-30 分钟 / 条（实际 10x 提升）
```
