# TL;DR 质量修正方案 — 中文 Tools 页面

## 现状

110 个中文 tools 页面，多数违反 `content/sections/section-tldr.md` 的内容规范（完整 section 规范见 `项目文档/Alignify项目上下文/content/sections/`）。问题集中在 6 类：

| 类别 | 数量 | 严重程度 | 说明 |
|---|---|---|---|
| 截断（item 语意不完整） | 8 页 | 🔴 紧急 | "等主"、"等"、"、" 结尾 |
| 超大 item（>70 字） | ~32 条 | 🔴 需重写 | body 级别内容塞入 TL;DR |
| 超大 intro（>100 字） | 11 页 | 🟡 需修剪 | 超出规范 40-80 |
| item 中等超标（51-70 字） | ~70 条 | 🟡 需压缩 | 主要是"比较"模板 |
| intro 中等超标（81-100 字） | 44 页 | 🟢 微调 | 需剪 1-19 字 |
| 末尾 item 过薄（<20 字） | 8 页 | 🟢 需充实 | "搭配"模板 |

## 修正标准

基于 `content/sections/section-tldr.md` §2，定义可执行边界：

### Introduction（引导句）
- **目标区间**：40-80 字
- **严格上限**：80 字。80-90 字可临时容忍但不推荐，必须在修正轮次中逐步降低
- **下限**：40 字。低于 40 字意味着信息缺失

### Items（要点）
- **单条目标**：25-40 字
- **严格上限**：50 字。任何超出 55 字的条目必须压缩
- **列表工具可比项（item[1] 常见类型）**：上限 55 字（因英文品牌名不可缩减）
- **下限**：20 字。低于 20 字的条目必须充实
- **HTML 链接**：`<a href="...">...</a>` 计入字数，标签内包含的汉字全计

### 数量
- **严格 4-5 条**。超出此范围的必须调整

### 语意完整性（新增规则）
- 绝对不能以"等"、"等主"、"、"结尾（截断）
- 每条必须是一个完整的陈述句，能让读者独立理解

## 修正策略

### 6 个 Tier（按优先级）

#### Tier 1：修复截断（8 页）
修复方式：补全句尾到完整语意。"等主" → "等主流工具"；"等" → "等主流工具的功能与适用场景"；"、" → 补全最后一个工具名。

#### Tier 2：重写超大 item >70 字（~12 页）
这些条目包含 body 级别的细节（技术原理、行业数据、对比维度列表），不适合 TL;DR。重写策略：
- 移除具体数据（"NPS +99%、销售转化 +26%" → "已验证的业务效益显著"）
- 移除技术细节（"DDSP-SVC、iSTFTNet+VAE" → "主流实时变声架构"）
- 保留核心结论，把细节省给文章正文

#### Tier 3：重写超大 intro >100 字（11 页）
修剪至 80 字以内。策略：
- 移除并列的第二个场景句
- 将"覆盖内容创作、音乐制作等场景"简化为"覆盖内容创作与音乐制作等场景"
- 移除"也覆盖"句式

#### Tier 4：批量压缩"比较"模板（~60 页）
"比较 A、B、C、D、E 等主流工具的功能、定价与适用场景" → "比较 A、B、C、D、E。"

理由：TL;DR 的 item 不需要重复"功能、定价与适用场景"——"比较"一词已暗示了这些维度。可以省 8-12 字。

#### Tier 5：充实"搭配"模板（8 页）
"搭配视频编辑、视频翻译等工具" → 增加具体使用场景和效果。

#### Tier 6：中等 intro 81-100 字修剪（44 页）
机械性压缩：移除冗余副词（"非常"、"十分"）、合并并列短语、缩短长定语。

## 实施顺序

```
Tier 1（截断修复）   →  立即执行，8 页
Tier 4（比较模板批量）→ 可脚本化，与 Tier 1 并行
Tier 5（搭配充实）   →  8 页，与 Tier 1 并行
---
Tier 6（intro 微调） →  44 页，机械性操作
Tier 3（intro 重写） →  11 页，需要编辑判断
---
Tier 2（item 重写）  →  ~12 页，每页独立处理，最耗时
```

## 验收标准

执行完毕后，运行审核：
```bash
node ../../项目文档/Alignify项目上下文/scripts/ops/audit-tldr-length.mjs  # 预期：0 截断，0 >55 字 item，0 <20 字 item，0 >80 字 intro，0 <40 字 intro
```
