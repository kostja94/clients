## 使用方式

1. 编辑 `content/topics/{slug}.json` 前 → 读 `topics/{slug}.md`
2. 新建 topic 笔记 → 复制 [templates/knowledgehub/_template.md](../../templates/knowledgehub/_template.md)
3. 产品版本变更 → 更新所有引用该产品的 topic 笔记
