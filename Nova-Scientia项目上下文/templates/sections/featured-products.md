# Featured Products — 写作规则

TopicFeaturedProducts 区块（编辑章节之后、对比表之前）。

**字段定义**：[content-model.md](../../specs/content-model.md) · **内链规则**：[internal-links.md](../../knowledge/internal-links.md)

---

## 写作规则

- **数量**：3–6（推荐 4–5）；标题 `"Os N Melhores..."` 中 N 必须等于 items 数
- **选品**：仅含站内已有页 `/products/{slug}`； líder + 性价比 + 细分场景
- **name**：`"{Produto}: Diferencial em 3-5 palavras"`，每条 diferencial 唯一
- **description**：100–250 字符，突出竞争力，不重复 name
- **顺序**：最佳产品第一

---

## Checklist

- [ ] 标题数字 = items 数量
- [ ] 3–6 个有效 slug
- [ ] 每条 name 有唯一 diferencial
- [ ] description 100–250 字符
- [ ]  líder → 性价比 → 细分 组合
