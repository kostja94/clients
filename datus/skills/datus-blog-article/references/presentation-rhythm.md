## §PR — 表现形式与表达节奏（ToolsList 适配版）

> **Phase 2–4 加载**
>
> ToolsList 最容易退化为「短导语 + 多表堆砌」。Google HCU 惩罚 list/table-heavy 碎片内容；分类与选型须用段落承载判断。

---

### 1. 段落节奏多样性

#### 1.1 段落类型与功能

| 类型 | 长度 | 功能 | ToolsList 角色 |
|------|:---:|------|------|
| **长段落（论证型）** | 4–8 句，80–200 词 | 分类权衡、读表分析、agent 连接 | **主干**——尤其 §1 每类、§2 表后 |
| **中段落（过渡型）** | 2–4 句，40–80 词 | 引出表、桥接层级 | **关节** |
| **短段落（节奏型）** | 1–2 句，15–40 词 | 强调关键结论 | **锚点** |

#### 1.2 健康标准

| 检查项 | 健康 | 警告 | 红线 |
|------|------|------|------|
| 长段落（≥4 句） | ≥3 个 | 1–2 个 | 0 个 |
| 连续短段（≤2 句） | ≤2 个连续 | 3 个 | ≥4 个 |
| 短段全文占比 | 15%–30% | 30%–40% | >40% |
| 段落标准差（句数） | ≥1.5 | 1.0–1.5 | <1.0 |
| 每节叙事重量 | 每 H2 至少 1 个 ≥3 句段落 | 个别节全是短段/表 | 3+ 节仅有表+一句 |

### 2. 列表与表格策略

#### 2.1 决策框架

| 信息特征 | 格式 |
|------|------|
| 有序/优先关系 | **有序列表** |
| 并列、无顺序 | **无序列表** |
| 多维产品对比 | **恰好 1 张主表** |
| 架构分类与权衡 | **段落**（非每类一张表） |
| 需逻辑连接才能理解 | **段落** |

#### 2.2 列表质量检查（7 项）

| # | 检查项 | 标准 |
|---|------|------|
| LQ1 | 有前导句 | 列表前必须有完整句子说明目的 |
| LQ2 | 并列结构 | 所有项语法结构一致 |
| LQ3 | 项长度相近 | 最长/最短 ≤3 倍 |
| LQ4 | 项 ≤2 句话 | 超过即应写成段落 |
| LQ5 | 列表后有分析 | ≥2 句分析 |
| LQ6 | 无单一项 | 1 bullet = 段落 |
| LQ7 | 重复词提取 | 多项同词开头→提取到前导句 |

#### 2.3 列表占比上限

| 类型 | 上限 | 说明 |
|------|:---:|------|
| ToolsList | **30%** | 略宽于 Glossary 25%；对比主表不算列表 |

#### 2.4 表格预算（与 article-types 一致）

| 规则 | 标准 |
|------|------|
| 全文表 | ≤3 |
| 产品目录主表 | =1 |
| 裸表格 | 表前无导语或表后 <2 句分析 → 计 1 处违规；≥3 处 ❌ |

### 3. 碎片化反模式（6 类）

| 类型 | 检测方法 | 红线 |
|------|------|:---:|
| **连续短段集群** | ≥3 个连续 ≤2 句段落 | ≥2 处 ❌ |
| **片段拼贴** | 连续 3 段可互换顺序 | 打乱后通顺 ❌ |
| **列表轰炸** | 相邻 2+ H2 各含列表无分析 | ≥3 连续 ❌ |
| **裸表格** | 表格前后无分析段落 | ≥3 处 ❌ |
| **分类表轰炸** | §1 每架构类一张产品表 | ≥2 张分类产品表 ❌ |
| **过渡缺失** | 抽样 10 段衔接率 | <50% ❌ |

**不通过项加权合计 >30% → Presentation 维度 ≤4/10。**

---

### 4. 段间衔接

| 手段 | 示例 | 频率 |
|------|------|:---:|
| 过渡词 | "However," "Beyond the grid," "That distinction matters because" | 每 3–4 段 ≥1 次 |
| 句子桥 | 上段关键信息开下段 | 读表→深潜必用 |
| 关键词重复 | 下段开头重复上段核心词 | 每节 2–3 次 |
| 逻辑推进 | 分类 → 栅格 → 成熟度 → 选型 → agent | 全文主线 |

连续 10 段衔接率 **健康线 ≥70%。**

---

### 5. ToolsList 特有节奏模式

#### 5.1 分类节（§1）

- 开篇段说明为何分类影响选型与互通路径
- 每类：小标题 + **≥1 中/长段**（工具名、权衡、典型买家）
- **禁止**每类附产品对比表

#### 5.2 主对比表（§2）

- 表前导语：本表回答什么问题、数据时效（as of {month year}）
- 表后 ≥3 句：谁领先评估维度、谁缺席、定价/OSS 信号如何读
- 禁止：表格 + 一句话跳到下节

#### 5.3 深潜节（§3）与选型节（§4）

- 成熟度分级用段落解释「intent ≠ shipped」
- 参与方名单优先 prose；勿再做第二张产品目录
- 选型：有序问题 + 可选 1 张场景表；表后须有分析

#### 5.4 Agent 节（§5）

至少 1 个 4–8 句长段：语义层定义指标 vs agent 演化上下文；链相关 hub。

### 6. Phase 4 SelfCheck — Presentation 打分

| 分数 | 标准 |
|:---:|------|
| **10** | 长/中/短交替；列表 ≤30%；表 ≤3 且 1 主产品表；≥3 长段；衔接 ≥70%；0 分类表轰炸 |
| **7** | 节奏基本合理；表 =3 边缘；1–2 长段偏少但仍达标 |
| **4** | 分类多表或裸表格 ≥2；列表 >40% |
| **1** | 全文表/bullet 堆砌 |
