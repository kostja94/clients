## 快速参考

### 一句话产品

Accessible Justice 是 AI + 持证加州律师双审的押金追回服务——AI 制备催款函和小额法庭文书，律师逐案审核，中文/英语/西语三语覆盖，追回押金之前不收费。

### 关键差异化

1. **AI + 律师双审** — 竞品中唯一（Rentrieve/DepositHawk 等纯 AI，DoNotPay 因缺少律师审核被 FTC 执法）
2. **仅做加州、仅做押金** — 深度理解 California Civil Code §1950.5 的每一个细节
3. **多语言（中/英/西）** — 竞品全部缺失——中文和西班牙语法律科技是蓝海
4. **无前期费用** — 消除"请不起律师"的最大障碍
5. **成功才收费** — 利益完全对齐

### 核心法律依据

- **California Civil Code §1950.5(g)**：房东须在 21 天内退还押金或提供逐项扣款明细（含收据）
- **California Civil Code §1950.5(l)**：恶意扣留押金——法院可判最高 2 倍押金作为惩罚性赔偿
- 可扣款项目仅限于清洁费（恢复至入住水平）、超出正常损耗的损坏、欠租

### 市场机会

- 全美每年数十亿美元押金被不当扣留——大多数租客因"请律师比押金还贵"而放弃
- 加州 ~1,700 万租客——最活跃的租房市场之一
- 华人/拉丁裔社区法律科技服务严重缺失——Accessible Justice 目前是唯一的母语押金追回服务
- DoNotPay FTC 事件产生大量"寻找可信替代品"的搜索流量
- Legal Aid 机构严重超负荷——技术填补 Access to Justice 缺口
