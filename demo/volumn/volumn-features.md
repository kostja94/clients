## 二、能力模块（汇总官网 + 公开摘要）

> 命名在不同页面可能中英混排（如 Ghost Writer、ReplyExtension、SalesBot）；以下合并为**能力线**，便于写文案与 PRD。

| 能力线 | 用户感知 | 说明（公开信息） |
|--------|----------|------------------|
| **智能回复 / Engage** | 「高价值回复雷达」 | 识别 feed 中值得回复的帖；宣称 **100–300 级/日** 等量化（以最新文档为准）；类人频率与语气。 |
| **Ghost Writer / 内容** | 目标驱动 + 病毒格式 | **Intent + Meme**、按目标生成长线点子；**Content mode / Goal mode**；高质量帖发现与改写。 |
|线索发现 **Search / Sales Engine** | 从帖文与竞品互动中获线索 | 产品与第三方综述提到 **语义检索 / 大规模账号索引**、按产品描述生成名单类能力（细节以官方 Doc 为准）。 |
| **Sales / DM 自动化** | SalesBot、Auto DM | 对线索列表进行私信、 qualification、跟进；用量与积分绑定；**每日 DM 上限** 随套餐变化（见下文定价）。 |
| **监控与告警** | 品牌提及、关键词 | 产品提及邮件通知；关键词/竞品监控席位与上限随套餐变化。 |
| **ViralLibrary（公开摘要）** | 爆款帖库 | 第三方描述为大规模爆款内容库 + 标签/意图分；官网主站抓取片段不完整，以 [Documentation](https://www.volumn.ai/) 导航为准。 |
| **多平台（叙事）** | X + Reddit 等 | 中文落地页强调 **Reddit** 扩展与「多平台一键发布」；英文首页抓取以 X 为主 —— **对外承诺以前台实际开关为准**。 |
| **数据与集成** | 看板、导出、API | 叙事含 **XLSX、API、CRM**；导航含 **API**、**Affiliate**。 |
|创作者收入辅助 | 曝光 → 收入估算 | 首页区块类「Creator revenue booster」描述（具体模型需官方解释）。 |
