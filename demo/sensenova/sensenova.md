## 1. 产品定位

| 维度 | 内容 |
|------|------|
| 品类 | Native unified multimodal foundation model（原生统一多模态基座）+ office agent productivity layer |
| 价值主张 | 用一套原生架构同时「看懂、想清、画出、交得出」——复杂办公与视觉任务一次跑到可交付结果，而不是只给建议或反复抽卡 |
| 竞争替代 | GPT-4o / Gemini 等通用多模态聊天；Midjourney / Flux 等纯生图；拼接式「视觉塔 + LLM + 生图」开源方案；纯文本 Agent + 外挂工具链 |
| 差异化锚点 | ★ NEO-unify 原生统一；★ U1 / U1 Fast 理解生成一体；★ U1 Pro 交付级 8K + 长程闭环；★ Cowork-Skills + Token 效率办公叙事 |
| 市场位置 | 商汤旗舰多模态线：开源拉开发者生态 + Token Plan 获客；U1 Pro 对标海外顶尖创图/多模态交付（高端能力叙事，公测期免费入口） |

### 1.1 定位简述

多模态赛道正从「能看图聊天 / 能抽卡出图」转向「理解与生成同构、长程任务可交付」。SenseNova U1 把赌注押在 **NEO-unify**——从第一性原理去掉拼接式割裂，让语言与视觉在同一表征里协同；其上叠 U1 Fast（办公信息图）与 U1 Pro（交付级创图与 Agentic Loop）。

ICP 一是要跑通 Excel→报告→PPT 的企业分析师与 Agent 搭建者，二是要出版级信息图与品牌海报的创意/电商团队，三是跟开源与 API 的开发者。中国站以日日新品牌与小浣熊应用放大触达；海外将拆独立域名，需单独做 SEO/合规与定价叙事。

## 2. 产品信息

**SenseNova（日日新）** Slogan 方向：*原生多模态，突破技术边界* / *Native Multimodal, Breaking Boundaries*。

产品线摘要（详见 [features](./sensenova-features.md)）：

- **模型**：U1（开源旗舰）→ U1 Fast（信息图加速）→ U1 Pro（旗舰交付创图，2026-07 WAIC 发布预览）→ 6.7 Flash-Lite（轻量办公 Agent）
- **技能**：Cowork-Skills 八组件（理解 / 执行 / 生成）
- **应用**：办公小浣熊、Seko 短片 Agent、如影数字人、Skills
- **商业化**：Token Plan 公测免费（1500 次/5h/模型）；Lite/Pro 与 U1 Pro 正式定价待公布
