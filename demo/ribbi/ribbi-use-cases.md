## 1. Persona（推断）

| 角色 | 典型诉求 |
|------|----------|
| **社媒运营 / 创作者** | 轮播与短视频复刻、趋势早报、账号数据追踪、增长自动化 |
| **视频与播客作者** | 多语配音、长视频拆条、叙事类视频/幻灯片、文章转视频形态 |
| **电商与设计** | 亚马逊主图套图、海报、Behance 链接转可执行设计、绘本与名片 |
| **音乐与音频实验** | 翻唱、文章转播客/歌曲、生成歌曲 |
| **效率向用户** | 批量抠图、增强与裁切、下载社交视频 |

---

## 2. 场景故事线（内容角度）

1. **一条链路多种形态**：同一素材从文章 → 播客 / 歌曲 / 幻灯片 / 短视频剪辑。  
2. **跨语言分发**：视频配音为多语言版本。  
3. **电商上架节奏**：主图套图 + 海报 + 社媒推广素材同一 Agent 内完成（能力与产品范围以官网为准）。
