## 1. 产品信息

### 产品摘要

**Tanka** 是面向 AI-Native 公司的协作与操作系统，核心产品 **EverMemOS** 将 Slack、Gmail、Outlook、Drive、Notion、Dropbox 等工具的数据整合为统一、可搜索、可被 AI 推理的组织记忆。目标用户为创始人、小团队、AI-Native 公司，通过 Smart Reply、Universal Inbox、语义搜索、AI 助手、任务路由、数据管道等功能，实现「在自动化中保留人的意图，用智能扩展替代人力扩张」。产品入口：Web tanka.ai、App Store。

### 产品定位

**Tanka** 是面向 **AI-Native 公司** 的协作与操作系统，定位为「AI-Native 公司的运营底座」。核心是 **EverMemOS**（世界首个 AI-Native × Memory-Native OS），将 Slack、Gmail、Notion、Dropbox 等工具的数据整合为统一、可搜索、可被 AI 推理的组织记忆，让团队在「自动化之海」中保留「人的意图」。

*来源*：[PR Newswire](https://www.prnewswire.com/news-releases/tanka-launches-worlds-first-ai-native-O-memory-native-os-ushering-in-the-era-of-unlimited-actionable-memory-for-startups-302566748.html)、[Tanka About](https://www.tanka.ai/about)

### 目标受众

- **创始人、创业者**：用更少人力、更少管理提升效率
- **小团队 / 创业公司**：希望 AI 助手基于组织记忆完成回复、总结、搜索、任务
- **AI-Native 公司**：将执行与意图分离，用智能扩展替代人力扩张

### 核心产品线

| 产品/功能 | 说明 |
|-----------|------|
| **EverMemOS** | AI-Native × Memory-Native OS；将 Slack、Gmail、Outlook、Drive、Notion、Dropbox 等整合为统一记忆；Locomo 长上下文记忆 benchmark 92.3% |
| **Smart Reply** | 基于上下文与记忆的智能回复建议（消息、邮件） |
| **Universal Chat / Inbox** | 统一管理邮件、Slack、WhatsApp 等 |
| **语义搜索** | 跨组织数据语义搜索，带来源引用 |
| **AI 助手** | 会议摘要、pitch deck、商业计划、文档分析、翻译、研究；基于存储记忆 |
| **任务与路由** | 任务分配、跨系统自动跟进 |
| **数据管道** | 持续采集业务数据，形成组织记忆 |

### 设计理念

- **神经科学启发**：Dynamic & Static Memory Architecture，平衡即时回忆与深度结构化知识
- **记忆非存储**：Memory is Not Storage; It is Intelligent Data
- **角色注入**：Injecting the Initial Power of "Role" into AI

### 安全与合规

- SOC 2 Type II、ISO 27001
- 不将客户数据用于模型训练
- 企业级加密
