## 1. 直接 / 邻近竞品

| 竞品 | 定位 | 与 Hyperknow 关系（归纳） |
|------|------|---------------------------|
| **ChatGPT / Copilot（通用）** | 通用对话 + 记忆 | 记忆场景混杂；长文档「读完」与考试排版非核心；Hyperknow 强调学习上下文与主动规划 |
| **Perplexity 等 AI 搜索** | 检索 + 摘要 | 强在广域搜索；非课程级 Deep Learn、非 Canvas 深度集成叙事 |
| **Quizlet / Anki 系** | 闪卡、间隔重复 | 强在记忆卡片；弱于「主动 Agent + 全学期材料规划」一体叙事 |
| **Grammarly / 写作助手** | 写作与语法 | 场景偏写作，非全课表学习闭环 |
| **Notion AI / 文档内 AI** | 工作区内辅助 | 非专为学生考试节奏、DDL 与 Persona 主叙事 |
| **Coursera / Khan + AI 功能** | 课程平台 + 辅导 | 内容自有课程体系；Hyperknow 侧重点是**用户自带材料**与个性化 Agent |
| **Khanmigo 等（校内 AI 辅导）** | K-12/通识辅导 | 区域与政策差异大；对比须 `待验证` |
| **Studocu / Course Hero 等资料共享** | 笔记与资料库 | 版权与校规敏感；定位与 Manifesto 合规分开叙述 |

*「首个 proactive learning agent」等表述须与竞品发布节奏核对后再对外使用。*

## 2. 间接竞品

| 类型 | 代表 | 说明 |
|------|------|------|
| **校内辅导 / 家教** | — | 转介与定价对比需谨慎，避免贬损 |
| **传统文献管理** | Zotero 等 | 引用管理 vs 读懂+辅导；可互补 |
| **拍照搜题类** | 地区产品各异 | Hyperknow 叙事强调**理解过程**而非仅答案（与创始人访谈一致） |

## 3. Hyperknow 差异化（草案）

| 维度 | Hyperknow | 典型通用模型 / 工具 |
|------|-----------|---------------------|
| **主动性** | Proactive agent：DDL、材料预准备、Deep Learn Sessions | 多依赖用户先提问 |
| **材料纵深** | 宣称千页级阅读 + 页级引用（以产品实际为准） | 长上下文仍常抽样或概括 |
| **工作流** | Cheatsheet 排版、半开卷场景、Canvas 知识库 | 通用聊天较少覆盖 |
| **记忆** | Learner’s Persona、学习场景记忆组织 | 通用记忆多场景混杂 |
