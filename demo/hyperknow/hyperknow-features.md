## 二、功能详情（摘要）

### 1. Proactive Agent（3.0 核心）

- 不等提问：理解上传材料、课表与目标，**提前**准备学习文件与 guided sessions。  
- 官网表述含「world’s first proactive agent for learning」— 对外需与 [hyperknow-competitors.md](./hyperknow-competitors.md) 交叉校验。

### 2. Deep Learn Sessions

- 结构化章节空间；AI **主动引导**；视频/互动动画等组合；针对「不知道包含哪些子知识点」的碎片学习痛点。

### 3. 检索与信源

- 创始人访谈：可检索约 **50** 网页并逐页阅读、段落级来源标签（以产品实现为准）。  
- Step-by-Step：宣称 **10+ credible sources** / 回应（官网）。

### 4. 长文档

- 宣称单次可达约 **1000 页**量级阅读（FAQ）；强调与「抽样摘要」体验差异。

### 5. Cheatsheet

- 针对半开卷：多列、小字号、公式与符号注释等**真实学生排版**。

### 6. 集成

- **Canvas LMS** 等；自建课程知识库。
