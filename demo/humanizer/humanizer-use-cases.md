## 一、Persona 详解

### P1：大学生（David）

| 项 | 内容 |
|----|------|
| **背景** | 大二～大四，非英语母语或写作薄弱 |
| **行为** | 用 ChatGPT 辅助写论文、作业、个人陈述 |
| **痛点** | 教授明确说「不准用 AI」，学校用 Turnitin 检测；自己改写很费时间 |
| **目标** | 让 AI 辅助的内容不被检测标记，同时保持学术语气 |
| **搜索词** | *bypass Turnitin、make my essay not AI detected、humanize essay free* |
| **使用场景** | 论文定稿前粘贴全文 → Advanced Mode → 人工复查 → 提交 |
| **转化路径** | 免费试用 → 检测分数明显下降 → 注册付费（论文季高峰） |

### P2：SEO 内容写手（Maria）

| 项 | 内容 |
|----|------|
| **背景** | Freelancer 或 in-house，月产 20–50 篇文章 |
| **行为** | 用 AI 批量生成初稿，手动改写费时 |
| **痛点** | 客户要求「100% human-written」；Google 可能降权 AI content |
| **目标** | 高效批量人性化 AI 初稿，保持 SEO 关键词与可读性 |
| **搜索词** | *humanize AI content for SEO、undetectable AI writer、AI humanizer bulk* |
| **使用场景** | ChatGPT 生成草案 → Humanizer 批量改写 → 轻微人工编辑 → 发布 |
| **转化路径** | 免费试用效果满意 → Pro 订阅解锁批量/无限 |

### P3：非英语母语职场人（Lina）

| 项 | 内容 |
|----|------|
| **背景** | 在英语国家留学或工作；英语尚可但写作不够自然 |
| **行为** | 先用中文或母语写好要点，AI 翻译/写作后润色 |
| **痛点** | 表达生硬、「读起来像翻译的」、被同事/客户注意到 |
| **目标** | 让英文邮件、报告、领英内容听起来像母语者 |
| **搜索词** | *make my English sound natural、AI writing assistant for non-native speakers、humanize AI text free* |
| **使用场景** | AI 写好英文稿 → Humanizer 自然化 → 发送/发布 |
| **转化路径** | 高频使用 → 免费额度不够 → 付费 |

### P4：营销文案人员（Alex）

| 项 | 内容 |
|----|------|
| **背景** | 社交媒体经理、广告文案 |
| **行为** | 用 AI 生成多版本广告/社媒/邮件文案 |
| **痛点** | AI 文案千篇一律、缺乏品牌个性、语气不对 |
| **目标** | 快速将通用 AI 文案转化为品牌语气 |
| **搜索词** | *humanize marketing copy、AI ad copy humanizer、make AI text sound casual* |
| **使用场景** | AI 生成文案 → 选择 Casual/Business Mode → 微调 → 发布 |
| **转化路径** | 多模式吸引 → Pro → 品牌定制语气 |

## 二、用户旅程

### 2.1 首次使用旅程

```
搜索 "how to bypass AI detection"
       ↓
Landing → 看到「粘贴文本，一键人性化」
       ↓
粘贴一段 AI 文本（免费试用）
       ↓
看到「改写前：85% AI」→「改写后：12% AI」
       ↓
Aha moment → 注册 → 付费 / 继续免费使用
       ↓
分享给同学/同事（病毒增长）
```

### 2.2 高频使用循环

```
写作用 AI 生成初稿
       ↓
打开 Humanizer → 粘贴 → 选择模式 → 改写
       ↓
检查改写结果 → 微调 → 用内置检测器验证
       ↓
发布 / 提交
       ↓
（重复，直到免费额度用完 → 升级）
```

## 三、季节性需求

| 时段 | 需求高峰 | 原因 |
|------|---------|------|
| **4–5 月 / 11–12 月**（学期末） | 学生论文季 | 大量论文/作业提交 |
| **9–10 月**（开学） | 新生适应期 | 了解工具、申请文书 |
| **全年度** | SEO/营销写手 | 持续内容产出 |
| **1–3 月**（申请季） | 大学/研究生申请 | Personal Statement 润色 |

## 四、场景 × 模式匹配

| 场景 | 推荐模式 | 原因 |
|------|---------|------|
| 学术论文 | Academic Mode | 保留学术语气 + 逻辑结构 |
| 博客文章 | Creative / Casual Mode | 自然随意、有个人风格 |
| 商务邮件 | Business Mode | 正式但不生硬 |
| SEO 文章 | SEO Mode | 保留关键词 + 可读性 |
| 社交媒体 | Casual Mode | 口语化、有趣 |
| 技术文档 | Standard Mode | 准确 + 去机械味 |
