## 2. 结构原则（摘录落实）

| 原则 | SoberVoice 动作 |
|------|-----------------|
| **Flat**：首页到任意页 ≤4 次点击 | 内链规划见 [sobervoice-features.md](./sobervoice-features.md)；避免孤儿页 |
| **Features vs Use cases** | `/features/*` = 能力优先；`/for/*` = 情境优先；互链、避免正文重复堆叠 |
| **Pricing 双触点** | 营销站 `/pricing` 获客；App 内 **Settings → Billing** 管订阅（文案在 [sobervoice-others.md](./sobervoice-others.md) **Pricing** 注明） |
| **增长路径** | 教育：`/blog`、`/learn`；对比：`/alternatives`（可选） |
