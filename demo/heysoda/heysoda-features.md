## 二、产品主张（能力块）

| 能力 | 说明（基于官网） | 差异化强度 |
|------|------------------|------------|
| **多维智能匹配引擎** | 结合社会学、心理学、行为科学等多学科洞见的推荐系统；不只是标签配对，而是对"人"的多维建模 | ★★★ |
| **可解释匹配叙事** | 不仅告诉用户"匹配了谁"，还说明**为什么合拍、可能产生怎样的火花**——将匹配从黑盒变为可理解的故事 | ★★★ |
| **AI 首轮破冰** | 匹配成功后，AI 主动生成破冰消息建议，减少用户面对新匹配时"不知道说什么"的启动阻力 | ★★ |
| **AI 对话续航** | 对话出现冷场时，AI 智能介入——提供话题建议、延续对话节奏，降低匹配后沉默率 | ★★★ |
| **多场景诉求表达** | 以「帖/求」形式覆盖联合创始、活动搭子、招聘、认真恋爱、投资对接等场景；同一套匹配引擎适配不同关系类型 | ★★ |
| **双生态跨平台触达** | Web 英文站 + 微信内小程序，支持浏览器与移动端双入口，覆盖英语与中文用户 | ★★ |

> ★★★ = 与主要竞品（Tinder/Bumble/Ditto/CoffeeSpace/Known）对比的强差异点；★★ = 有差异但竞品存在部分重叠。评估基于 2026-05 公开信息，以各产品最新版本为准。

## 六、与「竞品功能」的边界（对照 Ditto / CoffeeSpace / Known 摘要）

- **Ditto**（见 [heysoda-competitors.md](./heysoda-competitors.md)）强调：校园、**无滑卡**、**iMessage** 上由 AI 安排 **真实线下约会** 并跟进反馈。  
- **CoffeeSpace**（见同上）专注**联合创始匹配**，语义推荐 + 每日精选，与 HeySoda 的「创业」场景直接重叠但场景单一。  
- **Known**（见同上）采用**语音 AI 访谈** + $15/次按结果付费，聚焦约会场景，与 HeySoda 在「反滑卡疲劳」人群上有间接竞争。  
- **Articuler.ai**（见同上）采用**向量化全量背景匹配** + AI 冷邮件 Agent，聚焦职业社交。  
- **Jobright**（见同上）全流程 AI 求职 Agent（匹配+简历+投递+追踪），仅在招聘场景与 HeySoda 竞争；HeySoda 的招聘是**社交化双向匹配**（招人方和求职方都是用户），而非单向求职工具。  
- **HeySoda** 官网叙事更广（创业/投资/活动/恋等多类），**渠道组合**为 Web + 微信生态，与上述竞品的**单一场景与单一渠道**并非同一子赛道，对比时需分维度说明。
