## 1. 同赛道/邻近赛道（需按客户实际技术栈再校准）

| 类型 | 示例方向 | 与 CrowdCore 的对比视角（非排名） |
|------|----------|-----------------------------------|
| **传统调研与样本库** | 在线问卷、小样本用户访谈、品牌追踪 | CrowdCore 强调 **可规模化的 AI 受众代理 + 社媒/视频级信号** 与**持续学习**，非单次样本；适用场景与统计严谨性需因案而异。 |
| **达人/网红发现平台** | 以搜索、标签、商单市场为主的平台 | 站面故事侧重 **用「受众模型响应」评达人** 而不只是**粉丝/标签**；可与之组成「发现 + 预演」的两段式采购叙事。 |
| **创意预测与 ad testing 类工具** | 各平台的创意打分、小流量学习 | CrowdCore 用 **多引擎**（**Video Intelligence + Audience + Simulation**）打「内容理解 × 人群模拟」的包装；具体指标可比性要一事一议。 |
| **社交聆听 / 舆情** | 以文本与声量为主的产品 | 部分重叠在「社媒在发生什么」，但 CrowdCore 主卖点是**决策前模拟与创意/达人选择**，非仅监盘。 |
| **自建大模型+仿真** | 内部 MLOps、合成用户研究管线 | 站面以 **$17K/mo 量级自建行项** 与订阅档对比；**工程与合规成本**为差异化话术的锚点。 |

## 2. 网上可检索的相近 AI 产品（公开信息汇总）

> 以下基于 **2026-04-26 前后** 的公开网页与检索结果整理，**非穷尽列表**；产品定位、融资与能力以**对方官网/新闻稿**为准，对比 CrowdCore 时务必逐家核实。

### 2.1 合成受众 / AI 人格模拟 / 预演

| 产品 | 网站 | 与 CrowdCore 的相似点 | 与 CrowdCore 的常见差异（据公开描述） |
|------|------|------------------------|----------------------------------------|
| **Lumina** | [getlumina.in](https://www.getlumina.in/) | **AI 受众模拟**、活动上线前在大量 persona 上试创意、称可替代部分招募/田野周期 | 叙事偏「百万级 persona、通用营销/研究团队」；**是否强调长视频多模与达人侧**需对照自家站面。 |
| **AudienceLab** | [audiencelab.run](https://www.audiencelab.run/) | **Synthetic personas / Customer Twins**、多方案投票、数分钟内出结果 | 偏**文案/方案快速对决**（多 headline/价格等）；**社媒长视频 + 1,000+ agent 工程叙事**与 CrowdCore 官网侧重点不同。 |
| **SightsAI** | [sightsai.co](https://sightsai.co/) | **Synthetic audience**、消息/内容预试、**API 与 MCP**、数字孪生画像 | 强调**舆情安全、message testing** 与 to-B 多行业；**OpenClaw 代理集群 + Video Intelligence** 为 CrowdCore 独述，不宜直接划等号。 |
| **Synthetic Simulations** | [syntheticsimulations.com](https://www.syntheticsimulations.com/) | 将行为数据转为 **1 万～百万级** digital twins、在**类社交环境**中预演广告/产品/内容；**OASIS** 等学术基础设施引用 | 偏「行为预测平台 + 研究阶段**设计伙伴**」；对方站内亦列举其它竞品作对照（**Simile、Aaru、Artificial Societies、Blok、Synthetic Users** 等，均为**对方自述**，需独立验证）。 |
| **Moose Review（Paper Moose）** | [Moose Review 方法论](https://papermoose.com/moose-review/methodology) | **合成受众**评审创意、0–10 效力量表、**制作/媒介前**测试 | 偏**创意机构方法论 + 合成人格面板**；产品形态是服务/方法混合，**非**与 CrowdCore 同一类纯 SaaS 订阅叙事。 |
| **Synthetic Users** | （Gartner 提及，需以官网为准） | 1:1 **AI 访谈式**研究 | **Synthetic Simulations** 的对比文强调「**个体访谈** vs 大规模社会模拟」；若写竞品矩阵应单独开官网核对。 |

### 2.2 广告预投预测 / 创意 +「AI 消费者」验证

| 产品 | 网站 | 与 CrowdCore 的相似点 | 与 CrowdCore 的常见差异（据公开描述） |
|------|------|------------------------|----------------------------------------|
| **Extuitive** | [get.extuitive.com](https://get.extuitive.com/) | 上线前 **预测广告表现**、用大量 **AI consumer agents** 验证创意、**Shopify** 等整合 | 强 **D2C/效果广告/CTR·ROAS** 叙事；**达人筛选 + 重视频多模**若不在对方主线，可做多维度对比而非「完全替代」。 |

### 2.3 企业定制 / 加速器类（非独立消费级小产品）

| 产品 | 网站 | 说明 |
|------|------|------|
| **Campaign Simulation Accelerator（Credencys）** | [credencys.com 方案页](https://www.credencys.com/solutions/campaign-simulation-accelerator/) | 偏 **B2B 实施/加速器**：用历史数据与分群做**投放前**仿真与 ROI 叙事，常为项目制而非与 CrowdCore 同价带的自助 SaaS。 |

### 2.4 与 CrowdCore 做对比表时可用的「维度」

| 维度 | 说明 |
|------|------|
| **模态** | 是否**原生**支持长/短视频、语音、画面风格（与 CrowdCore **Video Intelligence** 对齐度）。 |
| **受众来源** | 仅人口统计 vs **CRM/广告/活动回灌**（与站面「**Accumulate**」是否同构）。 |
| **输出物** | 仅打分/选 winner vs **达人名单、活动路径、可解释理由**。 |
| **规模叙事** | persona/**agent 数量**、是否公开方法论与误差（E-E-A-T）。 |
| **交付形态** | 纯软件、**API/MCP**、还是咨询 + 方法（如 Moose）。 |

## 3. CrowdCore 可主打差异化（与站面一致）

| 维度 | 摘要 |
|------|------|
| **视频多模态** | 强调帧/语音/声景等，超越纯标题与标签。 |
| **代理集群规模** | **~1,000 OpenClaw agents** 的规模化 persona 与 CRM/活动数据对齐的叙事。 |
| **全链路** | 从社媒学习 → 受众模型 → 活动模拟 → 回灌，强调 **累积资产** 而不仅是单点 tool。 |
| **门槛梯度** | **$20** 起可验证、高阶含 **Success manager**，覆盖从小团队到 **Growth** 档。 |

## 4. 风险与内容机会

- **可验证性**：案例数字与证言需在落地页/博客中满足 **E-E-A-T** 与**客户授权**；方法论页有助于 AI Overview / 研报复述。  
- **名词解释**：*OpenClaw*、*Video Intelligence*、*AI Visibility* 等应配有简短定义页或知识库，减少歧义。  
- **比较内容**：`CrowdCore vs [竞品]` 以**可核查维度**（数据类型、是否模拟、是否含视频多模、部署模式）写，避免不可证明的「最强」类表述。
