## 2. 情境故事线（内容营销可用）

1. **「一条提示词到 15 秒片」**：Immersive Space → 导出 → Canvas 里接多条镜头。  
2. **「实拍变动漫/油画」**：Video Style Transfer → 社交发布。  
3. **「人像修完再动」**：换发型/换背景 → Convert photo to video。  
4. **「客户比稿」**：同脚本在两种模型下各出一版（需合规使用第三方品牌表述）。

## 2.1 电影制作向：行业共性 + Morph 映射（供叙事与落地页）

检索「**AI video for filmmaking / previs / storyboard**」时，垂直产品常见卖点包括：**剧本/创意→分镜→短视频断**、**Previs（预演）**、**镜头列表与机位/光影说明**、**多镜头角色一致性**、**多模型管线**、云渲染分辨率档位等。以下为**市场公开信息归纳**（便于 Morph 定差异与内容选题，**非**逐一竞品审计）：

| 方向 | 常见表述（行业） | 与 Morph 能力的对应（若产品具备则写进落地页） |
|------|------------------|-----------------------------------------------|
| **工作流** | Script → storyboard → motion clip / previs package | **Immersive Space** 快速概念 + **Open Canvas** 串联多镜头（官网已强调场景板、0–10s 等） |
| **视觉连续** | Character bible / reference、跨镜头一致 | 图生视频、参考图工作流；具体以产品是否支持「锁角色」为准 |
| **Look 探索** | 概念帧、风格方向 | **Video Style Transfer**、多模型出片对比 |
| **制作阶段** | 前期概念、比稿、低成本预演，非替代实拍/VFX 全流程 | 文案需 **底线**：AI 生成片段的定位（概念/预演/素材），避免过度承诺 |

**外部参考（垂直向产品官网，作题材与 SERP 参考）**：[Filmvision AI](https://filmvision.ai/)（previs / storyboard 向）、[M Studio](https://mstudio.ai/)（script-to-storyboard-to-video）、[StableGen](https://www.stablegen.io/)（多模型、多镜头）、[Frameliq](https://frameliq.com/)（storyboard / shot canvas）、[StoryLonger](https://storylonger.com/)（script→storyboard→video）。Morph 若主打 **多模型一站式 + 画布 + 风格迁移**，可在 `/for-filmmakers` 或支柱文中与「仅分镜」或「仅单模型」类定位做对比（须可验证）。
