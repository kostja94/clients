## 1. 竞品地图

| 类型 | 代表方向 | 与 Morph 的比较角度 |
|------|----------|---------------------|
| 综合 AI 视频平台 | Runway、Luma、Pika 等 | Morph 强调 **多模型聚合 + 画布工作流 + 图视频一体** |
| 单模型官方站 | Kling、即梦系、各模型官网 | Morph 为 **聚合试用与编排**，非单一模型官方 |
| 图像为主扩视频 | Midjourney 生态、Leonardo 等 | Morph **视频与风格迁移**权重更高 |
| 模板化短视频工具 | CapCut AI、各类「一键成片」 | Morph 偏 **可控生成与专业工作流** |

---

## 2. 差异化要点（草案）

1. **多模型一站式**：降低用户跨站试模成本。  
2. **Immersive + Canvas 双形态**：兼顾速度与叙事编排。  
3. **视频风格迁移 + 修图→视频闭环**：与纯文生视频竞品形成组合差异。  
4. **工具页矩阵**：长尾 SEO 覆盖 logo、headshot、upscaler 等（与 features 页脚一致）。

---

## 3. 风险与边界

- **第三方模型**命名、能力描述须与授权与实际 API 一致。  
- **Runway、Sora** 等商标在对比文案中注意合规。
