### 1.1 行业常见邻近类型（与产品片 / 品牌故事同类谱系）

以下类型在 **B2B / SaaS / 科技企业** 内容策略中常与 *product launch video*、*brand film* 并列出现，用于 Brief 对齐、拆条或后续项目扩展。定义综合行业常见归纳，**非 LucidEdge 官网逐条承诺的服务清单**。

| 类型（中英） | 典型目的 | 常见时长参考 | 与官网类型的关系 |
|--------------|----------|----------------|------------------|
| **Brand video / Brand story video（品牌片 / 品牌故事）** | 使命、愿景、为何存在、情感与信任；少堆功能 | 约 60–120s 常见 | 与官网 **brand film** 同谱系；偏「我是谁、为何重要」 |
| **Brand overview / About Us video（品牌概览 / 关于我们）** | 组织简介、团队、调性；首页 / About / 路演辅助 | 约 60–180s | 与品牌故事相邻，更偏「介绍性」而非纯情绪叙事 |
| **Product demo（产品演示片）** | 展示产品如何运作、真实使用情境、缩短销售周期 | 约 2–5 min 亦常见（亦有条状剪辑） | 与官网 **UI walkthrough / product demo** 案例描述一致 |
| **Product showcase / Promotional video（产品展示 / 促销片）** | 突出卖点、激发兴趣，常配合投放或上新 | 约 60–120s | 与 **launch / cinematic** 发布片在「上新造势」上重叠 |
| **Explainer video / Animated explainer（讲解片 / 动画讲解）** | 把复杂概念讲清楚；落地页、销售跟进、教育市场 | 约 60–90s 常见 | 与 LucidEdge 强调的「复杂 AI 叙事」高度相关，形式多为 MG/动画 |
| **Case study / Customer story video（案例片 / 客户故事）** | 可验证结果、行业场景、增强可信度 | 常 90s–数分钟 | 与 **testimonial** 同属「证明」类，偏故事化成果 |
| **Testimonial video（客户证言/访谈）** | 真人背书、短平快信任 | 约 60–120s | 漏斗中段；可与 launch 片、demo 组合投放 |
| **Founder / CEO message（创始人/高管致辞）** | 融资、重大发布、危机或愿景沟通 | 约 60–120s | 常作为 launch 战役中的「人格化」补充条 |
| **Teaser / Trailer（预告片）** | 预热、悬念、引流至正片或落地页 | 常 15–60s | 与 **product launch** 战役配套 |
| **Social-first short / Vertical-native（社交优先短视频）** | 信息流、Reels/TikTok 等；常由主片衍生 | 极短 | 官网 FAQ 已覆盖 **9:16** 等导出，策略上属「一主多剪」 |
| **FAQ / Objection-handler video（常见问题/异议处理）** | 消除购买顾虑、支撑销售与客服 | 可系列短条 | 与 explainer 相邻，更偏「答疑」 |
| **Event recap / Launch event video（活动精华/发布会）** | 延续现场传播、媒体素材 | 视活动而定 | 与 **launch** 时间窗口相邻，偏纪实剪辑 |
| **Corporate documentary（品牌纪录式长片）** | 深度叙事、文化或转型故事 | 更长 | 与 **brand story** 同向，制作与周期通常更重 |

**选题提示（行业常见框架，非官网原文）**：可按漏斗阶段搭配——认知向偏 *brand story / overview*；考虑向偏 *explainer、demo、testimonial / case study*；转化向偏 *demo、FAQ、CEO message* 等。可参考 [Green Frog Labs 对格式与业务目标的对应表](https://greenfroglabs.com/blog/corporate-video-ideas)。

## 三、方法论：Logic Distillation（官网「Why us?」）

| 模块 | 官网描述要点 |
|------|----------------|
| **Noise Stripping** | 去除干扰与冗余信息，聚焦品牌核心价值 |
| **Value Path Deconstruction** | 映射用户关键决策点与如何从产品中获取价值 |

## 六、交付与规格（摘自 FAQ）

| 维度 | 官网承诺摘要 |
|------|----------------|
| **周期** | 多数项目 **7–14 个工作日**（brief 到终剪）；可加急 |
| **画幅** | **16:9**（YouTube/落地页）、**1:1**（Ins feed）、**9:16**（Reels/TikTok/Stories） |
| **资产** | **Master** + **各平台优化导出** |
| **品牌一致性** | 按品牌视觉语言定制（色、字体、语气、节奏）；会先研究素材与竞争环境 |
| **用途扩展** | 可用于 **投资人材料、PR、媒体简报、展会演示** 等 |
