## 3. 典型用户旅程

### 旅程 1：首次创作者 → 完成第一个作品

```
1. 发现 → 通过 Google（"AI video generator"）、YC 推荐、或创作者社区推荐找到 YouArt
2. 注册 → 免费注册，获得 100 credits
3. 探索 → 浏览模板库，找到"AI Anime Short"模板
4. 创作 → 用 Creative Agent 优化 prompt → GPT Image 2 生成角色 → Seedance 2.0 生成动画片段
5. 编辑 → 在内置编辑器中微调转场、节奏
6. 导出 → 无水印导出 30 秒成片，发布到 TikTok
7. 升级 → 为更多 credits 和进阶功能升级到 Pro（$29.99/月）
```

### 旅程 2：创作者 → 发起众筹 → 建立粉丝经济

```
1. 积累作品 → 在 YouArt 上发布多个 AI 短片，积累粉丝
2. 发布预告片 → 用 Seedance 2.0 制作 90 秒原创系列预告片
3. 发起众筹 → 在 YouArt 平台发起众筹，目标 $30,000 制作 6 集系列
4. 粉丝支持 → 早期粉丝通过平台认缴，获得独家权益
5. 制作交付 → 用众筹资金购买更多 credits，完成全系列制作
6. 订阅变现 → 设置月度订阅层，粉丝 $5/月获取幕后内容和早期访问
7. 持续增长 → 建立私域粉丝社区，品牌合作接踵而至
```

### 旅程 3：品牌营销团队 → 月度内容生产体系

```
1. 评估期 → 免费试用，测试 Seedance 2.0 对产品照片的生成效果
2. 购买 → Max 计划（$149.99/月），3 人团队共享 credits
3. 建立工作流 → 创建"产品发布"模板：产品图 → 生活场景视频 → 多语言配音
4. 周度生产 → 每周一上传新品，批量生成 20 条视频，A/B 测试
5. 优化迭代 → 根据广告数据选择表现最好的创意方向，专注生产
6. 扩展 → 发现 ROI 为正后，升级到 Enterprise 获取更多 credits
```

## 4. 不适用边界

| 不适用场景 | 原因 | 替代方案 |
|-----------|------|---------|
| 需要 4K 原生视频输出 | Seedance 2.0 最高 2K（1080p 升频），非原生 4K | Runway Gen-4、Adobe Firefly |
| 需要毫秒级帧级别精确控制 | YouArt 注重易用性，非专业后期 | DaVinci Resolve、Adobe Premiere Pro |
| 需要商业 IP 保障（高预算品牌片） | Seedance 2.0 无商业 IP 赔偿条款 | Runway（部分计划含 IP 保障）、Adobe Firefly |
| 仅需视频编辑（不需要 AI 生成） | YouArt 的核心价值在 AI 生成 | CapCut、DaVinci Resolve |
| 需要自研模型训练/微调 | YouArt 是模型聚合商，不支持自定义训练 | Replicate（开源模型微调）、fal.ai |
| 企业内部合规要求极严（数据不出境） | YouArt 使用多模型供应商，数据路径复杂 | Google Veo 3（Vertex AI，企业内部署） |
