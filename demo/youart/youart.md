## 1. 产品定位与价值主张

**YouArt** 是面向 AI 时代创作者的"创作 + 变现"一体化平台。平台核心洞察：AI 降低了内容创作门槛，但创作者仍然面临两大瓶颈——**高品质制作**和**可持续变现**。YouArt 用一个平台同时解决这两个问题。

### 核心价值主张

| 维度 | 主张 |
|------|------|
| 行业领先的 AI 视频 Agent | 原生集成 Seedance 2.0——字节跳动最新多模态视频模型，支持 12 资产同步输入、多镜头叙事、8+ 语言唇形同步音频生成 |
| 多模型一站式访问 | 单一订阅同时接入 Sora 2、Veo 3.1、Seedance 2、GPT Image 2、ElevenLabs 等头部模型——无需在多平台间切换 |
| 替代好莱坞管线 | 传统模式：剧本 → 找资方 → 制作 → 发行；YouArt 模式：AI 制作预告片 → 平台众筹 → 粉丝订阅变现——省去中间环节 |
| 粉丝经济基础设施 | 创作者拥有自己的私域品牌，可设置月度订阅、售卖独家内容、直接变现 IP，无需依赖广告算法分成 |
| YC 背书 + 实战验证 | YC S26 批次，$120K+ MRR 在 5 个月内达成，验证了创作者对这一模式的需求 |

## 2. 核心架构：三步闭环

### 2.1 平台架构全貌

```
创作者
   │
   ├─→ 第一步：创作（Production）
   │     AI 视频 Agent（Seedance 2.0）
   │     多模型创作工具（图像/视频/语音）
   │     Creative Agent（AI 助手）
   │     Workflow 自动化
   │     ↓ 产出：预告片 / 视觉概念 / 完整剧集
   │
   ├─→ 第二步：众筹（Crowdfunding）
   │     在 YouArt 平台直接发起众筹
   │     早期粉丝提供制作资金
   │     ↓ 获得：$50K 级别的制作预算
   │
   └─→ 第三步：分发与变现（Distribution & Fan Economy）
         私域品牌建设
         月度订阅收入
         独家/私有内容售卖
         IP 直接变现
         ↓ 结果：可持续的创作者收入
```

### 2.2 与传统模式的关键区别

传统好莱坞管线：剧本 → 找制片厂 → 融资 → 制作 → 院线/流媒体发行 → 等待分账。环节多、周期长、中间商抽成高。

YouArt 模式：AI 制作 → 平台众筹 → 粉丝订阅。去中介化、缩短周期、创作者保留更多收入。

## 3. 竞品格局（摘要）

> 完整竞品矩阵、场景级对照表、SWOT 分析见 [youart-competitors.md](./youart-competitors.md)。

YouArt 的独特定位——[AI 视频创作工具] + [多模型聚合] + [创作者众筹] + [粉丝订阅经济]——使其在三个维度上同时竞争：

| 竞争维度 | 代表产品 | YouArt 的关键差异 |
|---------|---------|-------------------|
| AI 视频生成平台 | Runway、Pika、Kling AI、Google Veo | YouArt 不研发自研模型，而是聚合头部模型 + 叠加变现层 |
| AI 创作工具 | Midjourney、Leonardo AI、Adobe Firefly | YouArt 覆盖视频 + 图像 + 语音全模态，且自带变现功能 |
| 创作者变现平台 | Patreon、Ko-fi、Buy Me a Coffee | YouArt 在变现之上叠加 AI 制作工具，形成"创作即变现"闭环 |

**市场背景**：AI 视频生成市场 $847M–$946M（2026），预测 $3.35B–$3.44B（2033–2034）。Sora 关停（2026 年 4 月）证明纯消费者 AI 视频订阅模式不可持续，平台聚合 + 创作者经济可能是一条更可持续的路径。
