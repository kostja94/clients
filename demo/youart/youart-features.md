## 1. Seedance 2.0 — 核心视频生成引擎

### 1.1 模型概况

Seedance 2.0 是字节跳动 2026 年 2 月发布的最新多模态 AI 视频生成模型，是 YouArt 平台的核心差异化引擎。

| 规格 | 参数 |
|------|------|
| 输入模式 | Text、Image、Video、Audio（全模态） |
| 最大参考文件 | 12 个/次生成（9 图像 + 3 视频 + 3 音频） |
| 最大分辨率 | 2K |
| 时长 | 5–15 秒（支持多镜头序列） |
| 帧率 | 24 fps |
| 画面比例 | 21:9、16:9、4:3、1:1、3:4、9:16 |
| 视频输入 | 最多 3 段，每段最长 15 秒 |
| 音频输入 | 最多 3 段，每段最长 15 秒（MP3） |
| 音频输出 | 双声道立体声，8+ 语言唇形同步 |

### 1.2 四大核心能力

```text
创作者输入 Prompt + 参考资产（@-mention 语法）
              ↓
    ┌─────────────────────────────────┐
    │     Seedance 2.0 双分支扩散      │
    │      Transformer 架构            │
    ├─────────────────────────────────┤
    │  视频分支          │  音频分支     │
    │  - 角色一致性      │  - 对话 + 唇形  │
    │  - 多镜头叙事      │  - 环境音效     │
    │  - 物理模拟        │  - 背景音乐     │
    │  - 逐帧控制        │  - 8+ 语言     │
    └─────────────────────────────────┘
              ↓
     同步输出：视频 + 音频（一 pass 完成）
```

| 能力 | 描述 | 技术亮点 |
|------|------|---------|
| **多模态统一输入** | 同时输入文本、图像、视频、音频，使用 @-mention 语法分配角色 | 12 资产同步处理，自动理解上下文 |
| **同步音频生成** | 视频和音频通过双分支扩散 Transformer 同步生成 | 对话唇形同步、环境音效、背景音乐一次性完成 |
| **多镜头叙事** | 单次 prompt 生成连贯多镜头序列 | 角色动作、旁白、环境音、镜头角度跨镜头保持一致 |
| **逐帧精度控制** | 风格锁定、场景连贯、角色一致性、字体/转场/节奏控制 | 适合专业级制作需求 |

### 1.3 与其他模型的差异化

Seedance 2.0 在 YouArt 平台上的关键优势：

| 维度 | Seedance 2.0 优势 |
|------|-------------------|
| 多模态输入 | 唯一支持 12 资产同步输入的主流视频模型 |
| 音频同步 | 视频+音频同时生成，非后期配音 |
| 物理真实感 | 动作场景、碰撞效果、多角色互动 90%+ 首次可用率 |
| 角色一致性 | 通过 9 张参考图实现跨镜头角色外观统一 |
| 语言支持 | 8+ 语言唇形同步 |

## 2. 多模型聚合架构

### 2.1 模型矩阵

YouArt 不研发自研模型，而是聚合头部 AI 模型，以统一订阅和统一界面提供给创作者。

| 模型 | 类型 | 用途 | 来源 |
|------|------|------|------|
| **Seedance 2.0** | 视频生成 | 旗舰视频模型，多模态+音频同步 | 字节跳动 |
| **Sora 2** | 视频生成 | 叙事性视频、storyboarding | OpenAI |
| **Veo 3.1** | 视频生成 | 企业级视频生成、Google 生态 | Google |
| **GPT Image 2** | 图像生成 | 文本到图像、图像编辑 | OpenAI |
| **Nano Banana Pro** | 图像生成 | 快速图像生成 | — |
| **ElevenLabs** | 语音合成 | TTS、音色克隆、多语言 | ElevenLabs |

### 2.2 Credits 系统

所有模型消耗通过统一 credits 系统管理：

| 计划 | Credits/月 | 约合图像 | 约合视频 | 价格 |
|------|-----------|---------|---------|------|
| Free | 100 | ~20 张 | 有限 | $0 |
| Basic | 1,000 | ~200 张 | ≥1,000s | $9.99/月 |
| Pro | 3,300 | ~1,000 张 | ≥3,300s | $29.99/月 |
| Max | 18,000 | ~6,000 张 | ≥18,000s | $149.99/月 |
| Enterprise | 定制 | 定制 | 定制 | 定制报价 |

### 2.3 多模型聚合的价值

| 价值点 | 描述 |
|--------|------|
| 单一订阅 | 无需在 Runway、Pika、Midjourney、ElevenLabs 等多个平台分别付费 |
| 统一界面 | 同一 Workflow 内切换不同模型，无需学习多套工具 |
| 成本透明 | 统一 credits 系统，跨模型消费可追踪 |
| 模型升级自动获得 | 新模型接入后，现有订阅自动可用 |

## 3. Creative Agent（AI 创作助手）

### 3.1 功能描述

Creative Agent 是平台内嵌的 AI 助手，帮助创作者完成从创意到成品的全流程。

| 能力 | 描述 |
|------|------|
| 创意生成 | 根据用户意图自动生成创作方案、prompt 建议 |
| 工作流引导 | 智能推荐合适的模型和工作流步骤 |
| Prompt 优化 | 自动优化和扩充用户输入的 prompt |
| 风格建议 | 分析参考素材并推荐匹配的视觉风格 |

### 3.2 适用场景

- 新手创作者不确定从何入手
- 需要快速将创意转化为可执行的工作流
- Prompt 工程师需要优化生成效果

## 4. 创作工作流（Workflow）

### 4.1 工作流能力

| 功能 | 描述 |
|------|------|
| 多步骤串联 | 将图像生成 → 视频生成 → 语音合成串联为自动化流程 |
| 模板系统 | 预设模板覆盖常见创作场景（社交媒体短视频、产品展示、动画预告片等） |
| 视频编辑器 | 内置视频编辑工具，生成后可直接剪辑、调整 |
| 团队协作 | Max 及以上计划支持团队共享画布、工作流和资产 |
| 无品牌水印 | Basic 及以上计划去除水印 |

### 4.2 典型工作流示例

```
1. GPT Image 2 生成角色概念图
   ↓
2. Seedance 2.0 基于概念图生成多镜头视频
   ↓
3. ElevenLabs 添加多语言配音
   ↓
4. 内置编辑器中微调转场和节奏
   ↓
5. 发布到 YouArt 或导出至外部平台
```

## 5. 创作者变现体系

### 5.1 三部曲变现模式

这是 YouArt 区别于纯 AI 工具的核心功能——不仅是创作工具，更是创作者的商业化基础设施。

| 阶段 | 功能 | 描述 |
|------|------|------|
| **众筹** | 平台内众筹 | 创作者发布 AI 生成的预告片，直接向平台用户筹集制作资金（瞄准 $50K 级别预算） |
| **订阅** | 粉丝月度订阅 | 创作者设置月度订阅层，粉丝付费获取独家内容和早期访问 |
| **分发** | 私域品牌 + 内容售卖 | 创作者建立自己的粉丝社区，售卖独家/私有内容，直接变现 IP |

### 5.2 与传统平台的对比

| 维度 | YouArt | YouTube/TikTok | Patreon |
|------|--------|---------------|---------|
| 创作工具 | 内置 AI 视频生成 | 需外部工具 | 需外部工具 |
| 融资方式 | 平台众筹 | 广告分成 | 粉丝订阅 |
| 收入模式 | 订阅 + 众筹 + 内容售卖 | 广告为主 | 订阅为主 |
| 粉丝关系 | 私域（拥有粉丝数据） | 公域（算法分配） | 私域 |
| IP 控制权 | 创作者保留 | 平台条款限制 | 创作者保留 |

### 5.3 联盟计划

YouArt 还设有 Affiliate Program，用户可通过推广平台获得佣金收入，进一步扩大创作者收入来源。

## 6. 定价模型深度拆解

### 6.1 完整定价层级

| 层级 | 价格（月付） | 价格（年付） | Credits | 核心限制 |
|------|------------|------------|---------|---------|
| Free | $0 | $0 | 100 | 有限模型、有水印、社区支持 |
| Basic | $9.99 | ~$7.99 | 1,000 | ≥200 图像/月、≥1,000s 视频/月 |
| Pro ⭐ | $29.99 | ~$23.99 | 3,300 | ≥1,000 图像/月、≥3,300s 视频/月、新功能优先 |
| Max | $149.99 | ~$119.99 | 18,000 | ≥6,000 图像/月、≥18,000s 视频/月、团队功能 |
| Enterprise | 定制 | 定制 | 定制 | 无限团队/成员、Claude Code/Codex 集成、专属客户经理 |

### 6.2 与竞品定价对比

| 产品 | 入门价 | 中等档 | 高端档 | 视频模型 |
|------|--------|--------|--------|---------|
| **YouArt** | Free → $9.99 | $29.99 | $149.99 | 多模型聚合 |
| Runway | Free → $15 | $35 | $95 | 自研 Gen-4 |
| Pika | Free → $8 | $25 | $65 | 自研 Pika 2.5 |
| Kling AI | ~$6.99 | ~$15.99 | ~$37 | 自研 Kling 3.0 |
| Midjourney | $10 | $30 | $60 | 无视频 |

YouArt 的中档定价（$29.99 Pro）对标 Runway 的 $35 档和 Pika 的 $25 档，但因多模型聚合而具有"一份订阅 = 多个平台的模型访问"的价值。

### 6.3 YouArt 作为模型聚合商的经济学

注意：YouArt 是 Seedance 2.0 的第三方 wrapper，非官方接入渠道。AI Video Bootcamp 等第三方评测建议创作者优先使用官方路径（fal.ai、Replicate、BytePlus Volcano Engine），因为 wrapper 通常有溢价。YouArt 的定价（$29.99/月 for 3,300 credits）相比 fal.ai 直接接入有一定溢价，但用户获得的是统一界面、多模型访问、以及变现工具——这些附加值可能抵消溢价。
