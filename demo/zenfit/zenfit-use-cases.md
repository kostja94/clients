## 四、场景与 Use Case 详情

### 1. 改善平衡与防跌倒（Balance & Fall Prevention）

**场景**：中老年用户担心跌倒，希望通过温和运动增强平衡能力。

| 要素 | 内容 |
|------|------|
| **用户故事** | "我 65 岁，最近走路有点不稳，医生建议做平衡训练，但健身房太激烈。" |
| **ZenFit 方案** | 太极、八段锦中的平衡动作；5–15 分钟短课程；可在家完成 |
| **目标关键词** | tai chi for balance, fall prevention exercises, balance exercises for seniors |
| **建议 URL** | /for/balance、/for/fall-prevention |
| **调用的功能** | [Tai Chi](/features/tai-chi)、[Eight Brocades](/features/eight-brocades) |

### 2. 缓解背痛与关节不适（Back Pain & Joint Health）

**场景**：久坐、关节炎、腰椎不适，需要低强度、关节友好的运动。*研究支持：虚拟太极/气功可显著改善慢性腰痛。*

| 要素 | 内容 |
|------|------|
| **用户故事** | "我有慢性背痛，跑步和举铁都不行，想找温和的运动。" |
| **ZenFit 方案** | 气功、太极的舒缓动作；坐姿变体；TCM 体质调理建议 |
| **目标关键词** | tai chi for back pain, qigong for arthritis, low impact exercise for joint pain |
| **建议 URL** | /for/back-pain、/for/joint-health |
| **调用的功能** | [Qigong](/features/qigong)、[Tai Chi](/features/tai-chi)（坐姿变体）、TCM 营养 |

### 3. 减压与助眠（Stress & Sleep）

**场景**：工作压力大、失眠，希望通过呼吸与正念改善。

| 要素 | 内容 |
|------|------|
| **用户故事** | "我 50 岁，经常失眠，不想吃安眠药，听说气功有帮助。" |
| **ZenFit 方案** | 气功呼吸、冥想、睡前正念；5–10 分钟短练习 |
| **目标关键词** | qigong for sleep, tai chi for stress, mindfulness for seniors |
| **建议 URL** | /for/stress、/for/sleep |
| **调用的功能** | [Qigong](/features/qigong)、[正念与呼吸](/features/mind-body-balance) |

### 4. 零基础学太极/气功（Beginners）

**场景**：从未接触过太极或气功，想在家自学。

| 要素 | 内容 |
|------|------|
| **用户故事** | "我想学太极，但附近没有课程，有没有适合初学者的 App？" |
| **ZenFit 方案** | Tai Chi 101、Qi Gong Basics；分步视频；5–9 分钟入门课 |
| **目标关键词** | tai chi for beginners, learn qigong at home, tai chi app for beginners |
| **建议 URL** | /for/beginners、/learn/tai-chi-101 |
| **调用的功能** | [Tai Chi](/features/tai-chi)、[Qigong](/features/qigong)、/learn/tai-chi-101、/learn/qigong-basics |

### 5. 退休后的健康管理（Retirement Wellness）

**场景**：退休后有更多时间，希望系统化养生、保持活力。

| 要素 | 内容 |
|------|------|
| **用户故事** | "刚退休，想好好调理身体，对中医养生感兴趣。" |
| **ZenFit 方案** | AI 个性化计划、TCM 营养、每日追踪、长期课程 |
| **目标关键词** | wellness app for retirees, tai chi for 50+, holistic health for seniors |
| **建议 URL** | /for/seniors、/for/retirement-wellness |
| **调用的功能** | AI 个性化、TCM 营养、[健康追踪](/features/mind-body-balance)、[Tai Chi](/features/tai-chi)、[Qigong](/features/qigong) |

### 6. 坐姿/行动不便（Seated & Limited Mobility）

**场景**：站立困难、轮椅用户、术后早期、关节严重不适，需要坐姿或扶椅练习。

| 要素 | 内容 |
|------|------|
| **用户故事** | "我膝盖不好，站不久，有没有坐着也能练的太极？" |
| **ZenFit 方案** | 坐姿 Tai Chi、Chair Qigong、八段锦坐式变体；竞品 Slow Fit 强调此点，ZenFit 可对标 |
| **目标关键词** | seated tai chi, chair tai chi, tai chi for limited mobility |
| **建议 URL** | /for/seated |
| **调用的功能** | [Tai Chi](/features/tai-chi)（坐姿变体）、[Qigong](/features/qigong)、[Eight Brocades](/features/eight-brocades) |

### 7. 术后康复（Post-Surgery Recovery）

**场景**：医生建议温和运动，需循序渐进、不加重伤口。

| 要素 | 内容 |
|------|------|
| **用户故事** | "髋关节置换术后 3 个月，医生建议做温和运动，跑步不行。" |
| **ZenFit 方案** | 5 分钟入门、AI 根据康复阶段推荐强度、呼吸与轻动作优先 |
| **目标关键词** | tai chi for recovery, gentle exercise after surgery |
| **建议 URL** | /for/recovery |
| **调用的功能** | [Qigong](/features/qigong)、[AI 个性化](/features/tai-chi)、[正念与呼吸](/features/mind-body-balance) |

### 8. 职场久坐（Office Workers）

**场景**：午间 5–10 分钟、缓解肩颈、提升下午专注；研究显示职场太极可降低 musculoskeletal 风险、提升 productivity。

| 要素 | 内容 |
|------|------|
| **用户故事** | "每天坐 8 小时，肩颈僵硬，午休想动一动但不想出汗。" |
| **ZenFit 方案** | 5 分钟 Qigong、办公室友好（无需换装）、呼吸+轻动作 |
| **目标关键词** | office qigong, tai chi for desk workers, qigong at work |
| **建议 URL** | /for/office |
| **调用的功能** | [Qigong](/features/qigong)、[正念与呼吸](/features/mind-body-balance) |

### 9. 瑜伽转学/对比（Yoga Alternative）

**场景**：练瑜伽多年关节不适，或想尝试中式身心运动；Learn 页已有「Tai Chi vs Yoga」。

| 要素 | 内容 |
|------|------|
| **用户故事** | "瑜伽练了 10 年，膝盖开始疼，听说太极更温和？" |
| **ZenFit 方案** | Tai Chi vs Yoga 教育、零冲击、强调关节友好 |
| **目标关键词** | tai chi vs yoga, yoga alternative for seniors |
| **建议 URL** | /for/yoga-alternative、/learn/tai-chi-vs-yoga |
| **调用的功能** | [Tai Chi](/features/tai-chi)、[Mind-Body Balance](/features/mind-body-balance) |

### 10. 八段锦/中医养生（Eight Brocades & TCM）

**场景**：对八段锦、中医文化好奇；ZenFit 差异化，竞品少见。

| 要素 | 内容 |
|------|------|
| **用户故事** | "听说过八段锦，和太极有什么区别？想试试。" |
| **ZenFit 方案** | Eight Brocades 专题、TCM 营养、Chinese Wellness Philosophy |
| **目标关键词** | eight brocades for beginners, baduanjin app, TCM fitness |
| **建议 URL** | /for/eight-brocades、/features/eight-brocades |
| **调用的功能** | [Eight Brocades](/features/eight-brocades)、[TCM 营养](/features/qigong)、[Learn](/learn/chinese-wellness-philosophy) |

### 11. 晨间/晚间（Morning & Before Bed）

**场景**：晨起 5 分钟唤醒、睡前 10 分钟助眠；时段场景，竞品 GentleFit 有 30 天挑战可借鉴。

| 要素 | 内容 |
|------|------|
| **用户故事** | "早上起不来，想用 5 分钟太极醒神" / "睡前练什么能助眠？" |
| **ZenFit 方案** | 晨间 Qigong 能量、睡前正念+呼吸；可做 30 天晨间/晚间挑战 |
| **目标关键词** | morning tai chi, qigong morning routine, tai chi before bed, qigong for sleep |
| **建议 URL** | /for/morning、/for/sleep |
| **调用的功能** | [Qigong](/features/qigong)、[正念与呼吸](/features/mind-body-balance) |

### 12. 旅行/离线（Travel & Offline）

**场景**：出差、度假、酒店房间可练；App 支持离线。

| 要素 | 内容 |
|------|------|
| **用户故事** | "经常出差，酒店没健身房，有没有离线能练的？" |
| **ZenFit 方案** | 离线下载、5–15 分钟短课、无需器械 |
| **目标关键词** | tai chi app offline, practice tai chi while traveling |
| **建议 URL** | /for/travel |
| **调用的功能** | [Tai Chi](/features/tai-chi)、[Qigong](/features/qigong)（离线） |

### 13. 5 分钟快速练习（Quick 5-Minute）

**场景**：时间紧、只想动一动；强调「5 分钟也能有效」。

| 要素 | 内容 |
|------|------|
| **用户故事** | "只有 5 分钟，能练什么？" |
| **ZenFit 方案** | 5 分钟 Tai Chi/Qigong 短课、呼吸+核心动作 |
| **目标关键词** | 5 minute tai chi, quick qigong routine |
| **建议 URL** | /for/quick |
| **调用的功能** | [Tai Chi](/features/tai-chi)、[Qigong](/features/qigong) |
