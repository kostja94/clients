## 5. URL 模式与 Sitemap 结构

> Page Types 与 SEO 体系详见 [viggle.md](./viggle.md) Section 10。

**Sitemap 结构**：
```
/、/pricing、/app/home
/tools/[face-swap|ai-dance|meme-maker|image-to-video|...]
/vs/[kling|runway|pika|...]
/for/[meme-creators|tiktok-creators|...]
/glossary/[face-swap|motion-capture|...]
/blog/[slug]
```

| 类型 | 模式 | 示例 |
|------|------|------|
| 首页 | / | viggle.ai |
| 定价 | /pricing | viggle.ai/pricing |
| 应用 | /app/home | viggle.ai/app/home |
| **Tools** | /tools/[slug]/ | /tools/face-swap, /tools/ai-dance |
| **VS** | /vs/[slug]/ | /vs/kling, /vs/runway |
| **For** | /for/[slug]/ | /for/meme-creators, /for/tiktok-creators |
| **Glossary** | /glossary/[slug]/ | /glossary/face-swap |
| **Blog** | /blog/[slug]/ | /blog/... |
