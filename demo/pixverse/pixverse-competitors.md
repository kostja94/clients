## 2. 直接竞品详细拆解

### OpenAI Sora

- **定位**：AI 视频生成领域品牌最响亮的先驱，受 ChatGPT 生态加持
- **优势**：OpenAI 品牌背书、GPT 生态联动、Sora 2 Pro 质量受认可
- **劣势**：API 定价高（$18/min Pro）；生成速度争议；实时交互能力弱于 R1
- **流量**：品牌搜索量极大，品类第一
- **SEO**：sora.com 域名权威极高；媒体覆盖广
- **ELO**：Sora 2 Pro 1,195.5 vs PixVerse V6 1,343（Artificial Analysis 2026-04）

### Kling (快手)

- **定位**：中国短视频巨头推出的 AI 视频模型，Kling 3.0 Omni 定位全能
- **优势**：快手短视频生态数据优势、中国市场壁垒
- **劣势**：国际化程度弱于 PixVerse；API 定价偏高（$13.44/min）
- **流量**：中文搜索为主，英文品类词有覆盖
- **SEO**：klingai.com 中文 SEO 强
- **ELO**：1,298 vs PixVerse V6 1,343

### Runway

- **定位**：AI 视频编辑与创作的综合性专业平台
- **优势**：Gen-3/Gen-4 模型成熟、视频编辑工具链完整（绿幕/运动跟踪等）、ML 社区基础深、品牌认知度强
- **劣势**：API 定价 **待验证**；交互式实时生成不如 R1；模型迭代速度 vs PixVerse V6
- **流量**：**待验证** Semrush（brand awareness 高）
- **SEO**：runwayml.com 品牌词 + 品类词覆盖广

### VEO (Google DeepMind)

- **定位**：Google 旗下前沿视频生成研究模型
- **优势**：DeepMind 研究实力、Google Cloud 生态整合潜力
- **劣势**：API 定价最高（$24/min VEO 3.1）；产品化程度待提升；C 端触达弱
- **流量**：品牌和技术搜索为主
- **SEO**：通过 Google DeepMind 域传播
- **ELO**：1,246 (VEO 3.1) vs PixVerse V6 1,343

## 4. 差异与机会

| | 分析 |
|---|------|
| **S** | V6 ELO 1,343 第三方评测第一；R1 独家实时交互引擎；API 性价比最优 $4.80/min；自研全模型矩阵（V6/R1/C1）；CPP 创作者生态壁垒；AI 独角兽 + Alibaba $60M Series B |

| **O** | Vs 对比页借助 Artificial Analysis 数据强化「ELO 第一」「性价比最优」叙事；Template Gallery 公开可索引；FIFA 2026 合作（足球小将 KAGAMI Gate）品牌曝光；日/韩/东南亚市场本地化；API 开发者社区建设 |
| **T** | Sora 品牌挤压 + ChatGPT 生态绑定；Runway 专业工具链粘性；Kling 中国市场壁垒；Google VEO + Cloud 生态整合潜力；Meta/Apple 等大厂潜在入局 |

1. 强化 **「ELO #1 + 最低 API 价格」** 双冠叙事，在所有对比场景中突出 Artificial Analysis 数据
2. 独家的 **R1 实时交互世界引擎** 作为技术护城河，与竞品的"离线生成"形成代际差异
3. **C1 影视级模型** 切入专业细分市场，区别于 Sora/Runway 的通才定位
4. **CPP 创作者生态** 构建创作者 → 平台 → 品牌的增长飞轮
5. FIFA 2026 × 足球小将 KAGAMI Gate 合作形成体育 IP 独占壁垒
