## 3. 战役节奏

### 短期（0–90 天）

- **修复 sitemap-index.xml**（当前 500 错误），确保品牌站可被搜索引擎正常索引
- 上线 3 个 `/vs/*` 对比页（vs Sora / vs Kling / vs Runway），核心引用 Artificial Analysis 数据
- 构建 `/features/text-to-video`、`/features/image-to-video` 等能力着陆页
- 公开可索引的 `/pricing` 页（含 C 端订阅 + API 定价透明化）
- News 页已有 16+ 篇新闻稿，补充结构化 SEO 元数据
- CPP 2.0 创作者招募推广 + 首批 Creator Spotlight 案例发布

### 中期（90–180 天）

- 建独立的 API 开发者文档站（`/api/docs` 或 `docs.pixverse.ai`），承接 video api 关键词
- Template Gallery 公开可索引（app 内模板外化至品牌站 `/templates`）
- Blog/Guide 内容体系搭建（每月 4-6 篇教程 + 行业分析）
- FIFA 2026 期间（6–7 月）最大化 KAGAMI Gate 合作曝光
- 首批多语言 Landing 实验（日语 `/ja`、韩语 `/ko`、西班牙语 `/es`）
- Semrush/Ahrefs 跟踪核心品类词排名与竞品份额变化

### 长期（180 天+）

- Enterprise 方案详情页（含客户案例 + ROI 计算器）
- PixVerse Originals 孵化计划：签约/投资头部 AI 视频创作者
- 多模型矩阵分级定价（V6 fast/quality modes、R1 real-time tier）
- 本地化深度拓展（日/韩/东南亚建本地团队 + 内容运营）
- 与电影节/创意赛事合作，强化 C1 影视级定位
- 教育市场渗透（AI 视频制作课程 + 高校合作）

## 4. 变现与留存

### C 端变现

- **Freemium → Subscribe**：免费 Credits 试用 → 耗尽后推送订阅
- **CPP 变现循环**：创作者产出优质内容 → 获 Credits + 现金奖励 → 持续使用平台 → 吸引更多用户
- **订阅分层**：基础版（个人创作者）→ 专业版（重度用户）→ 团队版（**待验证** 是否存在）

### B 端变现

- **API 按量计费**：V6 $4.80/min，按分钟计费（同类最低，ELO 最高）
- **Enterprise 定制**：全栈方案（降本 68% + 10× 产出），直接销售触达
- **多模型分层**：不同模型不同价格档位（V6 vs C1 vs R1）

### 留存

- **News/Changelog**：模型迭代（V6→R1→C1）持续制造关注
- **CPP 激励**：分级制度（Partner→Pro→Premier）驱动创作者持续产出
- **Community**：Creator Spotlight 曝光激励 + 社区认可
- **Canvas/Mini-Apps**：工具生态增加平台粘性
- **Agent**：对话式交互降低使用门槛，提高留存

## 5. 技术 SEO 注意

| 项 | 现状 | 建议 |
|----|------|------|
| sitemap | sitemap-index.xml 返回 500 | 紧急修复，确保品牌站全量 URL 可被索引 |
| robots | 全 Allow，无 AI 爬虫屏蔽 | 评估是否对 GPTBot/ClaudeBot 做策略性屏蔽 |
| app 子域 | app.pixverse.ai 需登录 | 确保公开着陆页（非登录墙）可被索引 |
| 品牌站首页 | SPA/SSR **待验证** | 确保 SSR 渲染，搜索引擎可抓取完整内容 |
| 多语言 | 177+ 国家服务但无多语言结构 | hreflang 策略制定 |
| 结构化数据 | **待验证** | 建议加入 VideoObject / Organization / Article schema |
| Core Web Vitals | **待验证** | Lighthouse 性能审计 |
