## 1. 增长目标与约束

| 维度 | 策略 |
|------|------|
| **主转化** | 官网/内容 → **Telegram Bot** 启动 → 首笔 Pool |
| **主战场** | 加密 Twitter/X、Telegram 社群、中文 crypto 媒体 |
| **品类定位** | 不做「美国大选主战场」；做 **Asia + Telegram + crypto price** |
| **合规约束** | 对外禁用夸大收益；地区限制与风险披露须法务审定 |
| **品牌资产** | Slogan「亞洲自己的預測市場」贯穿中英文落地页 |

## 6. 合规与话术（增长侧）

- 使用 **prediction / forecast / market**，慎用 **gambling / casino**。  
- 所有战役落地页链接 **Risk Disclosure**。  
- 不在广告中承诺收益；NFT「降费」需写清规则。  
- 地区定向：付费广告 **待法务** 批准国家列表。
