## 1. Core capabilities (About — “What TubeAnalytics Does”)

| Module | Description (site voice) |
|--------|---------------------------|
| **Revenue analytics** | Authenticated **CPM / RPM** by video and geography (YouTube Analytics API) |
| **Retention curves** | Timestamped audience drop-off—where viewers leave |
| **AI thumbnail testing** | Upload a finished thumbnail; **predicted CTR score** before publish |
| **Competitor tracking** | Rival upload cadence, view trends, engagement benchmarks (plan caps below) |
| **View velocity** | Breakout signal in the first **48 hours** for new uploads |
| **Audience demographics** | Age, gender, geography; site emphasizes who watches longest and drives revenue |

**Sync (About)**: owned-channel metrics ~**hourly**; competitor data ~**daily**; read-only OAuth—no channel settings changes on the user’s behalf.
