## 二、核心功能详情

### 1. Based on Your Own Data

**Massive File Uploads**
- 将文档、幻灯片、表格、图片集中上传
- 支持大规模文件

**Smart Integrations**
- 连接常用工具与数据库
- 保持数据同步与更新

**Intelligent Knowledge Base**
- Kuse 理解数据并转化为可搜索知识库
- 支持后续创作与引用

**Source Only Mode**
- 仅基于自有材料工作
- 准确优先场景

### 2. Create & Edit in Every Format

**AI Note**
- 自由思考，AI 帮助组织与连接想法

**Layout Reference**
- 秒级产出 CV、发票、报告等文档
- 支持模板与布局参考

**Online Presentation**
- 将复杂想法转化为清晰美观的演示

**Interactive Quiz**
- 创建测验，检验理解、强化学习

**AI Image**
- 使用理解项目上下文的图像模型设计视觉

**Interactive Webpage**
- 几秒内创建并发布完整网站

**Study Note**
- 保持输出在视觉与结构上的一致性

### 3. Collaborative Workspace

**Human + AI + Human**
- 在智能工作区中协作与共创

**Evolving Memory**
- AI 记忆随你或团队的变动而更新

**Living Workspace**
- 每次创作都反哺下一次，工作区越用越智能

### 4.3 Kuse for Excel 页面结构（可复用模板）

| 区块 | 内容 |
|------|------|
| Hero | 主标题 + 副标题 + CTA |
| 核心价值 | Simple interaction、Guided / assisted execution（人机协同）、Multi-file to deliverables |
| 能力列表 | Selection Reference、Data Cleaning、Formula Generator、Charts、Reports、Aggregations |
| 对比表 | Kuse vs Excel（可改为 Kuse vs PowerPoint / Docs 等） |
| 扩展能力 | Go beyond Excel（跨表、非结构化数据、可视化产出） |
| Templates | 免费模板（Cap Rate、DSCR、Rehabbing 等） |
| Blog 入口 | Kuse vs Claude、10 Best AI Tools 等 |
| FAQs | 4–5 条 |

### 4.4 落地优先级

| 优先级 | 页面 | 理由 |
|--------|------|------|
| P0 | Kuse for Excel | ✓ 已上线 |
| P1 | Kuse for Presentations | 演示需求强，与 Gamma 竞品对标 |
| P1 | Kuse for Documents | 文档为主站核心能力 |
| P2 | Kuse for Websites | 落地页/网页生成，转化场景明确 |
| P2 | Kuse for Google Sheets | 与 Excel 同逻辑，GSheets 用户量大 |
| P3 | Kuse for Education / Marketing / Finance | 与 Use Cases 配合，行业入口 |
