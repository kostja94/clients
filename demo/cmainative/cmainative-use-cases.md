## 2. Persona / 方向归纳（分析）

| 方向 | 来源角色 | 核心痛点 | 官网文案表达的承诺 |
|------|---------|---------|-------------------|
| **一把手 / CEO** | #1 #2 #11 | 知道 AI 重要，但认知不到位导致组织推不动 | 一把手亲自用 → AHA moment → 1 天拆转型 |
| **转型推进者** | #3 #4 #5 #8 | 工具买了、培训做了，业务没变化 | 诊断卡点 → 找 AI 先锋 → 建生产力部 |
| **行业业务负责人** | #10 + 7 个 solution 页 | 不清楚本行业 AI 从哪切入、如何验收 | 行业痛点 → 实施路径 → 验收标准 → 活动 |
| **产品 / 数字化负责人** | #6 #7 | 试点做完就散，缺工具承接 | 特区 FDE 模式 + Easy Suite 沉淀 |

归纳依据：官网首页弹窗三分法（思维 / 组织 / 产品）+ solution 页统一结构（痛点 → 路径 → 验收 → 活动 CTA）。
