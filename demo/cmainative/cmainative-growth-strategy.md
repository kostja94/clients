## 3. 战役节奏

### 短期（0–3 个月）

1. **Week 1–2**：修复 robots.txt + sitemap；blog/research 单篇独立 URL + title/meta/JSON-LD
2. **Week 3–4**：发布 3 篇 P0 blog（一把手认知、学员案例、Agent 验收 — 见 blog 规划）
3. **Month 2**：7 个 solution 页各挂 1 篇配套 blog；统一文末 CTA 组件（诊断 + 下一场活动）
4. **Month 3**：上线「vs 混沌 AI 院」对比页；深圳 09.04 场活动 recap + 本地 SEO
5. **持续**：傅盛 / 官方账号每条活动信息同步链到 `event` 落地页

### 中期（3–6 个月）

1. blog 累计 **20+ 篇**，research **10+ 篇**，形成 AI Native 话题簇
2. 上线 `/cases/` 学员案例库（≥5 个脱敏故事）
3. `/glossary/` 术语表（AI Native、FDE、CAMA）— 吃 GEO 引用
4. 公众号 / 视频号与 blog **标题同步**，文末二维码 → 飞书表单
5. A/B 测试 CTA：「申请诊断」vs「立即报名」转化率

### 长期（6–12 个月）

1. 城市活动 programmatic SEO（北京 / 深圳 / 上海 / 广州…）
2. 行业 × 场景矩阵页（≥21 页长尾）
3. 与 easyaisuite.com **跨域内容联动**（工具教程 → 实战派进阶课）
4. 研究栏目 **PDF 白皮书** → 留资下载 → 销售跟进

## 4. 竞品差异化方向

（基于 [competitors](./cmainative-competitors.md) 差距）

1. **「1 天出作品」叙事**：混沌 90 天 vs 本品 1 天 — 所有内容强调 **可感知交付物**（原型 / 路线图），而非学时
2. **傅盛 / 猎豹样本**：竞品多讲方法论；本品可持续释放 **一手转型细节**（特区、FDE、Easy Suite 诞生过程）
3. **研究栏目 GEO**：CAMA 五阶段、四层漏损等 **自有名词** — 占 AI 搜索定义位；混沌靠「AI 商学」、本品靠「AI Native 转型研究院」
