## 2. 用户流程

### 路径 A：活动获客（主卖课路径）

1. 搜索 / 社交 / 傅盛内容 → 进入 `cmainative.cmcm.com`
2. 浏览「猎豹自己走了一遍」+ 活动日程 → 点击「立即报名」或「报名 9 月 4 日深圳场」
3. 填写飞书表单 / 扫码 → 销售跟进 → 线下支付 → 参加活动
4. 现场：上午方法论 + 下午 FDE 陪练实操 → 带走业务原型 / 路线图
5. 高意向客户 → 企业诊断 / 入企陪跑 / Easy Suite 续约

### 路径 B：内容种草 → 转化

1. 阅读 blog / research 文章（如「AI 能力边界为什么像锯齿线」）
2. 文末 CTA → 申请诊断 / 查看近期活动 / AI Native 特区
3. 进入路径 A 或 B 的企业服务漏斗

### 路径 C：行业精准入口

1. 搜索「教育行业 AI」→ `solution-education.html`
2. 确认痛点与验收标准 → 「查看近期实战活动」→ 报名
