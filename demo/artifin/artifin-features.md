## 1. 双层 AI 引擎（核心架构）

### 1.1 架构概览

```
用户输入股票代码
        ↓
L1：七位专业分析师（并行执行）
  Natasha  Steve  Tony  Thor  Clint  Sam  Vision
  (宏观)   (行业)  (技术)  (风控)  (基本面)  (财报)  (量化)
        ↓  去噪 + 量化打分
        ↓  仅合格资产升入 L2
L2：七位投资大师圆桌辩论（红蓝对抗）
  Buffett  Lynch  Marks  Soros  Dalio  Druckenmiller  Duan
        ↓  多维度辩论 → 圆桌综合
输出：综合建议 + 牛熊风险报告 + 仓位配置
```

### 1.2 L1 分析师能力矩阵

| 分析师 | 方法论 | 输入数据类型 | 输出 | 技术依赖 |
|--------|--------|-------------|------|---------|
| Natasha | 宏观量化 | 央行声明、经济指标、地缘政治新闻情绪 | 市场环境评分、风险等级 | NLP + 情绪分析 |
| Steve | 行业轮动 | 行业资金流、ETF 流量、经济周期指标 | 最优行业配置排序 | 资金流模型 |
| Tony | 技术分析 | 价格数据、成交量、技术指标 | 趋势评估、支撑/阻力位 | 图表形态识别 |
| Thor | 风险建模 | 历史波动率、相关性矩阵、尾部事件 | 压力测试、VaR、下行风险 | 蒙特卡洛模拟 |
| Clint | 基本面分析 | 财务报表、行业数据、估值倍数 | DCF 估值、财务健康评分 | 财务建模引擎 |
| Sam | 财报分析 | 财报、分析师预期、营收拆分 | 超预期分析、利润率趋势 | 金融 NLP |
| Vision | 量化回测 | 历史价格、因子数据、统计指标 | 因子暴露、回测报告、错误定价标记 | 统计模型 + 因子库 |

### 1.3 与通用大模型的区别

标准 AI 问答遵循"一个模型 → 一个答案"。ARTI 遵循"七位分析师并行去噪 → 七位大师红蓝对抗辩论 → 综合建议"。每一层独立验证，架构性降低 LLM 幻觉风险。

## 2. 红蓝对抗机制

### 2.1 机制概述

模拟顶级投资委员会的多维度辩论过程。七位大师从价值、成长、周期、反身性、宏观配置、动量、商业模式视角独立分析同一资产——揭示任何单一视角都会错过的盲点。

### 2.2 对抗输出

| 输出类型 | 内容 |
|---------|------|
| 多视角观点 | 每位大师的独立分析（核心逻辑、关键指标、评分） |
| 反驳挑战 | 针对每个看涨论点的批评与风险暴露 |
| 风险报告 | 牛方和熊方的风险管理建议 |
| 综合建议 | 圆桌综合 — 去偏见的仓位配置与可操作建议 |

### 2.3 确认偏误消除原理

单一 AI 模型倾向于输出用户想听的内容（确认偏误）。红蓝对抗辩论强制将对立视角引入分析，确保每个看涨论点都经受了来自截然不同投资哲学的挑战。

## 3. 智能资产匹配

### 3.1 功能描述

上下文感知的精准产品推荐引擎，不仅分析所查询的资产，还自动匹配相关机会。

### 3.2 覆盖范围

| 维度 | 覆盖 |
|------|------|
| 全球资产工具 | 55+ 种 |
| 传统市场 | 美股、港股、A 股 |
| 稀缺资产 | 日本 ETF、RWA（真实世界资产）结构化产品 |
| 匹配逻辑 | 上下文感知 — 基于资产属性、用户画像、市场环境动态推荐 |

## 4. 24/7 策略追踪

### 4.1 功能列表

| 功能 | 描述 |
|------|------|
| 自动回测 | 24 小时历史回测验证投资组合策略 |
| 市场监控 | 实时监控持仓关键价格与指标变动 |
| 止损预警 | 预设风险阈值触发时主动推送预警 |
| 宏观异常检测 | 监控央行政策转向、地缘政治事件等宏观冲击信号 |
| 策略失效预警 | 当策略底层逻辑崩塌（如基本面恶化），主动通知纠偏 |

### 4.2 与传统预警工具的差异

传统工具仅在价格水平触发。ARTI 的策略追踪运行在**逻辑层**——监控的是策略所依赖的前提是否仍然成立，而非仅仅价格阈值是否被突破。

## 5. SFC 持牌风控

### 5.1 牌照信息

| 项目 | 详情 |
|------|------|
| 持牌实体 | 香港主板上市公司背书 |
| 牌照类型 | SFC 第 1 类（证券交易）、第 4 类（证券咨询）、第 6 类（企业融资咨询）、第 9 类（资产管理） |
| 风控机制 | 每项 AI 生成的分析建议均经过持牌机构风险逻辑校验 |

### 5.2 合规价值

相较于无牌照的 AI 投顾工具，ARTI 的分析输出锚定在监管红线上——在 AI 金融建议领域建立了"硅谷 AI 巨头不敢碰"的竞争护城河。
