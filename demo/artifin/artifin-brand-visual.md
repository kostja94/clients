## 1. 品牌识别概览

ARTIFIN 的视觉识别将产品定位在机构金融与现代 AI 的交汇点。设计语言同时避开了"玩具感金融科技"（亮渐变、大量 emoji）和"冷酷机构风"（密集表格、终端美学）——而是投射出干净、自信、高级智能的品牌形象。

**核心视觉隐喻**：投资圆桌 —— 七个独特视角汇聚为一个整合视图。视觉上转化为结构化辩论界面，角色区分清晰。

## 2. 色彩系统

### 2.1 主色调

| 角色 | 颜色 | 色值 | 用途 |
|------|------|------|------|
| 主深色 | 深海军蓝/炭灰 | #0F172A（预估） | 标题、正文、页脚背景 |
| 主强调色 | 电光蓝 | #3B82F6（预估） | CTA、活跃状态、链接、进度指示器 |
| 背景色 | 近白/米白 | #F8FAFC（预估） | 页面背景、卡片背景 |
| 表面色 | 纯白 | #FFFFFF | 卡片、弹窗、分析面板 |

### 2.2 红蓝辩论系统（核心差异化）

对抗机制有独立的色彩编码：

| 角色 | 颜色 | 含义 |
|------|------|------|
| 牛方/做多/红队 | 暖红/玫红 | 看涨论点、成长论证、机会面 |
| 熊方/做空/蓝队 | 冷蓝/钢蓝 | 看跌论点、风险警示、谨慎面 |
| 综合/中性 | 石板灰/中性灰 | 圆桌综合建议 |

此色彩系统直接映射到红蓝对抗辩论输出 — 让读者一眼扫去立刻知道是哪个视角在发言。

## 3. 字体

### 3.1 字体栈

| 角色 | 字体 | 样式 | 备注 |
|------|------|------|------|
| 标题（H1-H3） | Inter 或 SF Pro Display（预估） | Semi-bold 至 Bold | 干净几何无衬线，传递权威 |
| 正文 | Inter 或系统无衬线 | Regular（400） | 16px 高可读性 |
| 数据/数字 | 等宽数字（mono） | Regular | 表格中数字对齐一致 |
| 代码/股票代码 | JetBrains Mono 或 SF Mono（预估） | Regular | 清晰显示股票代码 |

### 3.2 字号层级

| 级别 | 字号 | 字重 | 用途 |
|------|------|------|------|
| H1 | 48-56px | Bold（700） | 首页主标题 |
| H2 | 32-40px | Semi-bold（600） | 段落标题 |
| H3 | 24-28px | Semi-bold（600） | 卡片标题、功能名 |
| 正文 | 16px | Regular（400） | 段落、描述 |
| 说明/元信息 | 14px | Regular（400） | 标签、时间戳、来源 |
| 股票代码 | 20-24px | Mono Bold | 股票代码、价格数据 |

### 4.2 Logo 使用规范

- **安全间距**：四周最小留白等于 ARTIFIN 中"A"的高度
- **最小尺寸**：数字端 40px 高，绝不低于 24px
- **背景**：偏好白色或浅色背景；浅色表面使用深色 Logo 变体
- **禁止**：拉伸、旋转、添加效果或改色 Logo 标志

### 4.3 品牌名称惯例

| 用途 | 形式 |
|------|------|

| 产品名 | ARTI（全大写） |
| 描述性名称 | AI 投资圆桌（AI Investment Roundtable） |
| URL | artifin.ai |

## 5. 头像与人物系统

### 5.1 头像架构

头像系统是 ARTI 最强的视觉差异化之一 — 每位大师和分析师都有独特的插图头像，作为其投资哲学的视觉速记。

| 头像集 | 路径 | 数量 | 风格 |
|--------|------|------|------|
| 大师头像 | /avatars/circle/ | 7 | 圆形肖像插画 — 鲜明、可辨识，各自唤起投资哲学 |
| 分析师头像 | /avatars/circle/ | 7 | 圆形肖像插画 — 专业、分析风格 |

### 5.2 大师视觉个性

| 大师 | 视觉线索（预估） | 个性 |
|------|----------------|------|
| 巴菲特 | 年长绅士、眼镜、保守着装 | 智慧、耐心、可信赖 |
| 林奇 | 精力充沛、平易近人 | 好奇、成长思维 |
| 马克斯 | 深思、分析型 | 逆向思维、周期思考 |
| 索罗斯 | 锐利、强烈 | 挑衅、系统思维 |
| 达里奥 | 结构化、系统化 | 纪律、流程驱动 |
| 德鲁肯米勒 | 果断、专注 | 进取、机会主义 |
| 段永平 | 务实、直接 | 运营导向、不废话 |

### 5.3 头像使用规则

- 每位大师的头像出现在其辩论贡献和分析卡片旁
- 头像在辩论线程中呈现为 48-64px 圆形裁剪
- 完整分析页可使用更大 96-128px 版本
- 不得在 AI 生成分析之外使用大师/分析师头像

## 6. UI 组件风格

### 6.1 核心组件

| 组件 | 风格方向 |
|------|---------|
| 卡片 | 轻阴影（0px 2px 8px rgba(0,0,0,0.08)）、8-12px 圆角、白色背景 |
| 按钮（主） | 电光蓝填充、白色文字、8px 圆角、16px 水平内边距 |
| 按钮（次） | 描边风格、1px 蓝色边框、透明填充 |
| 输入框 | 1px gray-300 边框、8px 圆角、16px 内边距、聚焦环为主蓝色 |
| 标签页 | 下划线风格、活跃态为主蓝色 |
| 进度条 | 分析师→辩论→综合渐变、动画填充 |
| 辩论线程 | 彩色左边框（红为牛、蓝为熊）、差异化头像+名称头部 |

## 7. 设计原则

### 7.1 核心原则

| 原则 | 描述 |
|------|------|
| **透明建信任** | 每次分析展示推理过程 — 无黑箱、无单一评分。界面揭示谁说了什么、为什么。 |
| **辩论而非命令** | UI 呈现多重视角，从不是单一"正确"答案。视觉层级反映对抗过程。 |
| **专业不冷酷** | 干净的数据呈现搭配人物头像的人性温度。同时避开玩具化游戏化和无菌终端美学。 |
| **可扫描的深度** | 深度分析分层呈现 — 标题给出判断，展开区显示推理，色彩编码标示牛熊。 |

### 7.2 反模式（避免事项）

| 避免 | 原因 |
|------|------|
| 游戏化分数、徽章或连击 | 削弱严肃专业的定位 |
| 单一"买入/卖出"评分 | 与多角度辩论哲学矛盾 |
| 股票行情闪烁动画 | 像交易平台，非分析工具 |
| 过度 emoji 或娱乐化文案 | 与机构信任定位不匹配 |
| 无叙事的数据密集表格 | 投资者需要解读，非原始数据 |

## 8. 竞品视觉差异化

| 元素 | ARTI | QarvioFin | TradingView | Bloomberg |
|------|------|-----------|-------------|-----------|
| 视觉识别 | 7 个独特大师人物 | 2 智能体牛/熊 | 图表 + 社交动态 | 数据密集终端 |
| 色彩系统 | 红蓝辩论 + 大师色 | 可能牛/熊二元 | 交易绿/红 | Bloomberg 橙/黑 |
| 人物/头像系统 | 14 个插图人设 | 无（文字型智能体） | 无 | 无 |
| 界面个性 | 圆桌辩论 | 结构化论证 | 社区市集 | 机构工作站 |
| 情感调性 | 好奇、自信、透明 | 学术、严谨 | 社交、活力 | 权威、机构 |

ARTI 的人物驱动视觉系统是实质性护城河 — 竞品可以复制多智能体架构，但无法轻易复制 14 个人物插图头像系统和它所创造的视觉叙事。
