## 3. 战役节奏

### 短期（0–3 个月）

1. 上线 **Shanghai Food Tours** + **Beijing Private Tours** 两个 hub 页（P0 词承接）。
2. 为 17 个产品页补 **Product schema**（价格、评分、duration）— 修复私享价不可见问题。
3. TripAdvisor 主页链回官网 curated-city-tours；首页展示 TA 徽章。
4. 发布 1 篇 **「Small-group vs large tour in China」** 信息文，内链小团产品。

### 中期（3–6 个月）

1. 8 条 Example Itinerary 页独立 meta title/description + 内链至 builder。
2. 启动 **Guide Spotlight** 月更（SEO + 社交素材）。
3. A/B 测试 china-journeya 表单字段，缩短询价摩擦。
4. 对比文：**Eastbound vs Lost Plate**、**vs Jenny's**（官网直销对标）；另可写 **vs large OTA tour** 信息文。

### 长期（6–12 个月）

1. 建立 **China Travel Guide** 权威 hub（10+ 常青文），cluster 链向产品与定制。
2. 拓展 **Xi'an / Chengdu** landing（定制 builder 已有，补 SEO 入口）。
3. 评估 Shopify UCP / Agent 渠道订单占比；优化 agents.md 产品描述。
4. 多语言 hreflang 可行性研究（德语/法语评价已有，或可从导游能力延伸）。

## 4. 竞品差异化方向

基于 [competitors](./eastbound-and-beyond-competitors.md) 行业结构：

1. **对标国内自建站同行**（Lost Plate / Jenny's / China Highlights）：城市 hub + 评价聚合，抢官网直销流量。
2. **内容资产学 WildChina / China Highlights**：签证、礼仪、城市指南常青文，再内链产品与 Journey Builder。
3. **「Boutique · 原创 · 高端」可视化**：无旗帜小团 vs mass 组团；用于 landing hero 与广告素材。
4. **双重角色叙事**：官网 2C 直销 + 可承接 Audley / A&K / Wendy Wu 类海外品牌的中国精品落地。
5. **Instant book + human concierge**：Shopify 即时订与 12h WhatsApp，对比纯顾问制 luxury 长周期。
