# Runner AI 功能与主张

> 关联：[runnerai.md](./runnerai.md) | [runnerai-use-cases.md](./runnerai-use-cases.md)

**主要来源**：[runnerai.com](https://www.runnerai.com/) 首页与功能向页面；[docs.runnerai.com](https://docs.runnerai.com/)（如 *AI Store Builder*、*Getting Started*）。以下为归纳，**具体以线上产品与条款为准**。

---

## 一、能力分层（官网叙事）

### 1. AI 生成与编辑

| 模块 | 官网/文档要点 |
|------|----------------|
| **对话式建站** | 通过聊天描述业务，在「约 5 分钟」量级完成店铺生成叙事；强调无需传统主题/模板/代码/设计起步。 |
| **AI 视觉** | 生成商品图、营销视觉；降低实拍与设计门槛。 |
| **商品 Listing** | 自动生成商品信息与上架相关素材。 |
| **可视化编辑** | 生成后可微调布局、图文与模块（文档站有视觉编辑相关说明意图）。 |

### 2. 一体化电商栈（相对「插件拼图」）

首页以标签云形式罗列多类能力（节选归纳）：**聊天组件、SEO、GEO、加售、捆绑、多规格、弹窗、CRO、CRM、个性化推荐、心愿单、A/B 测试、会员与奖励、定向促销、评论、智能结账、公告栏** 等，并配合「节省约 **70%** 成本」类主张——宜在对外材料中附**计算口径**或改为定性表述。

### 3. 增长与实验（「AI 跑优化」）

| 能力 | 说明 |
|------|------|
| **行为分析** | 分析访客与购买路径，为实验与个性化提供输入。 |
| **自动实验** | 自动发起 **A/B** 与 **多变量** 测试（内容、布局、动线、促销、定价等）；可选手动分配流量或由 AI 管理。 |
| **扩量** | 识别获胜变体，按受众做个性化并持续放大（官网叙事）。 |

## 二、与 Shopify / 主题的邻近能力

官网展示 **Remix Shopify Theme** 等场景，文档与营销中亦强调可服务于 **Shopify 体系下的店铺构建与优化**心智。实施边界（是否托管、域名、 catalog 同步、结账路径）需产品/售前确认，避免 SEO 页面过度承诺。

## 四、对外表述注意

- 百分比类指标（成本节省、转化率提升、速度）建议对应 **案例脚注、统计周期或免责**。
