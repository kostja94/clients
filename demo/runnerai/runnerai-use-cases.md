# Runner AI 场景与 Persona

> 关联：[runnerai.md](./runnerai.md) | [runnerai-features.md](./runnerai-features.md)

---

## 一、核心 Persona

| Persona | 动机 | Runner AI 匹配点 |
|---------|------|------------------|
| **DTC 新手创始人** | 快速验证品类与首单 | Prompt 生成、分钟级上线叙事、低学习成本 |
| **小微电商卖家** | 降本、少雇人 | 一体化工具栈、少插件 |
| **跨境卖家** | 独立站 + 多渠道试水 | 建站速度、SEO/GEO 模块（以实际功能为准） |
| **增长/运营负责人** | 持续抬转化率 | 自动 A/B 与多变量、行为数据驱动 |
| **已有 Shopify 资产方** | 主题与页面升级 | Remix/Shopify 相关叙事（边界需售前对齐） |

---

## 二、典型场景（可用于案例与着陆页）

1. **从 0 到 1**：仅有产品与简报 → 对话生成店铺 → 上架首批 SKU → 开启基础促销与弹窗。  
2. **视觉与 Listing 批量**：多 SKU 需图与描述 → AI 生成商品图与文案 → 人工抽检后发布。  
3. **增长实验**：首页首屏、价格模块、结算路径 → 系统自动跑实验 → 放大优胜版本。  
4. **替换工具碎片**：减少「建站 + 邮件 + 弹窗 + 推荐 + CRM」多账单 → 统一门户（需财务测算支持）。
