## 五、SEO 与技术建议（内部）

| 建议 | 理由 |
|------|------|
| 核心关键词 **pillar**（如 AI ecommerce website builder）与 Features、Docs **三角互链** | 传递主题相关性、降低孤立长文 |
| 长文对比区块若与首页重复度高，考虑 **canonical** 或精简为摘要 + 链至 Blog | 避免重复内容稀释 |
| Docs 多语言路径（如 `/en/`）与 **hreflang** | 若正式做多市场 |
| 案例与实验结果页加 **Article** / **FAQ** schema（视模板） | 支撑长尾与富摘要 |
| 声明「分钟上线」「70% 节省」类，配套 **脚注或方法页** | E-E-A-T 与广告合规 |
