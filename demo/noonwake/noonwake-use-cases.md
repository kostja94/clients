## 一、人物画像

| 画像 | 描述 | 核心诉求 |
|------|------|----------|
| **海外「深夜失眠者」** | Gen-Z / 年轻上班族；凌晨清醒、无人可聊 | **无评判倾听** + 占星/塔罗语言下的 **情绪命名与安抚**，避免说教 |
| **占星兴趣者** | 已有 Co-Star 等产品使用习惯 | 更深 **AI 对话**、**个人星图** 与 **长期记忆**，而非仅推送通知 |
| **塔罗自省者** | 把塔罗当反思工具，非宿命论 | 单卡/牌阵 + 引导语，强调 **reflect not predict**（与官网文章方向一致） |
| **国内「十神 / 五行」体验者** | 对传统文化人格化叙事有兴趣 | **每日人格唤醒**、宝典与决策辅助口吻；**非**专业命理线下替代 |
| **八字 / 风水关注者（业务假设）** | 你方描述的核心延展人群 | 需产品确认 **功能边界** 与 **表述合规** 后再做定向内容 |
| **硬件早期用户** | 喜欢桌面摆件、日历仪式、小红书生态 | **Lucky Calendar Machine** 的可视化陪伴与收藏/赠礼场景 |

## 二、典型场景

1. **水逆 / 行运焦虑**：用行运解读 + 聊天承接情绪，降低「搜索引擎碎片化」带来的二次焦虑。  
2. **关系与合盘**：星盘可视化 + AI 解读（Synastry 类需求常见于竞品，可作为内容集群）。  
3. **独处夜话**：万象侧 — 唤醒当日人格，在多视角对话中梳理工作、情感抉择。  
4. **碎片化自我观察**：记录互动轨迹与「人格维度」成长，形成轻度 **日记式** 使用习惯。  
5. **从软件到桌面仪式**：手机陪伴 → 硬件日历/打印物 → 强化 **每日打开理由** 与礼品属性。  

---

## 三、边界（对外沟通建议）

- **医疗与心理**：明确 **不替代** 专业诊断与治疗；危机情形需引导至真人帮助与热线资源。  
- **占卜主张**：弱化「必然预测」，强化 **反思、叙事与情感支持**，利于平台政策与品牌信任。  
- **传统文化**：八字、风水等内容在广告与商店审核中敏感 — 材料需本地化法务过稿。
