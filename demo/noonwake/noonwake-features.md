## 三、万象有灵 — 功能（据应用分发简介归纳）

来源示例：[应用宝 · 万象有灵](https://sj.qq.com/appdetail/com.noonwake.allspirit)

| 能力 | 摘要 |
|------|------|
| **人格唤醒与对话** | 依时间节律与用户行为，每日唤醒最相关虚拟人格；多视角、带基础记忆的连续对话 |
| **成长体系** | 互动映射至不同人格维度，长期轨迹，解锁更深陪伴内容 |
| **万象内容与播客** | 多角色 AI 信息流，对现实议题多维度解读 |
| **宝典深度解读** | 情感、事业等主题，分章节引导式生成与分析 |
| **沉浸式陪伴** | 非结论导向的自我观察与情绪梳理（免责声明：非医疗） |

第三方下载站常列「情绪画像、场景化陪伴、语音包与虚拟空间定制」等 — **以官方版本说明为准**。

## 四、技术叙事（官网「Under the Hood」）

| 块 | 摘要 |
|----|------|
| **模型蒸馏与微调** | 面向占星/玄学领域的小模型；LoRA 微调，强调非通用 prompt 瞎编 |
| **长期记忆** | 记住出生星图/人格档案与对话历史，使用越久越贴用户 |
| **AI Agent 平台** | 多智能体编排：星盘、塔罗等由专门 agent 承担，再拼成个性化体验 |
| **RAG / 知识图谱** | 与站面标签一致，用于领域知识 grounding（细节以上线架构为准） |
