## 二、按 Agent 模板（官网 Coming Soon）

### 1. Travel Agent（Manus Agent Template）

**谁**：旅行平台、OTA、出行服务  
**情境**：行程规划、预订、推荐、客服  
**产出**：行程建议、预订确认、推荐、多通道客服  
**关键词**：travel agent iMessage, agent for travel, bring travel agent to iMessage

### 2. Customer Support Agent

**谁**：企业客服、SaaS、电商  
**情境**：7×24 客服、工单、FAQ、多通道  
**产出**：自动回复、工单、FAQ 解答  
**关键词**：customer support agent, agent for support, multi-channel support agent

### 3. Companionship Agent

**谁**：社交、健康、教育产品  
**情境**：陪伴、提醒、情感支持  
**产出**：对话、提醒、日程  
**关键词**：companionship agent, AI companion, messaging companion

### 4. Productivity Agent

**谁**：个人、团队、企业  
**情境**：会议摘要、日程、待办、邮件  
**产出**：会议摘要、日程同步、待办提醒  
**关键词**：productivity agent, meeting summary agent, agent for productivity

### 5. Concierge Agent

**谁**：酒店、高端服务、礼宾  
**情境**：预订、礼宾、个性化服务  
**产出**：预订、推荐、礼宾服务  
**关键词**：concierge agent, hotel agent, concierge AI

## 三、案例：Ditto

**产品**：iMessage-based matchmaker for college students  
**情境**：消除 swiping，从匹配到场地全流程管理  
**规模**：42,000+ 用户，5 个校园  
**Spectrum 角色**：支撑 iMessage 基础设施，团队专注 AI 匹配引擎  

**来源**：官网 [photon.codes/spectrum](https://photon.codes/spectrum)
