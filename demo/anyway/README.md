## 快速参考

### 一句话产品

Anyway 是面向 AI Agent 时代的支付网络 — 一次集成即可让任何 AI Agent 自主收款、付款和结算，覆盖所有协议与货币，配备可验证 Agent 执行追踪和内置安全沙箱。

### 关键差异化

1. **Agent-Native Payments** — 从零为 AI Agent 设计的支付基础设施，不是传统支付 API 的封装
2. **One Integration, Every Protocol** — 统一 X402、ACP、MPP 等所有 Agent 支付协议，同时支持法币和加密货币
3. **Secure Sandbox** — 防止 Prompt Injection 劫持 Agent 交易的独立安全沙箱
4. **Verifiable Agent Traces** — 证明 Agent 执行了什么，而不仅仅是支付了什么
5. **SuperAPI** — 一次安装给 Agent 全部所需 API，按调用计费

### 市场背景

- 2026 年是 Agentic AI 元年，Agent-to-Agent 自主交易需求爆发
- AI Agent 市场预计 2030 年达 $47.1B（MarketsandMarkets）
- Agent 支付协议碎片化：X402、ACP、MPP 等多标准并存
- 提示注入攻击是 Agent 支付的核心安全风险
- Stripe、PayPal 等传统支付基础设施完全未为 Agent 设计
