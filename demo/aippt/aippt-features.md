## 一、核心能力线

### 1. AI 生成（Prompt / Document / URL → PPT）

| 能力 | 说明 | 上线状态 |
|------|------|----------|
| **Prompt-to-PPT** | 输入一句话主题或自然语言描述，AI 自动生成大纲、文案、排版、设计 | 已上线 |
| **Document-to-PPT** | 上传 DOCX / PDF / TXT 文件（最多 5 个），提取内容转化为结构化幻灯片 | 已上线（Nano Banana 支持） |
| **URL-to-PPT** | 粘贴网页 URL，抓取内容生成 PPT | 已上线 |
| **Google Drive 导入** | 从 Google Drive 导入文件生成 PPT | Plus+ 可用 |
| **Markdown 导入** | 支持 Markdown 格式输入 | 已上线 |
| **Nano Banana Mode** | 高级 AI 渲染引擎，主题感知式视觉风格、多语言文本渲染、Prompt 精细化控制（幻灯片数/风格/图表/布局/语言） | 2026.01 上线；2026.03 升级至 Nano Banana 2 |
| **Nano Banana 2** | 秒级 Prompt-to-Pixel 生成；集成 Google 实时搜索确保视觉准确性；多语言自动本地化 | 2026.03 上线 |

### 2. AI 图像生成

| 模型 | 特点 | 上线时间 |
|------|------|----------|
| **Nano Banana 2** | 高速生成、实时搜索校验、多语言文本渲染 | 2026.03 |
| **GPT Image 2** | 低延迟推理、高保真度、更好的 Prompt 理解、自然场景 | 2026.04 |
| **Flux** | 开源模型集成 | 已上线 |
| **Imagen** | Google 模型集成 | 已上线 |
| **Seedream 4.0** | 前沿生图模型 | 已上线 |

用户可通过 **AI 模型选择器**（2026.03 上线）在速度优先与质量优先之间切换，部分模型需付费解锁。

### 3. 模板系统

| 维度 | 数据 |
|------|------|
| 模板总数 | **200,000+**（免费） |
| 覆盖场景 | 商务 / 教育 / 科技 / 营销 / 培训 / 简历 / 创意 |
| 模板替换 | Plus 起无限次一键更换模板 |
| 筛选方式 | 风格 / 颜色 / 行业 |

### 4. 编辑与优化

| 能力 | 说明 |
|------|------|
| **全新编辑器**（2026.03） | 现代化界面、拖拽编辑、实时预览 |
| **Agent Mode** | 多步迭代而非单次生成；AI 解析需求 → 分解大纲 → 补充信息 → 产出更丰富内容 |
| **Free Canvas** | 卡片式拖拽自由布局，脱离传统线性幻灯片范式 |
| **AI Edit** | AI 智能润色、扩写、改写、摘要；点击任意文本框即可语义优化与术语校准 |
| **AI 图像编辑** | 幻灯片内 AI 生图、替换、调整 |
| **图表生成** | 粘贴 Excel 数据自动生成 12+ 种图表类型，支持实时数据链接 |
| **多语言生成** | 支持中英文及多语言自动本地化 |
| **动态布局引擎** | 拖拽图片触发自动布局重排 |

### 5. 导出与分享

| 格式 | 说明 |
|------|------|
| **PPT** | 兼容 Microsoft PowerPoint、WPS、Google Slides |
| **PDF** | 标准 PDF 导出 |
| **图像** | PNG / JPG 等格式 |
| **可编辑链接** | 生成在线阅读链接，支持协作编辑 |
