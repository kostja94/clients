## 一、人物画像（Personas）

### P1：学生 / 学术用户

- **身份**：大学生、研究生、博士生
- **场景**：论文答辩、课堂展示、学术演讲、求职简历
- **痛点**：不会做 PPT 设计、时间紧、预算有限
- **关键诉求**：**免费 / 低价**、快速生成、模板美观、兼容学校电脑的 PowerPoint 版本
- **触发搜索**：*AI PPT for students*、*thesis defense PPT*、*free AI presentation maker*
- **产品触点**：Free 方案 + 学术模板 + Document-to-PPT（导入论文 PDF）

### P2：职场白领

- **身份**：初中级职员、项目经理、销售
- **场景**：周报/月报、项目提案、商务汇报、客户演示
- **痛点**：频繁做 PPT 但设计能力有限、需要兼容公司 PowerPoint/WPS 环境
- **关键诉求**：**PPT 导出兼容性**、模板丰富、可二次编辑、中英文支持
- **触发搜索**：*AI PPT maker for work*、*business presentation AI*、*convert document to PPT*
- **产品触点**：Plus/Pro 方案 + 商务模板 + PPT 原生导出

### P3：创业者 / 小型团队

- **身份**：初创创始人、小企业主、独立开发者
- **场景**：投资人 pitch deck、产品发布会、路演演示
- **痛点**：无专职设计师、需要高质量但无法投入大量时间
- **关键诉求**：**高质量设计**、数据图表生成、品牌一致性、快速迭代
- **触发搜索**：*AI pitch deck generator*、*startup presentation maker*、*AI PPT pro*
- **产品触点**：Pro 方案 + Nano Banana 2 精细控制 + 图表生成

### P4：营销 / 内容 / 培训人员

- **身份**：内容营销、企业培训师、课程设计
- **场景**：批量培训材料、营销报告、内容演示
- **痛点**：内容多、更新频繁、需要品牌统一风格
- **关键诉求**：**URL/文档批量导入**、模板替换、团队共享（可编辑链接）
- **触发搜索**：*training presentation maker AI*、*marketing PPT generator*、*URL to PPT*
- **产品触点**：Plus/Pro + URL 导入 + 无限模板替换 + 可编辑链接

### P5：国际化 / 多语言用户

- **身份**：印度/菲律宾/香港/马来西亚用户
- **场景**：本地化商务演示、教育课件
- **痛点**：英语非母语、需要本地语言支持
- **关键诉求**：**多语言生成**、本地化模板、区域定价
- **触发搜索**：*AI PPT maker India*、*presentation maker online free*
- **产品触点**：区域子站（/in、/ph、/hk、/my）

## 二、典型使用旅程

### 旅程 A：学生快速做答辩 PPT

1. 搜索 *thesis defense PPT AI* → 进入 AiPPT
2. 选择 Free 方案 → 输入论文主题
3. AI 生成大纲 → 确认结构
4. 上传论文 PDF（Document-to-PPT）→ AI 提取要点
5. 选择学术模板 → AI 自动排版
6. 微调文字（AI Edit）→ 导出 PPT
7. 在 PowerPoint 中做最终调整 → 答辩使用

### 旅程 B：白领做月度汇报

1. 打开 AiPPT → 选择 Pro 方案
2. 上传 Word 版月报 → Nano Banana Mode 生成
3. 选择商务风格模板 → 一键替换试用
4. AI Edit 润色关键段落
5. 需要配图 → AI Image 生成
6. 导出 PPT → 发给领导
7. 下月继续使用（留存）

### 旅程 C：创业者做 Pitch Deck

1. 搜索 *AI pitch deck generator* → 对比 Gamma/AiPPT
2. 选择 AiPPT Pro（性价比 + PPT 导出）
3. 输入产品描述 Prompt
4. 指定图表类型、页数、风格
5. AI 生成初稿 → 逐页调整
6. 用 GPT Image 2 生成产品示意图
7. 导出 PPT → 投资人演示

## 三、场景覆盖度评估

| 场景 | 产品匹配度 | 内容缺口 |
|------|-----------|----------|
| 学术演示 | 高（模板+免费+Document 导入） | 学术写作规范引导可强化 |
| 商务汇报 | 高（PPT 兼容+模板） | 品牌套件功能缺失 |
| Pitch Deck | 中高（Pro+Nano Banana） | 投资人叙事模板/引导 |
| 培训材料 | 中高（URL+批量导入） | 企业 Team 方案未上线 |
| 营销报告 | 中（URL 导入+图表） | 数据可视化功能可深化 |
| 本地化演示 | 中（多语言+区域站） | 印度/东南亚本地模板补充 |
