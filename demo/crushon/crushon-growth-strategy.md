## 1. 增长目标与约束

| 维度 | 策略 |
|------|------|
| **主转化** | SEO/社群 → 免费注册 → 首聊 → Standard/Premium 订阅 |
| **主战场** | Google 有机搜索、Reddit、Discord、TikTok/YouTube 创作者评测 |
| **品类定位** | **Character.AI alternative** + **AI Girlfriend** + **Unfiltered RP** |
| **品牌数据锚点** | 8M 角色、10M 用户、4.9★（chat 子域，2026-06-17） |
| **合规约束** | 18+；禁止未成年/真人内容；App Store 礼物等功能受限 |
| **付费锚点** | Standard $5.99 vs c.ai+ $9.99 — 价格对比贯穿营销 |

## 2. 渠道与战役（≥3 方向）

### 方向 A：SEO + 内容（有机）

| 要素 | 内容 |
|------|------|
| **目标** | 拦截 character ai alternative、ai girlfriend、crushon pricing |
| **已有资产** | [chat.crushon.ai](https://chat.crushon.ai/) 长文落地、FAQ Schema、对比表 |
| **待补强** | 主域 `/pricing`、`/vs/*`、sitemap、标签 landing |
| **主题** | 2026 更新（记忆/群聊/语音）、模型选择指南、创作者教程 |
| **节奏** | Phase 1 主域 5 页；Phase 2 每月 2–4 篇 blog |
| **联动** | [crushon-site-structure.md](./crushon-site-structure.md) Phase 1–2 |

### 方向 B：创作者飞轮（UGC + 社群）

| 要素 | 内容 |
|------|------|
| **目标** | 角色库增长、Discover 停留、礼物/订阅收入 |
| **战术** | Discord 创建教程；热门角色排行榜；Creators spotlight |
| **变现** | Diamonds 礼物、SubscribeStar/Patreon 外链、角色订阅 |
| **联动** | Persona P3、[crushon-features.md](./crushon-features.md) 创作者经济 |

### 方向 C：对比与 GEO（AI 答案可见性）

| 要素 | 内容 |
|------|------|
| **目标** | 在「best character ai」「crushon vs character ai」答案中被引用 |
| **已有** | chat 子域结构化对比表（CrushOn vs Character.AI vs Janitor.AI） |
| **战术** | FAQ + 对比表格 HTML；补充独立评测页；Reddit 官方参与 |
| **联动** | [crushon-competitors.md](./crushon-competitors.md) |

### 方向 D：付费与 LTV（订阅优化）

| 要素 | 内容 |
|------|------|
| **目标** | Free → Standard → Premium；Annual 锁定 |
| **杠杆** | 100 Credits/月触顶；Pro Models 质量差；24K 记忆仅高阶 |
| **加购** | Chat Package（无限 Pro 聊）；Coins 消息包 |
| **风险** | 档位过多（至 Imperial $199.99）可能增加选择摩擦 |
