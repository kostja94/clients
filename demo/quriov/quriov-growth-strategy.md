## 3. 战役节奏

### 短期（0–90 天）— 戒指 + 眼镜预热

- **Blog 启动**：启用 Shopify Blog，发布 5-8 篇戒指 SEO 文章
- **戒指对比页**：建 `/pages/vs-oura` 对比页
- **商品页优化**：增加 FAQ Schema、更突出的「No Subscription」标签
- **社交媒体启动**：TikTok/Instagram 戒指开箱视频
- **眼镜社区预渗透**：在 r/ADHD、GitHub/HN、盲人社区建立存在感，以"我们在做这个，来给反馈"的方式收集需求
- **眼镜概念 Demo**：制作三类场景短视频（ADHD 防遗忘 / 开发者远程 Coding / 视障环境感知）
- **评价激励**：已购用户追评邀请，目标 200+ 评价
- **眼镜 waitlist 分群**：在 waitlist 注册时询问"你最期待什么功能？"作为人群标签

### 中期（90–180 天）— App + 眼镜内测

- **App "little Q" 发布**：App Store/Google Play 上线 + 科技媒体送测
- **Blog 扩量**：月度 4-6 篇，覆盖戒指健康 + 眼镜三类话题簇
- **眼镜内测招募**：从 waitlist 按人群筛选 50-100 名内测用户（ADHD 20 / 开发者 30 / 视障 10 / 通用 40）
- **深度内容**：
  - ADHD 向：与 ADHD 博主/治疗师合作内容
  - 开发者向：在 GitHub 发布眼镜 API/SDK 文档 + 开源示例
  - 视障向：与视障机构联合发布用户研究报告
- **YouTube 专业评测**：3-5 位科技 YouTuber 深度评测
- **开放加拿大/英国发货**（戒指）

### 长期（180 天+）— 眼镜发布 + 生态

- **眼镜正式发布**：Kickstarter 或官网预售 + 科技媒体集中 PR
- **AI 订阅层**：眼镜 AI 功能成熟后推订阅（预计 $9.99–$14.99/月，含 AI Agent + 视觉理解 + 跨设备上下文）
- **三类人群生态深化**：
  - ADHD：与心理健康 App/Treatment 平台合作
  - 开发者：IDE 插件生态（VS Code/Cursor 深度集成）
  - 视障：与保险/政府辅助器具补贴对接
- **欧洲/亚太市场**：多语言站 + 区域仓储
- **零售渠道**：Amazon、Best Buy 等线上线下拓展

## 4. 变现与留存

### 当前变现

- **硬件销售**：Quriov Smart Ring $39.99（一次性收入，毛利率 **待验证**）
- **免费 App**：获取用户数据，为 AI 功能积蓄训练基础

### 未来变现

- **App AI 订阅**："little Q" AI 能力成熟后，推基础免费 + AI Pro 订阅
- **眼镜销售**：预估定价 $299–$499（高端硬件）+ AI 订阅捆绑 $9.99–$14.99/月（含 AI Agent + 视觉理解 + 跨设备上下文）
- **开发者 API/SDK**：眼镜开放 API，企业/开发者付费接入（与戒指 API 不同定价层）
- **配件**：不同颜色/材质戒指、眼镜镜片替换、充电座等
- **B2B 垂直方案**：视障辅助机构批量采购、ADHD 诊所推荐、企业开发者套餐

### 留存

- **健康仪表盘**：App 数据积累 → 健康洞察 → 习惯养成（戒指用户留存）
- **路线图期待**：眼镜 waitlist → 内测邀请 → App 升级通知 → 生态升级动力
- **Jarvis 记忆效应**：眼镜积累用户上下文 → 越用越有价值 → 换机成本极高（数据+上下文绑定）
- **分人群社区**：
  - ADHD 用户群：分享防遗忘技巧、日常使用心得
  - 开发者群：分享眼镜 Coding 技巧、API 集成案例
  - 视障用户群：生活辅助经验分享、出行安全讨论
- **内容**：Blog + 邮件周报 + 使用技巧推送（戒指+眼镜双内容线）
- **复购**：送礼场景、多色/多尺寸戒指、眼镜换代升级

## 5. 技术 SEO 注意

| 项 | 现状 | 建议 |
|----|------|------|
| 平台 | Shopify（自带 SEO 基础） | 利用 Shopify SEO 功能：alt text、meta、结构化数据 |
| sitemap | Shopify 自动生成 **待验证** | 确认 sitemap.xml 可正常访问 |
| robots.txt | **待验证**（抓取超时） | 确认 Shopify 默认 Allow 规则 |
| 结构化数据 | **待验证** | 建议加入 Product / Review / FAQ / Organization Schema |
| Blog | 未启用 | 启用 Shopify Blog 功能 |
| 页面速度 | **待验证** Lighthouse | Shopify 主题优化 + 图片压缩 |
| 移动端 | **待验证** | 移动端商品页转化率优化 |
| 多货币 | 200+ 币种支持 | hreflang 暂不需要（仅英语），开放发货后逐步添加 |
| URL 结构 | Shopify 默认 `/products/*` `/pages/*` | 对比页用 `/pages/vs-oura` 等 |
