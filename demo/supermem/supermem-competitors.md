# SuperMem 竞品分析

> 关联：[supermem.md](./supermem.md) | [supermem-use-cases.md](./supermem-use-cases.md) | [supermem-keywords.md](./supermem-keywords.md)

**SuperMem 产品形态**：平台型（Marketplace），双边市场。供给端=专家+其 Agent；需求端=企业/团队。详见 [supermem.md](./supermem.md)。

---

## 一、竞品类型拆解

竞品按**产品形态**与**供给端**分为四类：

| 类型 | 供给端 | 需求端 | 平台抽成 | 代表 |
|------|--------|--------|----------|------|
| **A. Freelancer 平台** | 真人自由职业者 | 企业/个人 | 5–35% | Upwork、Fiverr |
| **B. Fractional 专家平台** | 真人专家（CMO/CFO 等） | 企业 | 抽成或项目费 | Paro、Toptal |
| **C. AI Agent 市场** | 专家训练的 AI Agent | 企业/团队 | 25%+ | Fractional OS、CMOAI |
| **D. AI/SaaS 工具** | 无供给端；工具/工作流 | 企业 | 订阅费 | Stack AI、Eucera |

SuperMem 属于 **C 类**，但叠加 **Expert-in-the-loop**（专家审批）与 **真人+Agent 双供给**（真人 5%、Agent 25%），与 A/B/C 均有重叠与区隔。

## 二、A. Freelancer 平台

| 竞品 | 定位 | 供给端 | 品类 | 平台抽成 | 与 SuperMem 关系 |
|------|------|--------|------|----------|------------------|
| **Upwork** | 全球自由职业者市场 | 真人 freelancer | AI、开发、设计、营销、财务、法律等 | 客户 5–10%；自由职业者 0–15% | 间接竞品；真人交付；质量参差；无 Agent、无专家审批 |
| **Fiverr** | 按服务/Gig 交易 | 真人 freelancer | 400+ 品类；编程、设计、营销、AI 等 | 卖家 20%；买家 5.5%+$3 | 间接竞品；Gig 制；有效抽成 24–35% |

**Upwork**：800K+ 客户；AI 生成职位描述；按项目/里程碑付款；Business Plus 可访问 top 1% 审核人才。  
**Fiverr**：11M+ 企业；Gig 包/定制报价；Fiverr Go（AI 按卖家风格生成内容）。

**关键词**：hire freelancers、hire experts、freelance marketplace、Upwork alternative、Fiverr alternative

## 三、B. Fractional 专家平台

| 竞品 | 定位 | 供给端 | 品类 | 与 SuperMem 关系 |
|------|------|--------|------|------------------|
| **Paro** | 财务与会计专家市场 | 真人 CFO、会计师 | 财务、会计、税务、融资咨询 | 间接竞品；真人交付；AI 匹配；无 Agent |
| **Toptal** | 顶级人才市场（top 3%） | 真人开发者、设计师、财务等 | 开发、设计、财务、项目管理 | 间接竞品；严格筛选；试用期；无 Agent |
| **ExpertBridge** | 专家咨询市场 | 真人专家 | 30 分钟–多周项目；$50–$1000/小时 | 间接竞品；按需付费；72 小时匹配 |
| **ExpertEase** | 专家支持网络 | 真人专家（Google、McKinsey 等） | 技能学习、项目外包、辅导 | 间接竞品；真人；无 Agent |

**Paro**：接受率<2%；Big Four、Fortune 500 背景；60+ 行业；AI 匹配；分形 CFO、会计、税务、融资。  
**Toptal**：多轮筛选；按小时/兼职/全职/项目；透明定价；2 周试用。

**关键词**：fractional CMO、fractional CFO、hire expert、expert marketplace、Paro alternative、Toptal alternative

## 四、C. AI Agent 市场（直接竞品）

| 竞品 | 定位 | 供给端 | 与 SuperMem 重叠 | 差异化 |
|------|------|--------|------------------|--------|
| **Fractional OS** | AI Agents Marketplace | 专家训练的 Agent | 专家训练、市场研究/融资/内容/HR、24/7 | 无 Expert-in-the-loop；偏执行；有 Digital Twin、For Experts |
| **CMOAI** | CMO 专家网络 + AI Agent | 900+ CMO 训练的 Agent | 专家训练、Demand Gen/Content/SEO | 聚焦营销；无人类审批；2 周部署 |
| **Marketing AIgent** | Custom co-CMO + AI | 专家 + AI agent fleet | 专家 + AI、营销 | 偏服务交付；非平台 |
| **Tanka** | AI-Native 协作 OS | 记忆、Agent | 记忆、Agent、组织协作 | 无专家市场；竞品参考 |

## 七、差异化总结

| 维度 | SuperMem | Freelancer (Upwork/Fiverr) | Fractional (Paro/Toptal) | AI Agent (Fractional OS/CMOAI) |
|------|----------|---------------------------|--------------------------|-------------------------------|
| **供给端** | 专家 + Agent | 真人 | 真人专家 | 专家训练 Agent |
| **产出** | 计划、草稿、分析、工作流 | 真人交付 | 真人咨询/执行 | Agent 执行 |
| **审批** | Expert-in-the-loop | 无 | 无 | 无或弱 |
| **平台形态** | 双边市场 | 双边市场 | 双边市场 | 市场或订阅 |
| **质量** | 专家背书 + 审批 | 参差；需筛选 | 高（严格筛选） | 专家训练 |

---

## 八、Gaps（竞品未覆盖）

- **专家训练 + 人类审批**：A/B 类无 Agent；C 类无审批；D 类无专家市场
- **真人 + Agent 双供给**：同一平台可雇真人或 Agent，且 Agent 需专家审批
- **多职能 Agent 市场**：Research、Growth、Content、Fundraising、Accounting 一站式
- **Skill 工作流**：专家知识沉淀为 Skill，Agent 执行 + 专家 review 收费
