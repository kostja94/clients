## 1. 产品信息

### 产品摘要

**SuperMem** 是平台型（Marketplace）Expert Agent Hub：**供给端**为专家及其训练的 AI Agent，**需求端**为企业/团队。用户可「雇佣」专家或 Agent 完成计划、草稿、分析、工作流等实际工作，并在关键决策点由专家或用户本人审批后再执行。核心差异化：**Expert-in-the-loop**——AI 做重活，人类保留判断权。

### 产品定位

**SuperMem** 面向 **需要专家级产出但无法全职雇佣专家的团队**，定位为「专家级数字员工市场」。与纯自动化 AI 不同，SuperMem 强调：
- **Expert-trained**：Agent 由顶级 CMO、投资人、CFO、顾问等训练
- **Context-aware**：连接会议、文档、工具，Agent 学习你的工作方式
- **Real work output**：产出计划、草稿、分析、工作流，而非仅建议
- **Human approval**：关键决策需专家或用户审批后才生效

### 目标受众

- **Startups**：想雇佣最好的人，但预算有限
- **Teams**：高标准、不愿在质量上妥协
- **Builders**：想成为「一人独角兽」，产出专家级成果
- **Companies**：向 AI-Native 组织转型

### 核心产品线

| 产品/Agent | 训练者 | 能力 |
|------------|--------|------|
| **Research Agent** | Top Consultants | 深度市场研究、竞品分析、战略洞察 |
| **Growth Agent** | Top CMOs | 数据驱动增长策略、活动优化、渠道分析 |
| **Content Agent** | Best Storytellers | 叙事、品牌一致性、内容策略 |
| **Fundraising Agent** | Top Investors | Pitch 优化、投资人触达、尽调准备 |
| **Accounting Agent** | Top CFOs | 财务规划、税务优化、合规 |

### 平台能力

| 能力 | 说明 |
|------|------|
| **Expert Marketplace** | 浏览并雇佣经过验证的专家网络 |
| **Skill 导入与工作流** | 专家将知识沉淀为 Skill，导入平台并创建工作流；Agent 可执行（如跑关键词、生成网页和博客） |
| **结构化记忆** | 上传文章等内容提取成结构化记忆，AI 自动分类；支持 sitemap 自动 fetch 新内容、链接抓取 |
| **Seamless Integrations** | 一键连接常用工具；Onboarding 支持手动上传、未来集成更多工具 |
| **Real-time Progress** | 实时追踪 Agent 工作进度 |
| **交互方式** | 与专家 AI 聊天、预约会议；语音为主（提高付费意愿），文字输入后台已具备 |

### 收费模式

| 类型 | 平台抽成 |
|------|----------|
| 真人服务 | 5% |
| AI Agent 服务 | 25% |

### 核心价值主张

- **Enterprise Sovereignty & Privacy**：企业主权与隐私
- **High Quality Context Graph**：高质量上下文图谱
- **Human–Agent Collaboration**：人机协作

### 产品理念

> Today：AI 能写能总结，但不理解责任、权衡与后果。  
> SuperMem：未来不是 AI 取代专家，而是 AI 放大专家——让一个专家变成一支分形团队。

### 市场洞察

- **服务 vs 产品**：产品同质化严重、审美疲劳，人们没时间试用；服务将得到更多关注，公司更需要专家咨询与决策判断
- **Agent 取代人力**：市场趋势是 Agent 取代人力（而非取代 apps）；语音交互提高用户付费意愿
- **超级个体**：通才类（创立公司但精力有限）与顶尖专家类协作，可打造单人独角兽公司
- **工作流效率**：大模型用自然语言搭建工作流，一人花一半时间能顶一家公司半年搭建的 agents

**金句**：
> 「现在这个时代，大家对于产品的要求越来越高，审美越来越疲劳，产品再好也未必会被懂得欣赏，因为人们根本没有时间去尝试，接下来服务反而会得到更多的关注。」

> 「我们已经进入超级个体时代，超级个体分两种，一种是通才类，自己创立公司但精力有限；另一种是在某一领域顶尖的专家，两类超级个体协作能打造单人独角兽公司。」

> 「未来大模型可以用自然语言直接搭建工作流，一个人花一半时间做的工作流能顶一家公司花半年搭建的 agents，效率极高。」
