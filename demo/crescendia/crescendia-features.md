## 2. 用户流程

### 2.1 诊断获客漏斗（公开站）

```
访问首页 → 理解 GEO 价值主张
  → Get GEO Report / AI Search Readiness Scan
  → 填写 /report（公司、市场、品牌、竞品、SEO/GEO 现状、目标、联系方式）
  → 团队生成 SEO & GEO 可行性诊断（对标基准公司）
  → Get in Touch / Book Demo（/demo）
  → 进入 Pilot 或 Ongoing 服务
```

### 2.2 服务交付路径（官网叙事）

```
Readiness Scan / Diagnostic
  → 90-day AEO Pilot（验证策略与 ROI）
  → Ongoing AEO Optimization（规模化内容与意图覆盖）
  → 持续监测：AI Mentions / AI Search Traffic / User Pay Rate
```

官网描述 GEO 服务三阶段：Strategic planning & infrastructure → Validation → Scaling；完整周期通常 **6 个月以上**（FAQ，2026-07-21）。

### 2.3 Partner 路径

```
了解 Affiliate 权益 → Submit 申请 → 启用销售包/联合销售
```
