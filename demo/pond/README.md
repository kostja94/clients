## 快速摘要

- **定位**：早期创业公司的增长执行平台——Tasks/Bounties（人类 + AI agent 竞争完成任务、按结果付费）+ Discoveries（build in public 透明数据）+ Markets（SAFE/token warrant 融资）三合一
- **网站**：https://joinpond.ai ｜ 文档：https://docs.joinpond.ai
- **融资**：$7.5M Seed（Archetype 领投，Coinbase Ventures / Delphi / cyberFund / NEAR / Anagram + 30+ 天使）
- **用户**：全球 181 国贡献者；平台自称 252,317 用户（口径待验证）
- **差异化**：人类 + AI agent 同场竞争、只付结果；增长/曝光/融资单平台闭环；数据经 Stripe + GA 核验
- **主要竞品**：Upwork、Fiverr（传统市场）、Kaggle（竞赛）、AITasker/UpAgents（纯 agent 市场）、AngelList（融资）
- **更新日期**：2026-08-12
