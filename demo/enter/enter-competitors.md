## 2. 直接竞品详细拆解

### Lovable（原 GPT Engineer）

- **定位**：「从想法到 App」的对话式全栈构建，Supabase 集成成熟
- **优势**：社区声量、模板与 showcase、GitHub 双向同步叙事强
- **劣势**：与 Enter 功能高度重叠，差异化需靠 CLI/Code/Converge 多产品
- **流量**：**待验证** Semrush
- **SEO**：lovable.dev 对比类内容活跃

### Bolt.new（StackBlitz）

- **定位**：浏览器 WebContainer 内 AI 生成可运行全栈项目
- **优势**：零本地环境、即时运行、开发者口碑
- **劣势**：企业协作与 Visual Editor 叙事弱于 Enter；后端集成需自行扩展
- **流量**：**待验证**
- **SEO**：bolt.new 品类词覆盖强

### Replit Agent

- **定位**：Replit 平台内 Agent 自动规划、编码、部署
- **优势**：教育市场、一站式托管、Agent 多步 autonomy  marketed 充分
- **劣势**：代码导出与 lock-in 顾虑；Enter FAQ 强调 100% 代码所有权
- **流量**：**待验证**
- **SEO**：replit.com 域名权威高

## 3. 场景级对比表

### 场景 A：非技术创始人 48h MVP

| 场景 | Enter Pro | Lovable | Bolt | 本品优势 |
|------|-----------|---------|------|---------|
| 自然语言 → 可点击原型 | ✓ | ✓ | ✓ | Visual Editor 点选改 UI |
| Supabase + Auth | ✓ 内置 | ✓ | 部分需配置 | Cloud 一体化叙事 |
| Stripe 支付 | ✓ | ✓ | **待验证** | 电商/feature 页明确 |
| 代码导出 | ✓ React+Tailwind | ✓ | ✓ | FAQ 强调无 lock-in |

### 场景 B：专业开发者 + IDE

| 场景 | Enter Pro | Cursor | Bolt | 本品优势 |
|------|-----------|--------|------|---------|
| 在 Cursor 内端到端 publish | ✓ Enter CLI | 需手动 deploy | 非 IDE 原生 | **CLI 一条 prompt → live URL** |
| 本地 repo Agent | ✓ Enter Code | ✓ Claude Code | — | 测试验证后交还 |
| 团队 PM 改文案 | ✓ Visual Editor | ✗ | 有限 | 角色权限 Workspace |

### 场景 C：AI Agent / 自动化产品

| 场景 | Enter Pro | Replit Agent | v0 | 本品优势 |
|------|-----------|--------------|-----|---------|
| Chatbot + 后端 | ✓ Agent Builder | ✓ | UI 为主 | 全栈+多 LLM 统一 API |
| 多 Agent 并行 session | ✓（Changelog） | ✓ | — | **待验证** 产品深度 |
| 一键 Edge Deploy | ✓ | ✓ Replit 托管 | Vercel | Custom Domain 全档 Basic+ |

## 4. 差异与机会

| | 分析 |
|---|------|
| **S** | 多产品线（Web/Code/CLI）、13 语言 SEO、内置 Supabase/Stripe、Visual Editor + 团队协作、Converge 生态 Credits |
| **W** | 定价在父域；品类与 Lovable/Bolt 高度同质；Forum sitemap 稀释；具体 $ 价不透明 |
| **O** | Vs 页抢对比词；Showcase 案例；Enter CLI 绑定 Cursor 用户群；多语言非英市场 |
| **T** | Lovable/Bolt 融资与声量；Replit 教育渠道；IDE Agent（Cursor）侵蚀「编码」叙事 |

**差异化机会**：强化 **Enter CLI × Cursor/Claude Code** 独特路径；用 **Converge 多产品 Credits** 讲平台故事；Blog 已有竞品向内容（adalo），扩展至 Lovable/Bolt 对比。
