## 3. 战役节奏

### 短期（0–90 天）

- 上线 3 个 `/vs/*` 对比页，内链 from Blog
- `enter.converge.ai/pricing` 镜像或 iframe，减少父域跳出
- Forum sitemap 治理：低质帖 noindex + 新建 `/showcase`（10–20 精选案例）
- Basic 档「Daily Free Credits」在 meta/OG 中 A/B 测试

### 中期（90–180 天）

- Templates 分类 Hub（SaaS / Portfolio / E-commerce）+ programmatic 描述
- School 教程系列 SEO 化（Enter Code vs CLI 澄清）
- 13 语言市场各选 1 个本地化关键词做 Landing 实验（de/ja/es）
- Semrush 跟踪 vs Lovable/Bolt 份额

### 长期（180 天+）

- Enterprise 叙事页（SSO、私有部署 **若产品就绪**）
- Converge 生态 bundle 营销（Enter + Framia 视频等）
- 开发者大会 / Event 内容（Blog category=Event 已有）

## 4. 变现与留存

- **Freemium → Basic**：Daily Free Credits 培养习惯；7 天 Free 额度到期推动 Basic（1,500 credits/月 + Custom Domain）
- **Pro 协作 upsell**：单人 Basic → Pro-1（Workspace ≤20 人）服务初创团队
- **Ultimate**：Early access + Priority Support 服务 heavy builder
- **留存**：Changelog 节奏（2026-04–06 活跃）；Forum 活动；Discord 支持

## 5. 技术 SEO 注意

| 项 | 现状 | 建议 |
|----|------|------|
| robots AI bots | GPTBot/ClaudeBot Disallow | 与 GEO 策略权衡；可保留 search=yes |
| crawl budget | ~3,870 URL，forum 占比高 | Showcase 优先，forum 降级 |
| 定价 off-domain | converge.ai/pricing | on-domain 或 canonical 明确 |
| 多语言 | 13 lang 镜像 | hreflang 审计 |
