## 1. 产品信息

**Enter Pro** 是 Converge AI 推出的 **AI Dev Agent**，Slogan 为 *Just Press Enter, Ship Like a Pro*，定位 **Vibe Coding 时代** 的「一人公司 / 小团队」构建工具。用户用自然语言描述需求，Agent 生成 **React + Tailwind** 前端、配置 **Supabase** 后端（数据库、存储、Serverless、Cron），并支持 **Stripe** 支付与 **GitHub** 同步；一键部署至 Edge 网络并绑定自定义域名。

产品线分为四条入口：**Enter**（浏览器协作工作区）、**Enter CLI**（让 Claude Code / Cursor / Codex 端到端构建发布）、**Enter Code**（本地终端 Super Agent，读代码库、写代码、跑测试）、**Enter Desktop**（原生桌面体验，**待验证**  GA 状态）。内置 **Design / Code / Plan** 等可定制 Agent，并通过统一 API 接入 GPT、Claude、Gemini、Grok 等模型。

与纯聊天式编码助手不同，Enter 强调 **可运行的全栈产品**：从 Landing Page、SaaS Dashboard、电商小程序到 AI Chatbot / 自动化 Agent，均可在同一 Workspace 内预览、Visual Edit、团队协作（Owner/Manager/Editor/Viewer）。FAQ 明确 **用户 100% 拥有代码**，可随时导出，无 vendor lock-in。

商业模式为 **Freemium + Credits 订阅**（Converge AI 统一套餐：Free / Basic / Pro-1 / Pro-2 / Ultimate）；免费用户每日登录获 **Daily Free Credits**。LLM 按 **list price** 计费，无额外渠道费。

## 7. 优化建议

1. **定价本地化**：在 `enter.converge.ai/pricing` 或 SSR 静态化美元价，降低从营销页到父域定价的跳出。
2. **对比页矩阵**：针对 Lovable / Bolt / Replit 做 `/vs/*`，承接高意图 commercial 词（Blog 已有 adalo 向内容，可扩展）。
3. **Forum 索引治理**：sitemap 含大量 `/forum/t/{uuid}`；建议 curated `/showcase` Hub + 低质帖 noindex，避免 crawl budget 稀释 features/blog。
