## 三、Tripo Studio（AI 原生 3D 工作台）

| 能力模块 | 用户感知 | 说明（公开信息） |
|----------|----------|------------------|
| **Intelligent Segmentation** | AI 自动分割模型 | 将任意模型自动拆分为有意义部件（头部/四肢/道具），支持独立编辑 |
| **Smart Low-Poly Generation** | 低模自动生成 | 产出干净、优化过的游戏/AR/VR 可用低面数资产 |
| **Magic Brush（Texture）** | AI 纹理笔刷 | 锁定视角 → 生成纹理 patch → 直接刷到模型表面 |
| **Uni-Rig** | 自动骨骼绑定 | 对任意形状角色（人/动物/生物）自动绑定骨骼，数秒完成 |

## 四、用户入口功能

| 能力 | 说明 |
|------|------|
| **Text-to-3D** | 文字描述 → 带纹理 PBR 网格；核心入口之一 |
| **Image-to-3D** | 上传 2D 照片/图 → 转 3D 模型 |
| **AI Photo-to-3D** | 人物/物体照片 → 3D 模型 |
| **PBR 材质输出** | 完整材质通道（basecolor / normal / roughness / metalness），直接对接引擎 |
| **四边面拓扑** | 重新拓扑后的网格，支持骨骼绑定与动画 |
| **Auto-Sizing** | 生成资产保持一致的物理尺寸 |
| **多格式导出** | 兼容 Blender、Maya、Unreal、Unity、3D 打印（STL）等 |
| **免费层** | 免费基础额度，降低新用户入门门槛 |

## 八、技术亮点与叙事要点

- **原生 3D 扩散**（P1.0）：区别于「2D 扩散 → 3D 重建」的串行方案，直接在 3D 空间生成，出图更快且拓扑更干净。  
- **200 亿参数**（Tripo 3.0）：对标 LLM 与图像模型的 Scaling Law，建立 3D 领域的参数规模壁垒。  
- **PBR + 四边面**：两个关键词是 3D 创作者判断「能用吗」的核心标准——Tripo 在这两点上下了重注。  
- **2 秒生成**：Smart Mesh P1.0 的速度卖点非常适合游戏/实时应用场景的文案。
