## 三、目标 URL 映射（推断 · 待爬虫验证）

| 主题 | 建议路径形态 | 备注 |
|------|----------------|------|
| 首页 / 主转化 | `/` | Hero + Demo / Login |
| 模型目录 | `/models` 或文档内模型浏览器 | 与「400+ models」叙事一致 |
| 供应商 | `/providers` | 页脚 **Providers** |
| BYOK | `/byok` 或 `/product/byok` | 页脚 **BYOK** |
| 定价 | `/pricing` | 页脚 **Pricing** |
| 文档 | `/docs`, `/quickstart` | **Docs**, **Quick Start** |
| API 分区 | `/docs/llm`, `/docs/search`, `/docs/media` | 与 **LLM / Search / Media APIs** 导航对应 |
| 博客 | `/blog` | **Blogs** |
| 关于 | `/about` | **About Us** |
| 状态 | `/status` 或外链 | **Service Status: Operational** |
| 法律 | `/privacy`, `/terms` | Privacy Policy, Terms of Use |
